# PP-FormulaNet_plus-M — 冻结合成数学公式识别实测（2026-10-23）

本报告记录 PP-FormulaNet_plus-M 在 Tang GPU 推理环境中实际产生的汇总指标与逐例观察。STEM Mentor 代码、前后端和文档仍在 Mac 开发；Tang 只承载 GPU 推理。没有真实学生数据或未经授权的试卷照片。

## 评测条件

- 模型：PP-FormulaNet_plus-M（未微调），PaddlePaddle GPU 3.3.0、PaddleOCR 3.3.2。
- 推理设备：NVIDIA RTX 4090 Laptop GPU，16 GB 级显存，gpu:0。
- 测试集：项目自编的 22 张合成数学公式图片，18 个不同公式、4 个额外视觉扰动样本。不是历年真题或手写照片。
- 冻结 Manifest SHA256：836d4c0a0ff7134a51443b5e6ea7cfd43554a714fe827df8e11d4c509eadf382。
- 图片生成：Matplotlib 3.10.9 / Pillow。逐图送入公式模型，不含 Mac 文本 OCR、手机拍照、网络传输或用户纠错。
- 原始模型结果存于 Tang 推理目录 evaluations/formula_v016/local_results.json；此报告保存已真实观察的控制台汇总。原始逐样本 JSON 尚未归档到 Mac。

## 已核对的识别差异

- F001：原始真值 x^2+2x+1=(x+1)^2，预测 x^{2}+2x+1=(x+1)^{2}；主要是上标括号写法差异。
- F004：参考以小写 x 起始，模型输出大写 X；大小写对变量有实际影响，不可以当作排版差异忽略。
- F007：f'(x) 被写成 f^{\prime}(x)，存在 LaTeX 序列化差异。
- F011、F017：模型增加了 array 环境包裹整条公式，对原始 exact match 影响较大。
- F020：轻微模糊后的分式仍原样正确匹配。
- F022：低对比度积分里的小写 x 被预测为大写 X，需要人工核对。
- F012：区间表达式增加 \left、\right；轻度排版归一化消去这类标记。

## 跨设备联调与仍然存在的问题

Mac 端已经实测原 Apple Vision → 按需裁剪 → SSH 隧道 → Tang PP-FormulaNet 的完整调用链，模型曾返回非空 LaTeX。早期整行裁剪把 Question: 一起送给模型，导致英文字母混入公式输出；后来 Mac 原生 Vision substring bbox 提供了冒号后公式区域，联调结果确认只采用对应的局部 bbox。

但局部公式仍出现 \because、\wedge 等可疑识别，不应自动当作正确表达式。这次 Mac 开发又缩小了公式裁剪的左右留白，并新增原始图片局部预览、断连状态探测与请求熔断。远端在后续检查时连接中断，因此**不能**声称裁剪后模型准确率得到实测提升；上述 22 样本指标也不代表新路由算法的端到端质量。

## 补充：Mac 局部裁剪与 Tang 真正联调（2026-10-23）

在 Tang 推理服务恢复后，Mac 再次真实调用本地 FastAPI、Apple Vision substring bbox 和受保护的 SSH 通道；服务没有接收任何真实学生图片。自动复验入口位于 scripts/check_formula_e2e_v016.py，原始响应保存在 Mac 的 artifacts/vision/formula_e2e_v016.json（被 Git 忽略）。

- 输入 1：Question: x^2 + 2x + 1 = (x+1)^2。裁剪成功，专用模型返回 x^{\prime}2+2x+1=(x+1)^{\prime}2；这并不正确，不能自动作为题干公式。
- 输入 2：Question: x² + 2x + 1 = (x+1)²。普通 Apple Vision 漏掉上标且将部分 x 认成 ×，但专用数学模型从原图局部返回 x^{2}+2x+1=(x+1)^{2}。此合成例与原式匹配。
- 首次恢复后的完整请求（含冷模型加载）约 12.8 秒和 4.1 秒；后续暖模型自动脚本复跑两例分别约 1.02 秒与 0.72 秒。数字来自不同运行条件，不能拿其平均数代替真实 P95 或正式 SLA。
- 在这两例中，服务没有调用 VLM，math_verified 始终是 false，用户仍需人工校对。

这验证了“普通 OCR 提取题干 → 精确局部公式裁剪 → 专用 OCR 补偿”的可行性，也暴露了对于 ASCII 幂符号、特殊排版和语义一致性仍然脆弱的事实。**仅两例，绝不是整题准确率的统计保证。**
