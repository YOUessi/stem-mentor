# 实施路线图

## M0 需求与设计基线
把讨论要点、验收矩阵、架构/模型、安全与评测文档上传 GitHub。验收：均可从 README 导航，可持续版本化更新。

## M1 模拟全栈闭环（当前目标）
无需 LLM API：可实际运行的响应式 Web 学习工作台、三模式、持久化会话/草稿、可观察的教学动作与思维地图、受控题卡。验收：接口和前端工作流可在本地测试。

## M2 个人记忆与复习
记录学生实际完成的历史经历，结构相似检索触发回忆；微知识点复习和调度。验收：跨会话真实引用、错误相似拦截、间隔升级/降级、无冗余提醒。

## M3 数学验证与资料审核
精细的公式/等价条件校验；补教材/方法卡审核管理工具。验收：有明确无法验证的返回，覆盖特定的已验证例题和反例。

## M4 真实模型集成（用户明确暂缓）
统一模型适配器、推理输出规范/策略约束、预算治理、RAG/长记忆实验。需先完成安全和性能对照，禁止以模拟结果宣称通用 LLM 能力。

## M5 学生试用与实际效果研究（未启动）
专家审核、真实学习前后测、无提示迁移和延迟复测；未成年人保护和资料授权先行。
