# v0.13：真实历史题目迁移与无提示学习证据协议

2026-10-19。只在 MacBook Air 的 ~/Documents/文件/stem-mentor 开发，不碰 Tang、不接 LLM API、不接触真实学生数据。保留第一版绿色 UI 和现有所有功能。

## 第一阶段（本轮交付）
1. 内置可解释且保守的历史题匹配：只索引同一学生在本次目标会话创建以前真正记录过完成的题，方法标签至少1个交集、结构标签至少2个交集；旧题和当前题不同，不编造相似来源。
2. 学生主动开启迁移训练：先在 INDEPENDENT 模式且没有已记录提示时写下独立思路，冻结 BASELINE；此时不显示旧题标题、方法或答案。
3. 完成基线后才有资格请求回忆；仅展示来自真实同学生历史练习的标题，不显示历史完整解答；回忆后再写 AFTER_RECALL 思路，双方存档但一律不自动判对。
4. 教学策略可根据显式操作从正推转逆推，反复卡住改变提示，不把学生自由文本评分当成模型推理。
5. 查看个人迁移过程和汇总：区分独立基线记录、回忆后记录、未验证正确性，禁止把“没有观察到应用内提示”称为学生真正自主掌握。
6. 冻结测试、用户数据隔离、主分支 CI、真 Chrome 绿色界面验收、日期证据、GitHub PR 合并，保护正式 demo 数据库。

## 安全和评估
- 完成一题不是数学正确性的证据；回忆过真实题目不是成功迁移。
- 紧紧绑定演示学生 ID 和可见会话；没有正式登录权限，不能投放真实未成年人数据。
- 对自定义题或无匹配历史只提示“无法确认”，禁止生成虚构记忆。
- AFTER_RECALL 必须有 BEFORE_RECALL 基线、同会话真实 recall 事件，且来源是本人过去完成的相近题。
- 禁止未经明确授权启用模型 API、联网检索真实学生记录或自动安排真实儿童学习任务。
