## 下一批次与验收门槛
### v0.10：基础数学对象补齐
复平面（加减、模、共轭、旋转）、集合韦恩图、数轴区间与不等式；先定义场景和数学真值测试，再实施。不要把“可画坐标”当作已有专项课程。

### v0.11：数列与函数深化
等差/等比数列、递推点图、部分和、q=1例外、比较增长；动态切线与单调/极值条件、端点比较；有限项图像不得声称证明无穷性质。

### v0.12：概率、计数和统计
计数树、样本空间、互斥与独立、二项/超几何分布、频率模拟、均值方差与回归；使用固定种子与归一化测试，区分模型假设和采样波动。

### v0.13：教学闭环而非动画堆积
把“预测—操作—解释—反例—迁移”接入教学动作与真实旧题记忆；记录自主尝试、辅助线依赖，不把观察正确当独立掌握。用冻结场景和教师评分指标评价策略。

### v0.14：内容与真实模型阶段（尚未授权开启）
教材/教辅授权、地区年份考试元数据、教师审核、未成年人数据合规。只有用户明确解除“无 API”限制后，才进行模型接入/预算与真实效果对照。

## 并发执行规则
开发模块由单一集成者维护共享 controller、课程映射和 API；独立纯数学测试、后端回归、浏览器验收可以并发。当前没有子 Agent 调度工具，日志写的是实际进程，不标成多个 AI Agent。

无定时后台任务：本看板不等于对话结束后会自动无限执行。恢复任务时从已确认的 Git 提交与待办继续，发现失败则先修复并记录；不能把计划写成完成状态。
