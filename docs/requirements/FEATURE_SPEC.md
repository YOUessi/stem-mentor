## 负面测试
- 历史记录为空：不得声称学生以前解过具体题。
- 两题文本都出现“椭圆”但数学结构不一致：不得做肯定迁移推荐。
- 非奇异切线等条件不满足：不得滥用换一半法则。
- 自主挑战未经求助：不能提前泄露方法/最终答案。
- 推理不可验证：显示“尚未验证”，不能自信判定错误。
- 题目未受支持：明确“模拟样例覆盖有限”，不假装已完成通用数学求解。
- 完成题目不等于掌握：只能记录完成和提示使用量，无独立证据不能打高分。
- 复习过于频繁：受每次会话/时间窗口限制。
