## 数列极限的ε–N量词与必要条件
**编辑目标**：KB33-A-P052-A001 · concept · REVIEW_PENDING

**课标版本/轨道与来源页指纹**：CN-HS-MATH-2017-REV2020 / ELECTIVE_A / 印刷页52 / 80d2633ed69158a2bd4de8ab2a22c0eae71f3960473df9a88a522d028b2d585f
**符号约定**：∀ε>0 ∃N∈ℕ ∀n≥N: |a_n−L|<ε
**先修主题（尚未认证图谱边）**：实数与绝对值、全称量词与存在量词、数列下标

**精确定义/命题**：数列(a_n)收敛到实数L，定义为：对每个ε>0，都存在正整数N，使所有n≥N满足|a_n−L|<ε；N可以依赖ε，但不能依赖已选定的n。

**完整前提**：数列的每项与候选极限L均为实数；n取正整数；ε必须对所有正值成立。

**分步论证（待教师复核）**：
1. 先固定任意正的误差容限ε。（依据：极限定义的外层量词是对所有ε>0。）
2. 从ε构造一个整数N(ε)。（依据：允许阈值随容差变化，却不允许每项重新挑阈值。）
3. 证明每个n≥N均满足误差界。（依据：只有尾部全称量词成立，才能判定该给定L是极限。）

**不适用例**：a_n=(-1)^n在任意大n仍交替±1，取L=0和ε=1/2时始终不满足尾部界。
**常见误解**：检查少数很大的n就足以证明极限。。纠正：有限次样本验证无法替代尾部所有n的条件。

**教师侧例题**：
- 证明a_n=1/n趋于0。 思路：给定ε>0，取整数N>1/ε。；n≥N时0<1/n≤1/N<ε。。答案：0。核验：对所有ε都有此N，满足全称尾部界。
- 判断a_n=2+1/n的极限。 思路：对误差|a_n−2|=1/n。；给定ε取N>1/ε。。答案：2。核验：首项是否等于2不影响尾部极限。
**启发提示阶梯（不展示教师答案）**：先把极限陈述写成∀ε>0∃N∀n≥N。 → 把误差|a_n−L|化简为关于n的上界。 → 从误差不等式反求严格足够大的整数N，最后统一检验全部n≥N。
**近迁移**：证明a_n=3/n趋于0并明确N对ε的依赖。
**远迁移**：解释为什么一次有限计算轨迹不能证明迭代算法收敛。

## 收敛实数列有界的逐步证明
**编辑目标**：KB33-A-P052-A002 · theorem · REVIEW_PENDING

**课标版本/轨道与来源页指纹**：CN-HS-MATH-2017-REV2020 / ELECTIVE_A / 印刷页52 / 80d2633ed69158a2bd4de8ab2a22c0eae71f3960473df9a88a522d028b2d585f
**符号约定**：a_n→L ⇒ ∃M>0 ∀n≥1: |a_n|≤M
**先修主题（尚未认证图谱边）**：数列ε–N极限、三角不等式、有限集合最值

**精确定义/命题**：若实数数列a_n收敛到有限实数L，则存在M>0，使所有正整数n都满足|a_n|≤M；反过来有界本身不能保证收敛。

**完整前提**：收敛极限L有限；数列每项为实数；结论是整条数列有界而非仅尾部有界。

**分步论证（待教师复核）**：
1. 在极限定义中选ε=1并取得N。（依据：收敛性保证n≥N时|a_n−L|<1。）
2. 对n≥N用三角不等式得|a_n|≤|L|+|a_n−L|<|L|+1。（依据：三角不等式给出无限尾部的统一上界。）
3. 与有限个前缀项|a_1|,…,|a_(N−1)|取最大值。（依据：有限非空实数集合有最大值；空前缀无需额外项。）

**不适用例**：a_n=(-1)^n始终在[-1,1]但两子列分别恒为1和−1，无法有同一极限。
**常见误解**：每条有界实数数列都会收敛。。纠正：有界只控制幅度，不约束奇偶项振荡。

**教师侧例题**：
- a_n=1/n有界吗？ 思路：n≥1故0<1/n≤1。；M=1就统一界住全部项。。答案：有界。核验：还可独立证明它趋向0。
- a_n=2+(-1)^n是否收敛？ 思路：所有项属于{1,3}故有界。；奇偶子列分别固定为1、3。。答案：不收敛。核验：两个不同常数子列极限排斥同一极限。
**启发提示阶梯（不展示教师答案）**：先用ε=1获得一个全尾部的估计。 → 有限前缀和无限尾部要分别控制。 → 把前缀的最大绝对值与|L|+1取共同上界。
**近迁移**：论证收敛数列3+1/n有界。
**远迁移**：为什么数值优化的参数范数有界不能保证参数迭代点收敛？

## 单调有界收敛定理的严格前提
**编辑目标**：KB33-A-P052-A003 · theorem · REVIEW_PENDING

**课标版本/轨道与来源页指纹**：CN-HS-MATH-2017-REV2020 / ELECTIVE_A / 印刷页52 / 80d2633ed69158a2bd4de8ab2a22c0eae71f3960473df9a88a522d028b2d585f
**符号约定**：a_1≤a_2≤…≤sup{a_n}
**先修主题（尚未认证图谱边）**：单调数列、上确界及实数完备性、数列极限

**精确定义/命题**：实数数列若单调递增且有上界则收敛到其值域上确界；单调递减且有下界时收敛到下确界；单独有界不足以推出收敛。

**完整前提**：实数完备性（非空有上界集合存在上确界）；单调方向与对应一侧界必须明确。

**分步论证（待教师复核）**：
1. 把递增数列的全体值组成非空有上界集合S，并令L=sup S。（依据：依赖实数的上确界性质。）
2. 任意ε>0，L−ε不可能是S的上界，故有某N使a_N>L−ε。（依据：上确界的最小上界定义。）
3. 递增保证n≥N时L−ε<a_N≤L；若a_n递减且有下界，令b_n=−a_n，则b_n递增有上界，前述结论给出a_n趋向其下确界。（依据：单调递增情形的误差界证明收敛；递减情形通过取负数列和上下确界的对应关系归约证明。）

**不适用例**：(-1)^n有界却不单调也不收敛。
**常见误解**：只知道有界就能直接调用单调收敛定理。。纠正：没有单调性就不能用一个靠近上确界的项控制后续所有项。

**教师侧例题**：
- a_n=1−1/n是否收敛？ 思路：n增大时1/n递减，故a_n递增且≤1。；上确界为1，故极限为1。。答案：1。核验：差值为1/n，亦可用ε–N检验。
- a_n=(-1)^n是否可用此定理？ 思路：数列值域只含±1所以有界。；后续增减交替，不满足任一单调条件。。答案：不可用。核验：不能用前提不成立的定理推导极限。
**启发提示阶梯（不展示教师答案）**：标清楚是递增还是递减。 → 检查对应的上界或下界，并说明实数完备性。 → 用上确界的ε定义加单调性建立全部尾项的误差界。
**近迁移**：论证1−1/(n+1)的收敛性。
**远迁移**：解释递推数值过程有界但可能振荡的反例。
**限制**：该审稿独立于旧关联，未完成官方条款拆分、课标数学等价认证和真实教师签署。

## 介值定理与连续性的不可遗漏前提
**编辑目标**：KB33-A-P053-A002 · theorem · REVIEW_PENDING

**课标版本/轨道与来源页指纹**：CN-HS-MATH-2017-REV2020 / ELECTIVE_A / 印刷页53 / ae9e0d41b2c8f7ac33b967ff6c40ae2a875322373c7e8470ddce25838b929d3b
**符号约定**：f∈C([a,b]), y∈[min(f(a),f(b)),max(f(a),f(b))]
**先修主题（尚未认证图谱边）**：连续函数、闭区间、实数完备性

**精确定义/命题**：若实函数f在闭区间[a,b]连续且a<b，任意介于f(a)与f(b)之间的实数y，都存在c∈[a,b]使f(c)=y；严格夹在两端之间时可选c∈(a,b)。

**完整前提**：区间为非退化闭实区间，f在整段连续；y确实介于端点函数值之间。

**分步论证（待教师复核）**：
1. 设g(x)=f(x)−y，则g连续。（依据：连续函数减常数仍连续。）
2. 当y在端点函数值之间，g(a)与g(b)不异号则至少一端为零，否则两端异号。（依据：根据端点值与目标值的相对位置逐一进行代数符号分类。）
3. 异号情形用实数连续性与二分嵌套区间得到g(c)=0。（依据：连续性保证每次保留的夹零闭区间长度趋零，极限点函数值为零。）

**不适用例**：f(x)=−1(x<0)、1(x≥0)定义于[-1,1]；端点夹住0，但函数从不取0。
**常见误解**：只要函数端点值夹住目标值，中间必取到。。纠正：跳跃不连续破坏了介值性质。

**教师侧例题**：
- f(x)=x²−2在[1,2]有零点吗？ 思路：函数为多项式，在[1,2]连续。；f(1)=−1且f(2)=2，异号。。答案：至少一个零点。核验：由介值定理；无需声称唯一。
- f(x)=1/x在[-1,1]能直接使用介值定理吗？ 思路：函数在x=0未定义。；不满足闭区间连续的前提。。答案：不能使用。核验：端点符号异号但中间不必有定义的零点。
**启发提示阶梯（不展示教师答案）**：先明确f在整个闭区间有定义并连续。 → 检查端点值是否确实夹住所求目标值。 → 结论是存在至少一个解；唯一性还要另外证明。
**近迁移**：判断x³−1在[0,2]存在零点。
**远迁移**：说明数值二分搜索为何需要连续及端点异号作为安全前提。
**限制**：该审稿独立于旧关联，未完成官方条款拆分、课标数学等价认证和真实教师签署。

## 拉格朗日中值定理的两重正则条件
**编辑目标**：KB33-A-P053-A004 · theorem · REVIEW_PENDING

**课标版本/轨道与来源页指纹**：CN-HS-MATH-2017-REV2020 / ELECTIVE_A / 印刷页53 / ae9e0d41b2c8f7ac33b967ff6c40ae2a875322373c7e8470ddce25838b929d3b
**符号约定**：∃c∈(a,b): f′(c)=(f(b)−f(a))/(b−a)
**先修主题（尚未认证图谱边）**：闭区间连续与开区间可导、导数、罗尔定理

**精确定义/命题**：若f在闭区间[a,b]连续且在开区间(a,b)可导，a<b，则存在c∈(a,b)，满足f'(c)=(f(b)−f(a))/(b−a)。

**完整前提**：闭区间连续、开区间处处可导、端点不同且有限；定理只保证存在，不保证c唯一。

**分步论证（待教师复核）**：
1. 定义弦斜率m=(f(b)−f(a))/(b−a)和g(x)=f(x)−m(x−a)。（依据：b−a非零，g连续且内部可导。）
2. 计算g(a)=g(b)=f(a)。（依据：减去线性函数后端点相等。）
3. 罗尔定理给出c∈(a,b)且g'(c)=0，故f'(c)=m。（依据：罗尔定理适用于g的闭区间连续与内部可导。）

**不适用例**：f(x)=|x|在[-1,1]的弦斜率为0，但在(-1,0)导数−1，(0,1)导数1，0处不可导。
**常见误解**：只要端点函数值存在就一定有内部切线斜率等于弦斜率。。纠正：内部不可导点会阻断中值定理。

**教师侧例题**：
- f=x²在[1,3]取何c？ 思路：弦斜率(9−1)/2=4。；f'(x)=2x，令2c=4得c=2。。答案：c=2。核验：2严格属于(1,3)。
- f=3x+1在[0,5]如何？ 思路：弦斜率(16−1)/5=3。；每个c∈(0,5)均有f'(c)=3。。答案：任意内部c。核验：存在性不必意味着唯一。
**启发提示阶梯（不展示教师答案）**：首先分开检查闭区间连续和内部可导两个条件。 → 构造通过端点的割线并从原函数中减去它。 → 用罗尔定理找导数为零的位置，再恢复原函数导数。
**近迁移**：求f=x³在[0,2]满足中值定理的c。
**远迁移**：为什么带尖点的实际响应曲线不能无条件套用瞬时斜率公式？

## 显著性水平与p值的条件概率方向
**编辑目标**：KB33-A-P057-A002 · concept · REVIEW_PENDING

**课标版本/轨道与来源页指纹**：CN-HS-MATH-2017-REV2020 / ELECTIVE_A / 印刷页57 / dca127ce9bc7a223440713495ea73ba89e2654586fda16bab4dcf465d648f2f2
**符号约定**：p=P_H0(T∈E), α=事先规定的拒绝阈值
**先修主题（尚未认证图谱边）**：古典概率与条件概率、样本分布、检验假设

**精确定义/命题**：给定零假设H0、检验统计量T和事先指定的极端性方向，p值是H0成立时获得至少同样极端数据的概率；显著性水平α是事先约定的Ⅰ类错误概率控制阈值，不等于H0为真的后验概率。

**完整前提**：事先给定检验统计量、尾部方向及H0下的抽样分布；不把观察到的p值当作随机选择的α。

**分步论证（待教师复核）**：
1. 根据研究问题给定H0与极端性事件E。（依据：不同单双尾和检验统计量会改变E。）
2. 计算p=P_H0(T∈E)，条件始终是H0为真。（依据：抽样分布下的尾概率定义。）
3. 用p和预设α作拒绝决策，不把P(数据|H0)翻转为P(H0|数据)。（依据：贝叶斯方向逆转需要先验与备择模型。）

**不适用例**：在抛硬币H0为公平且两次都为正面的观测下，单侧尾概率是1/4；这不是P(H0|观测)。
**常见误解**：p=0.03表示零假设只有3%的概率为真。。纠正：尾概率以零假设为条件，后验假设概率需要其他先验信息。

**教师侧例题**：
- 公平硬币2次都正面，单侧p值？ 思路：H0下4条长度2序列等可能。；至少2次正面仅HH一种。。答案：1/4。核验：这不是公平假设有25%概率为真。
- 预设α=0.05、观察p=0.04如何决策？ 思路：先确认检验方案与α在观察数据前预设。；0.04<0.05故在该规则下拒绝H0。。答案：拒绝H0。核验：决策不是证明备择为真，更不是计算后验概率。
**启发提示阶梯（不展示教师答案）**：明确写出概率符号中的条件H0。 → 明确极端性是单尾还是双尾，且不可看数据后随意更改。 → 最后把p与预设α比较，严禁反向解读为P(H0|数据)。
**近迁移**：公平骰子两次均为6时计算单侧指定极端事件概率。
**远迁移**：解释临床试验中为什么统计显著性不等于实际效果大小。

## 线性微分与真实函数增量的误差
**编辑目标**：KB33-B-P058-A004 · theorem · REVIEW_PENDING

**课标版本/轨道与来源页指纹**：CN-HS-MATH-2017-REV2020 / ELECTIVE_B / 印刷页58 / e119d314a74926dfadf4794e35ab3a665662ee3ec29ddcb3a119baaba50dcb7f
**符号约定**：Δy=f′(x)h+o(h), dy=f′(x)dx
**先修主题（尚未认证图谱边）**：差商与导数、线性函数、小o渐近符号

**精确定义/命题**：函数在x可导时有Δy=f(x+h)−f(x)=f'(x)h+o(h)(h→0)；微分dy=f'(x)dx是线性主部，一般不等于实际有限增量Δy。

**完整前提**：f在给定点x可导；h或dx趋于0；小o结论是局部极限而非任意大步长恒等式。

**分步论证（待教师复核）**：
1. 可导定义给出lim_{h→0}(f(x+h)−f(x))/h=f'(x)。（依据：导数存在是线性化的必要条件。）
2. 将差商误差写成r(h)h，其中r(h)→0。（依据：由极限定义，差商与导数之差趋0。）
3. 得到Δy=f'(x)h+r(h)h，故余项是o(h)。（依据：小o定义为余项除以h趋于0。）

**不适用例**：f(x)=x²，x=1、h=1时Δy=3，而dy=2。
**常见误解**：函数可导就有任何非零步长下Δy=dy的严格相等。。纠正：有限步长保留非线性余项h²，不能无条件删去。

**教师侧例题**：
- f=x²，在x=1、h=1/10的微分与真增量？ 思路：dy=2×1×(1/10)=1/5。；Δy=(11/10)²−1=21/100。。答案：dy=1/5，Δy=21/100。核验：差值1/100=h²。
- f=3x+1在任意h的微分与增量？ 思路：导数恒为3所以dy=3h。；直接相减f(x+h)−f(x)=3h。。答案：完全相等。核验：仿射函数无高阶剩余项。

## 微积分基本定理的连续性与端点条件
**编辑目标**：KB33-B-P059-A002 · theorem · REVIEW_PENDING

**课标版本/轨道与来源页指纹**：CN-HS-MATH-2017-REV2020 / ELECTIVE_B / 印刷页59 / 25cef7034650de2cdafb41e1b4bfdd895acb37c33cab7c939bfb57d7c84416dd
**符号约定**：F(x)=∫_a^x f(t)dt; F′(x)=f(x)
**先修主题（尚未认证图谱边）**：定积分、连续函数、中值定理与原函数

**精确定义/命题**：若f在[a,b]连续，定义F(x)=∫_a^x f(t)dt，则F在(a,b)可导且F'(x)=f(x)；若G是[a,b]上的任意原函数，则∫_a^b f(t)dt=G(b)−G(a)。

**完整前提**：a<b且f在整个闭区间连续；积分为定积分，原函数G在区间内满足G'=f并有合法端点。

**分步论证（待教师复核）**：
1. 用F(x+h)−F(x)=∫_x^{x+h} f(t)dt表示积分增量。（依据：定积分的可加性。）
2. 连续性使短区间上的平均函数值趋于f(x)，从而F'(x)=f(x)。（依据：积分均值估计和连续性。）
3. G−F导数恒为0，在区间内为常数，故G(b)−G(a)=F(b)−F(a)。（依据：中值定理与F(a)=0、F(b)=∫f。）

**不适用例**：f(x)=1/x在[-1,1]含x=0的奇点，不能把ln|x|在两端的值相减当作跨奇点定积分。
**常见误解**：被积函数在区间里有奇点也能直接套两端原函数差。。纠正：既未在整个区间连续，也没有跨越奇点的一份全区间原函数。

**教师侧例题**：
- 求∫_0^2 2x dx。 思路：f=2x连续，原函数G=x²。；G(2)−G(0)=4。。答案：4。核验：积分下限与上限的顺序正确。
- F(x)=∫_1^x t²dt，求F'(2)。 思路：t²在全实数连续。；微积分基本定理给F'(x)=x²，故F'(2)=4。。答案：4。核验：先核查积分函数的连续性和积分变量。
**启发提示阶梯（不展示教师答案）**：检查函数在整个积分区间定义且连续。 → 用变上限积分的短区间差商理解第一部分。 → 选全区间原函数，再严格计算上限值减下限值。
**近迁移**：计算∫_1^3 3x²dx。
**远迁移**：在跨越间断点的物理速率积分中说明为什么必须分段或重新定义模型。

## 经典二值逻辑的矛盾律与排中律
**编辑目标**：KB33-C-P065-A001 · concept · REVIEW_PENDING

**课标版本/轨道与来源页指纹**：CN-HS-MATH-2017-REV2020 / ELECTIVE_C / 印刷页65 / 603c130ef7943eab9b85fb3a21dbd3937756a4737d3f7295886d4e0dc71616c5
**符号约定**：¬(p∧¬p), p∨¬p
**先修主题（尚未认证图谱边）**：经典二值命题、合取析取否定、有限真值表

**精确定义/命题**：在经典二值命题语义中，矛盾律表达¬(p∧¬p)恒真，排中律表达p∨¬p恒真；二者是不同公式，不应推广为所有非经典逻辑的无条件定律。

**完整前提**：p为同一语义语境中的确定命题；取经典真/假二值及标准否定、合取、析取。

**分步论证（待教师复核）**：
1. 当p为真时，¬p为假。（依据：经典二值命题语义下否定联结词的真值规则。）
2. 当p为假时，¬p为真。（依据：二值否定规则覆盖所有允许赋值。）
3. 两行真值表中p∧¬p恒假而p∨¬p恒真。（依据：分别推出矛盾律与排中律，二者结构不同。）

**不适用例**：两公式分别是¬(p∧¬p)与p∨¬p，虽然经典语义下都恒真，但逻辑连接词及表达的否定关系不同。
**常见误解**：矛盾律与排中律是同一个命题公式。。纠正：同真值不代表同一语法表达式，且非经典逻辑中逻辑律可有不同地位。

**教师侧例题**：
- p为真时分别计算两公式。 思路：¬p为假，p∧¬p为假。；于是¬(p∧¬p)真，p∨¬p真。。答案：都为真。核验：两条规律都符合该真值行。
- p为假时分别计算两公式。 思路：¬p为真，p∧¬p为假。；于是¬(p∧¬p)真，p∨¬p真。。答案：都为真。核验：已遍历经典二值语义所有行。
**启发提示阶梯（不展示教师答案）**：先把每个命题公式明确写出，不要仅用口头标签。 → 分别计算p为真和p为假的两行真值表。 → 分清两者同为经典重言式与语法上为不同公式。
**近迁移**：对p、q分别列出¬(p∧¬p)和q∨¬q的真值表。
**远迁移**：比较经典二值逻辑与三值逻辑对排中律的定义差异。

**精确定义/命题**：若Q=A L^α K^β且A,L,K都严格为正、α和β为实数，则ln Q=ln A+αln L+βln K；该恒等式不是估计出模型参数或证明经济因果关系。

**完整前提**：A>0、L>0、K>0，实数幂按正底数定义；Q>0；现实生产函数本身为先验模型假设。

**分步论证（待教师复核）**：

**启发提示阶梯（不展示教师答案）**：先检查A、L、K及Q严格大于0。 → 将乘积逐项取对数，再用幂的对数法则。 → 解释线性化仅是数学变换，不能据此自动断定现实模型或因果关系成立。

**编辑目标**：KB33-D-P071-A002 · method · REVIEW_PENDING

**先修主题（尚未认证图谱边）**：整数整除、最小公倍数、时间单位换算

**精确定义/命题**：若若干循环节拍的周期为正整数p1,…,pk，且共用同一离散拍单位与起点，则首次正整数拍同步时刻是它们的最小公倍数；转换为秒必须额外知道每拍时长。

**完整前提**：各周期为正整数；节拍单位相同；初始相位为零；物理时间换算需有有效每拍秒数。

**分步论证（待教师复核）**：

3. 最小正公倍数就是lcm(p1,…,pk)。（依据：最小公倍数定义；没有速度时不能把拍数直接称为秒数。）

**常见误解**：计算出最小公倍数就知道同步所需秒数。。纠正：相同离散拍数对应的物理时间取决于节奏速度。

**启发提示阶梯（不展示教师答案）**：先统一周期是否用同一拍单位。 → 用整除关系而非直接相加来找最早共同周期。 → 如需物理时间，必须明确每分钟拍数或每拍秒数。
