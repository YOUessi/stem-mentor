# Batch41｜精确数学见证的前提、证明边界与失效案例

本文件将数学结论（必须数学上正确）、算法能证明什么、教师审核资格严格分离。源码：`backend/app/kb_batch41_exact.py`，测试：`backend/tests/test_kb_batch41_core_selective_depth.py`。所有验证器只对输入白名单、有限且有界的整数值进行精确计算，**绝不证明一般定理、自由文本解答或课程官方等价性**。

| 算子 | 精确实例与推理依据 | 非法/失效边界 |
|---|---|---|
| `set_complement_mask` | 3 位全集 111₂、子集 101₂，补集 010₂，即整数 2。通过有限位掩码集合差证明此具体结果。 | 若子集包含全集之外元素（011₂ 与 101₂ 的关系不满足子集）拒绝；这不是任意集合论证明器。 |
| `amgm_square_gap` | a=4、b=9 时 `(a-b)²=25`，准确验证 `(a+b)²-4ab≥0`；一般 AM–GM 的根式论证另见对应审核讲义。 | a<0 或 b<0 不适用实数非负 AM–GM；本算子的数值 25 不是两个平均值之差。 |
| `inequality_scale` | 1<2，同乘 -3 后 -3>-6；直接用整数序关系核验变向。 | 前提 a<b 不成立则拒绝；c=0 会产生等式，不是严格不等式。 |
| `quadratic_roots_count` | x²-5x+6=0，Δ=25-24=1>0，恰有两个不同实根。 | a=0 不是二次方程；不从 Δ 公式推断退化方程。 |
| `radical_fraction_domain` | 对 `√(x+2)/(x-1)`，x=-2 可取，因被开方数 0、分母 -3。 | x=1 除零；x<-2 负数开偶次根均拒绝。 |
| `log_product_powers` | a=2，x=2²，y=2³，xy=2⁵，`log₂(xy)=2+3=5`；Fraction 精确检查指数乘积。 | 底数不能为 1、0 或负；本算子对一般实数真数不作符号量词证明。 |
| `classical_probability` | 等可能模型假设成立时有利 3/总共 6 → 1/2。 | 有利数超过样本点数拒绝；**算子不能从计数确认真实试验等可能**。 |
| `event_union` | 6 个等可能样本点，|A|=3、|B|=3、交集 2，|A∪B|=4，概率 2/3。 | 不合法交集计数（大于最小事件规模、低于容斥下界）拒绝。 |
| `event_independent` | n=4、|A|=|B|=2、交集 1，1/4=(1/2)(1/2)，在此有限均匀模型下独立。 | 超出合法交集规模拒绝；独立不等于互斥，空概率事件可能构成例外。 |
| `weighted_population_mean` | 总体分层 (80,均值4)、(20,均值9) → (320+180)/100=5。 | 层大小必须正；当均值来自随机抽样时这只是估计而非实际总体精确均值。 |
| `sample_variance_unbiased_2` | 数据 1,3：样本均值2，平方离差和2，分母 n−1=1，样本方差 2。 | 输入极大整数拒绝；不能把 2 与分母 n 的描述性方差 1 混用。 |
| `arithmetic_term` | 首项5，公差−2，第4项5+3(−2)=−1。 | 项数必须为正整数。 |
| `arithmetic_sum` | 首项3，公差2，前4项 3,5,7,9 → 24。 | 项数非法拒绝；若非等差，公式不适用。 |
| `geometric_sum` | 首项4、公比1、项数5，直接得到 20，**不除以1−q**。 | n=0 拒绝；有限和可以 q=1，不能误用无穷级数收敛标准。 |
| `complex_division` | (1+i)/(1−i)=i，精确实部0与虚部1，基于共轭和分母模平方2。 | 分母 0+0i 拒绝。 |
| `plane_normal_dot` | xy 平面两独立方向 (1,0,0)、(0,1,0)，w=(0,0,1) 同时正交；叉积非零保证两方向张成平面。 | 两方向平行使叉积为零时拒绝；垂直两条**平行**线不足以推线面垂直。 |
| `square_increase` | 0≤1<3，3²−1²=8>0，这是正半轴上 x² 严格递增的一个精确点对。 | 负区间、倒序、同点拒绝；有限两点不足以独立证明一般严格单调定理。 |

## 数学核验的三层边界

1. **内容数学陈述**：29 篇审核稿有必要条件、清晰表达、独立反例及分步依据；尚未进行完整专家/形式系统认证，状态始终 `NOT_FORMALLY_CERTIFIED`。
2. **程序数学检查**：17 算子使用有界整数与 `fractions.Fraction`，输入类型严格是 `int`（拒绝 `bool`、`float`、字符串、额外 JSON 字段和巨型数），返回 `FINITE_EXACT_CASE_ONLY`、`CONDITIONS_NOT_ESTABLISHED` 或 `UNSUPPORTED`。合法实例和前提破坏实例均在 CI，未声称自然语言推导全部正确。
3. **教学 Agent 审核和可见性**：29 篇单独存于教师审核隔离区；`student_retrieval_projection()` 中完整答案与学生文档都是空列表。没有教师正式审核签字，不能发布或悄悄进入权威检索索引。

## 来源与许可边界

讲义内容项目原创。每篇 `goal` 对应 Batch31/32 先前通过原始课标 PDF 初查而产生的**项目编辑候选目标**，有印刷页码、轨道、主题、原始 TSV SHA 和准确行号；**本批没有重新逐页独立核验原 PDF**，不应把内容归属的页码初查误读为正式官方逐条条款认证。没有提交版权教材原文、原课标 PDF 或真实学生数据。所有七个课程方向的正式原子总分母继续为 null。
