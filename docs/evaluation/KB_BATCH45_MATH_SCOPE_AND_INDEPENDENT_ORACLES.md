# Batch45｜数学前提、有限证据与独立回归边界

本批 24 篇原创教师审核稿来自项目内部课程编辑候选，不是 24 条官方认证的课程原子。全部状态为 REVIEW_PENDING / TEACHER_ONLY / NOT_FORMALLY_CERTIFIED，数学代码仅对有界特定实例给出结果；不能认证一般定理、学生自由推导、教师审查或学生发布。

## 数学对象与具体反例

**零点存在与二分法**：若实函数在 [a,b] 连续，且 f(a)f(b)<0，则至少有一个内部零点，不保证唯一。f(x)=x(x²−1) 在 [-2,3] 的端点异号，却有 -1、0、1 三个根。需要持续保持含根括区才能把 n 次二分后的区间宽度写成 (b-a)/2^n，其中点的最坏绝对误差不超过 (b-a)/2^(n+1)。受控验证器要求给出连续多项式系数和严格端点异号，不能据此认证学生随意生成的二分过程。

**三角恒等变换**：单位圆与正交旋转的点积给出 cos(a−b)=cos(a)cos(b)+sin(a)sin(b。正弦和角与二倍角来自余函数关系及代数代入。将 sin²t+cos²t=1 两边除以 cos²t，必须要求 cos t 非零；在 t=π/2 时原式有意义而 tan t 无定义。有限三角真值检查只针对 -720° 到 720° 的 90° 整数倍角，独立使用 SymPy 精确三角值交叉核对，并不证明所有实数角的定理。

**平面几何和向量**：二维基底唯一展开必须有非零行列式；三点唯一确定平面必须非共线；两点属于平面推出整个直线属于平面需两点不同；两个不同平面有交点时交集为直线，而重合平面交集仍是平面。测试通过叉积、点积和行列式有限穷举检查显式坐标，不能从图像外形自动断定这些假设成立。

**复数除法**：当且仅当 c²+d²>0 时允许除以 c+di；公式实部为 (ac+bd)/(c²+d²)，虚部为 (bc−ad)/(c²+d²)。分母实部 c=0 但 d 非零时仍可除。独立测试用精确 Fraction 对范围内除法结果反向相乘复原原分子。

**样本空间枚举条件与存在性表述修复**：原有限检查器把“每次二值”误当作“全部二进制序列都可能”，但完全相关的两次观测可以每次均出现两种取值，而联合样本空间只有 HH、TT。现在需要明确声明 `all_sequences_possible=true` 才返回 2^n，并且该声明只是前提、不构成真实实验支持性的认证。原检查结果 `ROOT_EXISTS_NOT_UNIQUE` 可能误导为“证明不唯一”，已改成 `ROOT_EXISTS_UNIQUENESS_UNDETERMINED`，对严格单调的 x−1 和有三根的 x(x²−1) 均只宣称存在、唯一性未判。新增相应负面回归。

**事件、概率和抽样**：互斥是交集为空，独立是 P(A∩B)=P(A)P(B)，正概率时二者不能兼得。古典概型不仅样本空间有限，还要求基本结果等可能；equally_likely 标记只是调用者的前提声明，不证明真实硬币/骰子公平。简单随机样本的每个无序组合概率 1/C(N,n) 同样以前提 uniform=True 为条件；不能替代实际随机化审计。分层比例分配 n×N_h/N 只有得到整数份额时才能直接输出人数；需取整但未指定整数化策略则显式拒绝。描述性方差用 n 作分母，不与 n−1 的无偏样本方差混为一谈。

**几何体和体积**：柱体与锥体需明确底面、侧面母线平行或汇聚及顶点关系；受控分类器不从底面形状单独推断整体几何体。柱体 Sh、锥体 Sh/3 要求真实底面积和垂直高，斜棱不等于垂高。算子仅作给定参数的有限精确值检查。

## 可执行证据和安全界限

backend/app/kb_batch45_exact.py 内 24 个命名算子各有合法实例、非法前提和结构字段负例。普通整数范围 [-100,100]，角度范围 [-720,720]，部分试验和数组更严格；范围外返回 CONDITIONS_NOT_ESTABLISHED 是能力边界，不表示数学上不成立。未知算子或自然语言证明返回 UNSUPPORTED。每次结果的 teacher_approved、student_publishable、general_theorem_certified、student_freeform_step_verified 均为 false。

独立回归包括 SymPy 三角精确值全组合、有限空间向量行列式穷举、3D 法向量正交性、复数除法反向验证、事件真值表、组合概率归一、分层样本量守恒、方差平移不变性、反例/缺失字段/伪造教师签字及实际应用 student_evidence_lookup 与 draft_next_question 的安全阻断。

## 本批实际失败与修复

首次 Batch45 专项测试为 411 passed / 4 failed。三项因为反例长度或错误原因不满足可审核质量门槛，现已补充具体数值与机制；第四项是测试**自身数学判断错误**：曾误认为 x(x²−1) 在 [-2,2] 两端不异号，其端值实际为 -6 和 +6。已改为 [-1,1]（两端都等于0）作严格异号失败案例，并保留 [-2,3] 多根但满足存在性条件案例。修复后重跑专项验收。

开发阶段还主动强化二分法必须具备多项式端点异号、随机组合抽取必须声明均匀性、几何类别必须显式给出侧面母线几何结构，并放宽符合明确数学界的 180°/270° 角输入，不再无故沿用窄整数范围。以上全是有限受控见证，而非一般证明的认证。
