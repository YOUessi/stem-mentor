## 1. 复合函数定义域：逆像条件

对应冲突ID: math.hs.function.composition-domain
候选/现行来源SHA: 0a9eba9335bd48642d1bee6df94f9e391060c06d6d6492b61dbf9100b5a6e8f9 / 8f4ca2c9ffe46431847027164f7eca2ecb203272cb3057f2e6eaedb3e4c3ab26
知识类型: THEOREM

### 数学前提
- g:D_g→ℝ、f:D_f→ℝ 均为确定的实值函数。
- 只讨论先计算 g(x)、后计算 f(g(x)) 的复合。

### 精确陈述
复合函数 f∘g 的定义域恰为 {x∈D_g | g(x)∈D_f}；不一定等于 D_f∩D_g。

### 逐步论证（待教师及独立数学审核）
1. 论断：若 (f∘g)(x) 有定义，则 x∈D_g。；依据：复合计算的第一步必须合法取得 g(x)。
2. 论断：若 (f∘g)(x) 有定义，则 g(x)∈D_f。；依据：第二步把 g(x) 代入 f 时必须位于 f 的定义域。
3. 论断：若上述两条件成立，则 f(g(x)) 有定义。；依据：两步求值顺序均已满足定义要求。
4. 论断：因此两条件共同刻画复合定义域。；依据：由必要性与充分性两方向合取，得到集合相等。

### 适用边界
只对定义确定的函数复合成立；不能因代数化简消去因子就补回原本未定义的点。

### 原创例题（教师侧解答）
令 f(t)=1/t（t≠0）、g(x)=x−2（x∈ℝ）。求 f∘g 的定义域。
教师解答：须同时有 x∈ℝ 与 x−2≠0，故 D=ℝ\{2}；x=3 时函数值为1。

### 错法与反例
误把 g 的定义域 ℝ 当作复合定义域，宣称 x=2 合法。
原因：g(2)=0 但 f(0) 未定义，代入第二层时出现零分母。

### 分层提示
- H1：先画出 f(g(x)) 的计算顺序。
- H2：把内层 g 的输出当作外层 f 的输入检查。
- H3：分别列出 x∈D_g 和 g(x)∈D_f，最后求交。

近迁移：改令 f(t)=√t、g(x)=x−5，写出 x≥5 的原因。
远迁移：把对数复合 ln((x−1)/(x+2)) 的分式分母与真数正值条件分别列出。

## 2. 奇偶函数：定义域对称与零函数边界

对应冲突ID: math.hs.function.parity
候选/现行来源SHA: dfbfc8ec6b1fb25484c4f6b5c49a56fd893a99559da77416a533d1f380b669c3 / 557000e248fa20439817d7c1f36d08490dfc57156a96ae40a2971bcf659e8575
知识类型: CONCEPT

### 数学前提
- 函数 f:D→ℝ 的自变量集合 D 非空。
- 谈论全域奇偶性时 D 必须关于原点对称，即 x∈D⇒−x∈D。

### 精确陈述
定义域关于0对称且 ∀x∈D，f(−x)=f(x) 时为偶函数；对称且 f(−x)=−f(x) 时为奇函数；在对称定义域上的零函数同时是奇函数和偶函数。

### 逐步论证（待教师及独立数学审核）
1. 论断：检查每个 x 对应的 −x 是否都在 D。；依据：没有对称定义域，f(−x) 不能对所有 x∈D 比较。
2. 论断：比较 f(−x) 与 f(x) 的恒等关系。；依据：全称量词必须覆盖定义域，而不是抽查一个数。
3. 论断：比较 f(−x) 与 −f(x)。；依据：奇函数判定与偶函数判定使用不同等式。
4. 论断：若两式同时成立，则所有 x∈D 上 f(x)=0。；依据：相减得到 2f(x)=0；零函数也直接满足两式。

### 适用边界
零函数在对称定义域上兼有奇偶性；若定义域不对称，不能只凭零值忽略定义域要求。

### 原创例题（教师侧解答）
在 D=ℝ 上判断 f(x)=x³。
教师解答：f(−x)=−x³=−f(x)，故它是奇函数；在 x=1 与 x=−1 的值分别为1和−1。

### 错法与反例
f(x)=x² 只在 D=[0,+∞) 定义，却直接判定偶函数。
原因：非零正 x 的 −x 不属于定义域；多项式表达式本身对称不能弥补受限定义域。

### 分层提示
- H1：先写出自变量定义域。
- H2：针对任意 x 测试 −x 是否也可取。
- H3：分别计算 f(−x)、f(x) 和 −f(x)。

近迁移：判断 f(x)=|x| 在 ℝ 和 [0,+∞) 上的奇偶性差别。
远迁移：分析 f(x)=1/(x−1) 的定义域是否允许奇偶性判定。

审核阻断：10组历史冲突仍未裁决，本条不可自动批准或发布学生端。

## 3. 分段函数边界：唯一性与覆盖

对应冲突ID: math.hs.function.piecewise
候选/现行来源SHA: b7cd6eeb5feaeca859c90061d20359b23d3c76edf2b89ab1df599a1a2f1f1116 / d2398e513adc2e80ef2de3fdf604960c48f90907d50e1cc44354008b1a5fe30c
知识类型: CONCEPT

### 数学前提
- 给定各分支定义区域 D_i 和对应规则 f_i。
- 在每一 x 上至少存在一个适用分支；若多个分支同时适用，给出的函数值必须一致。

### 精确陈述
分段表达定义函数的充要条件是对每个定义域内 x 至少有一适用分支且所有适用分支输出一致；分支两两不交并覆盖定义域只是充分条件而非必要条件。

### 逐步论证（待教师及独立数学审核）
1. 论断：固定任意 x，检查是否至少匹配一个分支。；依据：一个定义域内输入没有分支值就不是完整的函数定义。
2. 论断：若同一 x 匹配多个分支，比较其输出是否相等。；依据：函数必须对每个输入唯一确定输出。
3. 论断：若每个 x 都有且只有一个一致输出，则规则定义函数。；依据：由函数唯一对应的定义可直接构造映射。
4. 论断：两两不交是方便的充分条件，但不是必要条件。；依据：重叠分支若在交集上给出同一数，仍唯一决定输出。

### 适用边界
重叠分支相同输出可以仍是函数；不应机械宣称一切分支交叠都无效。

### 原创例题（教师侧解答）
f(x)=x² (x<0)，f(x)=x+1 (x≥0)，求 f(0)。
教师解答：在 x=0 只有第二分支适用，f(0)=1，且全实数区间被覆盖。

### 错法与反例
写 f(x)=x² (x≤0)，f(x)=x+1 (x≥0)，并称之为良定义函数。
原因：x=0 被两个分支覆盖，分别输出0和1，违反唯一性。

### 分层提示
- H1：在数轴上标注每一分支覆盖区域。
- H2：检查边界点是否遗漏或重叠。
- H3：若重叠，代入所有适用表达式检验值是否相等。

近迁移：把分界点写作 x≤2 与 x>2，检查是否覆盖所有实数。
远迁移：核验一个带有三个类别的阶梯定价规则是否在每个阈值唯一计价。

审核阻断：10组历史冲突仍未裁决，本条不可自动批准或发布学生端。

## 4. 介值定理零点存在：条件与唯一性区分

对应冲突ID: math.hs.function.zero-ivt
候选/现行来源SHA: 5b2775f2eac0269a11e2bfe96e6b3e729d31978a2800d79f9299f473082e472e / a711b76c4db2777645835732e23494aa378ed3a123ea1b8cc86d96dd7a3e247c
知识类型: THEOREM

### 数学前提
- 实函数 f 在闭区间 [a,b] 连续，a<b。
- 端点满足 f(a)f(b)<0。

### 精确陈述
存在 c∈(a,b) 使 f(c)=0；结论只有存在性，不保证零点唯一；端点异号是充分条件而非必要条件。

### 逐步论证（待教师及独立数学审核）
1. 论断：由端点乘积为负，f(a) 与 f(b) 异号。；依据：积为负且为实数意味着两端不为0并异号。
2. 论断：数值0严格位于 f(a)、f(b) 之间。；依据：异号实数夹住0。
3. 论断：应用闭区间连续函数的介值性质。；依据：连续映射取遍端点函数值之间的每个中间值。
4. 论断：因端点函数值均不为0，可取 c∈(a,b)。；依据：零点不能落在任一端点；唯一性未由上述步骤推出。

### 适用边界
单调性等额外条件才可能保证唯一；端点同号也可能存在偶重零点或两个零点。

### 原创例题（教师侧解答）
f(x)=x³−x 在 [−2,2] 连续，端点值−6和6异号。
教师解答：由介值定理至少有一零点；实际上−1、0、1都是零点，说明不保证唯一。

### 错法与反例
将 f(x)=−1(x<0)、f(x)=1(x≥0) 在 [−1,1] 端点异号，就宣称存在零点。
原因：f 在0不连续，且对全区间取值仅−1、1，没有零点。

### 分层提示
- H1：先检查 f 在整个闭区间连续。
- H2：计算两个端点函数值并比较符号。
- H3：区分“至少一个”和“恰好一个”的结论强度。

近迁移：f(x)=x²−1 在 [0,2] 上判定存在零点。
远迁移：设计满足端点同号却在区间内部有两个零点的连续函数。

审核阻断：10组历史冲突仍未裁决，本条不可自动批准或发布学生端。

## 5. 点到直线距离公式：非零法向量

对应冲突ID: math.hs.geometry.point-line-distance
候选/现行来源SHA: fe6966d4605d4097363eb1a7ad94d3c8a156d11177fecbaf4a1e411818be8b47 / dac0d1540d6b01096ffa722c34f4c548181d6f02d8de3d3c2117981beda5838e
知识类型: THEOREM

### 数学前提
- 平面直线 L: Ax+By+C=0，其中 (A,B)≠(0,0)。
- 点 P=(x₀,y₀) 及系数为实数，使用欧氏距离。

### 精确陈述
d(P,L)=|Ax₀+By₀+C|/√(A²+B²)。

### 逐步论证（待教师及独立数学审核）
1. 论断：直线法向量 n=(A,B) 非零，长度为 √(A²+B²)。；依据：直线方程的系数构成法向量，假设确保长度正。
2. 论断：取 L 上任一点 Q，存在且有 n·Q+C=0。；依据：非零法向量的线性方程总表示一条非空直线。
3. 论断：(P−Q) 在法向量方向的投影绝对值为 |n·(P−Q)|/‖n‖。；依据：内积投影与勾股定理说明法向投影是最短距离。
4. 论断：代入 n·Q=−C 得出公式。；依据：n·(P−Q)=Ax₀+By₀+C，且分母严格大于0。

### 适用边界
(A,B)=(0,0) 时不是有效直线；同乘非零系数后距离不变。

### 原创例题（教师侧解答）
P=(0,0)，L:3x+4y−10=0，求距离。
教师解答：代入直线系数得 d=abs(−10)/sqrt(3²+4²)=10/5=2；法向量非零。

### 错法与反例
把 0x+0y+1=0 当作直线并套公式。
原因：它没有任何点满足方程且分母为0，不是欧氏平面直线。

### 分层提示
- H1：找到方程的法向量。
- H2：核对法向量是否非零。
- H3：用法向投影长度推导距离表达式。

近迁移：求 P=(1,2) 到 x=−2 的距离并与坐标直觉比对。
远迁移：分析直线方程全部系数同乘−7时距离为何不变。

## 6. 二项分布：独立同分布与端点概率

对应冲突ID: math.hs.probability.binomial-distribution
候选/现行来源SHA: 2f19452fc3bfb0c0f595365e7c2b1580c9e7b0b242a6f07df9d866a5e494d0d0 / 699a78f5f5518ded8f9277535f670acb28a4cfd15bbddc20930a0d014276e3ae
知识类型: THEOREM

### 数学前提
- n 为非负整数，X 是 n 次相互独立试验中成功次数。
- 各次试验成功概率均为 p∈[0,1]，失败概率1−p。
- k 为整数且 0≤k≤n。

### 精确陈述
P(X=k)=C(n,k)p^k(1−p)^(n−k)，端点 p=0 或1按直接事件概率解释；独立性不能省略。

### 逐步论证（待教师及独立数学审核）
1. 论断：固定恰有 k 次成功的具体位置组合。；依据：有 C(n,k) 种不同的成功位置集合。
2. 论断：任一指定组合的联合概率为 p^k(1−p)^(n−k)。；依据：不同次试验相互独立且成功率相同。
3. 论断：不同成功位置组合对应互斥事件。；依据：每组样本序列有唯一成功位置集合。
4. 论断：由互斥加法法则求和得到二项分布概率。；依据：相同概率乘以组合数；p=0或1可通过直接计数避免形式0^0歧义。

### 适用边界
n≥0为整数、p在[0,1]；k越界时概率0；p=0或1应直接处理退化分布。

### 原创例题（教师侧解答）
n=3、p=1/2，求恰好2次成功概率。
教师解答：C(3,2)×(1/2)²×(1/2)=3/8；概率在[0,1]。

### 错法与反例
两次完全相关的伯努利试验 X₁=X₂，均有成功率1/2，却用二项式算 P(X=1)=1/2。
原因：实际两次要么全成功要么全失败，P(X=1)=0，独立性假设不成立。

### 分层提示
- H1：先确认每次成功率是否一致。
- H2：检查各次试验是否相互独立。
- H3：把恰有 k 次成功拆成位置组合求和。

近迁移：n=4、p=1/4，计算 P(X=0) 并说明零次成功事件。
远迁移：比较同样成功率但完全相关和真正独立的两个试验系统。

审核阻断：10组历史冲突仍未裁决，本条不可自动批准或发布学生端。

## 7. 超几何分布：无放回与合法支持集

对应冲突ID: math.hs.probability.hypergeometric
候选/现行来源SHA: 32e19775af8d600e9ed132c6154a1fbc871fd014fa229fbff8a3ab43415347f6 / 8b241b93c47cef3f88d5e601c6e5481b1168c57cd5cebadb915f8f1d4b81a69a
知识类型: THEOREM

### 数学前提
- 总体 N∈ℕ_{>0}，其中成功项 K 满足0≤K≤N。
- 不放回等可能选取大小 n 的子集，0≤n≤N。

### 精确陈述
k 的有效范围为 max(0,n−(N−K))≤k≤min(n,K) 且为整数；P(X=k)=C(K,k)C(N−K,n−k)/C(N,n)。

### 逐步论证（待教师及独立数学审核）
1. 论断：可行的成功数不得超过已选数n或成功库存K。；依据：故 k≤min(n,K)。
2. 论断：失败选取数 n−k 不得超过失败库存 N−K，且非负。；依据：得 k≥n−(N−K) 以及 k≥0。
3. 论断：恰取 k 个成功和 n−k 个失败的子集数量为 C(K,k)C(N−K,n−k)。；依据：两个类别中的选择组合独立计数。
4. 论断：所有 n 元子集等可能且共有 C(N,n) 个。；依据：按古典概型的有利数除总数，得到分布公式。

### 适用边界
要求样本空间为等可能n元子集；N=0须单独定义退化抽样而不能沿用分母C(N,n)。

### 原创例题（教师侧解答）
N=4、K=2、n=2，不放回抽两项均成功概率。
教师解答：有利子集 C(2,2)C(2,0)=1，总数C(4,2)=6，故概率1/6。

### 错法与反例
上述模型改为有放回抽取，却仍声称两次成功概率1/6。
原因：有放回且每次独立成功率1/2，概率为1/4，模型已改变。

### 分层提示
- H1：区分有放回与不放回。
- H2：检查 K、n、N 的整数约束及 k 的可能区间。
- H3：分别计算成功项组合数、失败项组合数与全部子集数。

近迁移：N=7、K=3、n=2，计算一次成功的概率。
远迁移：比较不放回超几何与有放回二项分布在大总体近似中的适用条件。

## 8. 相关系数与最小二乘斜率：零方差边界

2. 论断：对 a 求偏导令零，得到 a=ȳ−b x̄。；依据：所有残差求和为零对应过样本中心。
3. 论断：代入一阶条件对 b 求导，得到 b Sxx=Sxy。；依据：正规方程展开并中心化后得到该式。
4. 论断：Sxx>0 保证斜率唯一；r 还需 Syy>0。；依据：正的平方和可以作除数；若 Sxx=0 则斜率不唯一。

### 适用边界

教师解答：x̄=1、ȳ=3、Sxy=4、Sxx=2，故 b=2、a=1，拟合直线ŷ=1+2x。

## 9. 三角形面积：两边夹角的正弦

对应冲突ID: math.hs.triangle.area-sine
候选/现行来源SHA: 65f0f943e5c9568894a150f757a9065920564f6e019e60f84112394c77633007 / feca569a56b1d149b0e6bb391b9dfd6af6e6d96b32cb64bac55da5b2256fc360

### 数学前提
- 非退化平面三角形的两边长度 a>0、b>0。
- θ 是这两边真正的夹角，0<θ<π。

### 精确陈述
三角形面积 S=(1/2)ab sinθ；不可以把 θ 任意替换成某个非夹角。

### 逐步论证（待教师及独立数学审核）
1. 论断：取长为 a 的边为底。；依据：平面三角形面积等于底乘高的一半。
2. 论断：另一边长 b 与底的夹角为 θ，其到直线的高度为 b sinθ。；依据：在 0<θ<π 中 sinθ>0，垂直投影长度等于b sinθ。
3. 论断：代入底高面积得 S=(1/2)a·b sinθ。；依据：几何面积关系直接推出。
4. 论断：非夹角或退化角不得无条件套用。；依据：对应高度不同；sin0=0 或 sinπ=0 是退化而非非退化三角形。

### 适用边界
在退化θ∈{0,π}时表达式形式上为0，但不再是非退化三角形；θ必须是所用两边的夹角。

### 原创例题（教师侧解答）
直角三角形两条直角边3、4，夹角π/2，求面积。
教师解答：S=(1/2)×3×4×sin(π/2)=6。

### 错法与反例
3-4-5三角形取两边3和4却用与边3相对的角代替夹角。
原因：该角的sin为3/5，错误得到(1/2)×3×4×3/5=18/5，不等于实际6。

### 分层提示
- H1：先标出被选的两条边。
- H2：确认所给角是它们的公共夹角。
- H3：通过底×高/2把高度写为另一边×sin夹角。

近迁移：两边长分别为5和6，夹角为30°，计算三角形面积并说明角的位置。
远迁移：已知三边3、4、5，先由余弦定理求相邻夹角再求面积。

## 10. 向量线性运算：维度一致与结构不混淆

对应冲突ID: math.hs.vector.linear-operations
候选/现行来源SHA: a8977ba555d84ed6fd84d7ce38b0e8834d8386b13cc42a93d17b940d4d397fc1 / ce4d8f75e4ccb20a695f299c041b2ec84157a885466fbc70b5dbe90e253923e6
知识类型: THEOREM

### 数学前提
- u,v∈ℝ^n 且 n 是固定正整数。
- a,b∈ℝ，运算按坐标分量定义。

### 精确陈述
(u+v)_i=u_i+v_i，(au)_i=a u_i；同维线性运算在 ℝ^n 中封闭，并满足 a(u+v)=au+av；概念定义与分配律定理不能视为同一类证明任务。

### 逐步论证（待教师及独立数学审核）
1. 论断：按坐标定义 u+v 与 au。；依据：对每一 i 都存在相应实数分量。
2. 论断：同维相加和数乘每个分量仍为实数。；依据：由实数运算封闭性得到结果仍属于ℝ^n。
3. 论断：对任意 i，(a(u+v))_i=a(u_i+v_i)。；依据：展开线性运算的坐标定义。
4. 论断：由实数分配律，该分量等于a u_i+a v_i。；依据：每一坐标相等说明向量相等；概念规则不同于这个性质的证明。

### 适用边界
同维是加法与分配律的前提；不同维向量须先给出明确空间映射，不能默认缺省分量为零。

### 原创例题（教师侧解答）
u=(1,2)、v=(−3,4)、a=2，检查分配律。
教师解答：a(u+v)=2(−2,6)=(−4,12)，au+av=(2,4)+(−6,8)=(−4,12)。

### 错法与反例
把 u=(1,2) 与 v=(3,4,5) 逐分量相加成所谓(4,6,5)。
原因：两个向量处于不同的ℝ^n，没有给定嵌入映射时常规加法未定义。

### 分层提示
- H1：先写明向量属于哪个 ℝ^n。
- H2：核对两向量有相同坐标数。
- H3：逐分量展开左式、右式再比较相等。

近迁移：证明在ℝ³中 3(u−v)=3u−3v。
远迁移：讨论同一几何向量在两种坐标基底下表示为何变化，运算规律为何不变。
