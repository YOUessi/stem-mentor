## KB125-CONFLICT-01 · 复合定义域并非两个原定义域的简单交集
- 历史冲突ID: `math.hs.function.composition-domain`
- 适用条件: 先确定内层输出是否落入外层定义域；对有分母的外层函数检查非零。
- 错误/反例解释: 当内层输出为0时，外层倒数在该点不存在；不能因内层在实数域定义便放行。
- 远迁移教学问题: 将复合表达改为根号或对数时，逐层生成非负或严格正值条件。
- 核验范围: 1组合法例 + 1组无效前提精确见证；不认证整体推理；REVIEW_PENDING。

## KB125-CONFLICT-02 · 定义域对称是全域奇偶性不可省的前提
- 历史冲突ID: `math.hs.function.parity`
- 适用条件: 检验每个输入的负数也在定义域，然后才判断等式；零函数是奇偶兼有的边界。
- 错误/反例解释: 仅在非负半轴上给出的x²不能直接称为全域偶函数。
- 远迁移教学问题: 把定义域换成不对称的有限集合，观察代数相等如何不足以成立。
- 核验范围: 1组合法例 + 1组无效前提精确见证；不认证整体推理；REVIEW_PENDING。

## KB125-CONFLICT-03 · 分段规则覆盖后还需要重叠区输出一致
- 历史冲突ID: `math.hs.function.piecewise`
- 适用条件: 对每个定义域输入，至少有一条分支适用；重叠区的函数值必须相同。
- 错误/反例解释: 在x=0两个分支分别输出0和1，故不是单值函数。
- 远迁移教学问题: 为同一个输入添加第三条分支，检验三者是否同时一致。
- 核验范围: 1组合法例 + 1组无效前提精确见证；不认证整体推理；REVIEW_PENDING。

## KB125-CONFLICT-04 · 介值定理需要连续性且只保证存在
- 历史冲突ID: `math.hs.function.zero-ivt`
- 适用条件: 核对闭区间连续和端点异号；得出有根后不得推断唯一性。
- 错误/反例解释: 跳跃函数可两端异号但全区间没有零点；三次连续函数可有多个零点。
- 远迁移教学问题: 比较二分法的存在性前提与单调性提供的唯一性前提。
- 核验范围: 1组合法例 + 1组无效前提精确见证；不认证整体推理；REVIEW_PENDING。

## KB125-CONFLICT-05 · 点到直线距离公式分母不能是零
- 历史冲突ID: `math.hs.geometry.point-line-distance`
- 适用条件: 把Ax+By+C=0视为直线前，必须满足法向量(A,B)不为零。
- 错误/反例解释: 若A=B=0且C不等于零，得到的是空集而非直线，距离表达式分母为零。
- 远迁移教学问题: 同时比较零法向量且C=0时方程代表整个平面而非一条线。
- 核验范围: 1组合法例 + 1组无效前提精确见证；不认证整体推理；REVIEW_PENDING。

## KB125-CONFLICT-06 · 二项式分布需独立且同一成功率
- 历史冲突ID: `math.hs.probability.binomial-distribution`
- 适用条件: 先核对每次伯努利试验相互独立、成功率一致，才使用组合计数。
- 错误/反例解释: 两次成功指示完全相同时，不可能恰好成功一次，即使各自边际都是一半。
- 远迁移教学问题: 保持边际概率不变而改变联合相关结构，比较成功次数分布。
- 核验范围: 1组合法例 + 1组无效前提精确见证；不认证整体推理；REVIEW_PENDING。

## KB125-CONFLICT-07 · 超几何分布要求无放回与有效支持集
- 历史冲突ID: `math.hs.probability.hypergeometric`
- 适用条件: 从有限总体无放回等可能抽取固定数量，检查样本数和成功数的整数边界。
- 错误/反例解释: 放回抽样会改变成功概率且不满足固定子集等可能模型。
- 远迁移教学问题: 使用总体较小且成功项较少的例子列举组合数与支持集。
- 核验范围: 1组合法例 + 1组无效前提精确见证；不认证整体推理；REVIEW_PENDING。

## KB125-CONFLICT-08 · 最小二乘斜率与相关系数有不同非零条件
- 历史冲突ID: `math.hs.statistics.correlation-regression`
- 适用条件: 斜率需要Sxx>0，Pearson相关还要Syy>0；二者都不能用关联代替因果。
- 错误/反例解释: 所有x相同时斜率分母为零；误把无法辨识写成斜率0不合法。
- 远迁移教学问题: 保留相同x数据但替换y，检验最小二乘常数拟合与斜率不唯一。
- 核验范围: 1组合法例 + 1组无效前提精确见证；不认证整体推理；REVIEW_PENDING。

## KB125-CONFLICT-09 · 三角形正弦面积公式要求两边真正夹角
- 历史冲突ID: `math.hs.triangle.area-sine`
- 适用条件: S=ab sinθ/2中的θ必须是所选a、b的夹角，长度均为正。
- 错误/反例解释: 直角三角形的边3和4夹角是直角，错取边3的对角会给出不同面积。
- 远迁移教学问题: 同一三角形换用另一对边时，重新识别两边夹角。
- 核验范围: 1组合法例 + 1组无效前提精确见证；不认证整体推理；REVIEW_PENDING。

## KB125-CONFLICT-10 · 向量运算必须位于同一向量空间
- 历史冲突ID: `math.hs.vector.linear-operations`
- 适用条件: 逐坐标线性运算需要相同维数；叉积更有专门的三维约定。

- 核验范围: 1组合法例 + 1组无效前提精确见证；不认证整体推理；REVIEW_PENDING。
