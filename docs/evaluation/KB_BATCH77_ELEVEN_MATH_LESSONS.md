## KB77-M01｜量词命题的否定、论域及反例构造
来源：KB75-P016-S03｜COMPULSORY｜ad188e8982a4291db7aabcdd84f9929db9d0c41f647325e5738021f02a2f133a
定义：在非空论域D中，¬(∀x∈D,P(x))当且仅当∃x∈D,¬P(x)；¬(∃x∈D,P(x))当且仅当∀x∈D,¬P(x)。
前提：论域和谓词P在前后两句完全相同；采用经典二值逻辑
结论：否定量词须交换∀和∃并否定其内部谓词，不可只改不等式符号。
逐步推理（待教师核对）：
1. 否定全称：∀x P(x)失败意味着至少存在一个x使P(x)不成立。
2. 否定存在：∃x P(x)失败意味着没有任何x满足P；故每一个x都满足¬P。
3. 保留论域：对实数论域的命题不能在取反时悄悄改成整数论域。
4. 给出反例：∀x∈R,x²>0为假：x=0；其否定∃x∈R,x²≤0为真。
失效前提：空论域也有相应的标准逻辑语义，但本教学例按非空实数域；不把逆否命题与量词否定混同。
反例：错误否定‘所有实数平方都严格正’为‘所有实数平方均非正’；x=1即可否定后者。
典型错因：只把x²>0改成x²≤0却保留∀，产生比真实否定更强的命题。
原创教师侧例题：
- 在全体实数论域内，否定∀x∈R,x²>0。 → ∃x∈R,x²≤0；可取x=0成立。
- 在整数论域内，否定命题∃n∈Z,n²<0。 → ∀n∈Z,n²≥0；整数平方均非负，因而该否定为真。
三级提示：找出最外层是∀还是∃。 → 换成另一种量词但保持D。 → 只在内部P(x)上取逻辑否定，给出见证或证明。
近迁移：否定∀n∈N,n≥5并给出一个违例。
远迁移：用软件断言的‘所有输入通过’和存在失败样本的关系作类比。

## KB77-M02｜复平面关于虚轴的反射与乘i
来源：KB75-P027-S01｜COMPULSORY｜44374aeff9c4681121bf16e2ce7279cf8300d9a8f5167edf8ad153d1915f52a6
定义：复数z=x+yi对应点(x,y)，关于虚轴反射得到(-x,y)，对应w=-共轭(z)；乘i得到(-y,x)，一般是逆时针90°旋转而非反射。
前提：使用标准复平面坐标与通常复数乘法；反射轴是虚轴即x=0
结论：虚轴反射由z↦-共轭(z)给出；z↦iz通常不是同一个映射。
逐步推理（待教师核对）：
1. 确定几何点：z的实部与虚部分别给出横纵坐标。
2. 执行反射：虚轴反射改变横坐标符号而保持纵坐标不变。
3. 改写复数：(-x)+yi=-(x-yi)=-共轭(z)。
4. 比较乘法：i(x+yi)=-y+xi；取z=1两者分别为-1与i。
失效前提：原点在两种映射下均不变；不能以一个固定点为证据宣布两变换相等。
反例：z=1时关于虚轴反射为-1，乘i为i，结果不同。
典型错因：把复数乘i一律解释为关于虚轴对称，混淆旋转与反射。
原创教师侧例题：
- z=2+3i关于虚轴反射的对应复数。 → 坐标(2,3)变(-2,3)，故为-2+3i。
- z=1+i乘i后与反射后分别是什么？ → iz=-1+i；-共轭(z)=-1+i，此特例恰好相同，不可推广到所有z。
三级提示：先画出对应的复平面坐标点与作为反射轴的虚轴。 → 核对关于虚轴反射只改变实部的符号、保持虚部不变。 → 再单独乘i对照，检查是否为同一变换。
近迁移：写出关于实轴反射的复数公式并比较。
远迁移：用图像处理中水平翻转和图像旋转区别两种变换。

## KB77-M03｜相关系数与样本均值的区别
来源：KB75-P046-S04｜SELECTIVE_COMPULSORY｜274b06eb4b2933426d3c4a9ab7eb27210c408f81ee0993754b2dcf28bbfa7d1d
定义：对非零方差的成对数值样本，皮尔逊样本相关系数r=Σ(xi-x̄)(yi-ȳ)/sqrt(Σ(xi-x̄)²Σ(yi-ȳ)²)，衡量样本线性关联而非均值。
前提：样本成对观测且n≥2；两变量中心化平方和均严格正
结论：即使两组样本具有完全相同的各变量均值，相关方向也可以相反。
逐步推理（待教师核对）：
1. 建立两组数据：固定x=(0,1,2),令y+=(0,1,2)，另令y-=(2,1,0)。
2. 检查均值：两组的x均值均为1，y均值也均为1。
3. 计算协同变化：逐对求差并相乘后求和，两组中心化乘积和分别是2和-2。
4. 归一化：两组平方偏差和均为2，因而r+=1,r-=-1。
失效前提：方差为零使分母为0；样本相关只能描述这组配对观测。
反例：两组样本各自变量均值相同，但一个r=+1另一个r=-1。
典型错因：通过x和y各自平均数相同来推断二者独立或正相关。
原创教师侧例题：
- x=(0,1,2),y=(2,1,0)，r是多少？ → 中心积和-2，两个偏差平方和都是2，r=-1。
- x=(0,1,2),y=(0,2,4)，r是多少？ → y与x严格正线性，中心化乘积和4，平方和2和8，r=1。
三级提示：先检查成对样本与非零方差。 → 分别计算x与y的样本均值，并对成对数据中心化。 → 比较协同方向并计算归一化值。
近迁移：给相同边际频数重新配对，讨论相关系数为何变化。
远迁移：讨论消费数据中同时受季节影响的两个指标为何不能直接认定因果。

## KB77-M04｜已知总体方差的单样本Z统计量与模型前提
来源：KB75-P056-S04｜ELECTIVE_A｜5a3d09189cb5588723e47d169ecc84160cc1433a2e4b6daa0f4588e000e42289
定义：在独立同分布的正态样本且已知总体标准差σ>0条件下，检验均值μ=μ0可用Z=(x̄-μ0)/(σ/√n)；零假设下Z服从标准正态分布。
前提：样本独立来自同一正态总体；σ为已知正值，n≥1，检验不依赖因果解释
结论：四个样本(1,1,3,3)的均值为2，μ0=1且σ=2时Z=1；统计量的计算不等于直接拒绝原假设。
逐步推理（待教师核对）：
1. 求样本均值：样本合计8,样本容量4,均值为2。
2. 求标准误：σ/√n=2/2=1，而非σ本身。
3. 计算统计量：(2-1)/1=1，此计算不自动给出决策。
4. 区分推断：假设检验结论还依赖显著性水平、单双侧备择与模型条件。
失效前提：若σ未知不能直接套已知总体方差的Z模型；样本不独立或非正态时需重新审查方法适用性。
反例：把总体标准差σ=2误当标准误，会错误算Z=1/2。
典型错因：未设置显著性水平就凭Z的符号宣称原假设必被拒绝。
原创教师侧例题：
- n=4,x=(1,1,3,3),μ0=1,σ=2计算Z。 → 样本均值x̄=2，已知σ=2且n=4所以标准误=1，统计量Z=1。
- 改为μ0=2,其他保持不变，Z是多少？ → x̄=2，故分子0，Z=0；这只是统计量而非结论。
三级提示：确定已知还是未知总体方差。 → 分别计算样本平均值以及已知总体方差条件下的均值标准误。 → 再列明原假设、备择假设及决策规则。
近迁移：对比未知σ时t检验的额外假设。
远迁移：在质量控制中区分统计显著与实际重要性。

## KB77-M05｜一元导数与定积分不能混同
来源：KB75-P058-S03｜ELECTIVE_B｜e6f12d7719a399df309ecbec935c4a83b07ba6aa67e2426062cfc9491dff66f2
定义：若f在点x0可导，f'(x0)是差商的极限；若f在[a,b]可积，∫_a^b f(x)dx是有向面积型累积量。两者运算对象及前提不同。
前提：本例f是全实数上的多项式；被积区间闭且有界，计算采用通常黎曼积分
结论：f=x³在x=2导数为12，而区间[0,2]的定积分为4；不能交换两种运算。
逐步推理（待教师核对）：
1. 导数定义：由((x+h)³-x³)/h=3x²+3xh+h²，h趋零得3x²。
2. 代入点值：f'(2)=3×4=12，是指定点的局部变化率。
3. 找原函数：F(x)=x⁴/4满足F'=x³。
4. 算积分：F(2)-F(0)=16/4=4，量化区间累积量。
失效前提：不可从f在某点可导推断任意区间的原函数表达式；不连续等特殊情形要重新核对积分存在条件。
反例：同一多项式在点2的导数12，与区间[0,2]积分4不相等。
典型错因：把f'(2)代入积分的计算结果或以面积公式当点变化率。
原创教师侧例题：
- 给定多项式函数f(x)=x³，求其在x=1处的导数f'(1)。 → 对x³求导得到3x²，再代入x=1得到该点导数为3。
- f=x³，求∫_0^1 f(x)dx。 → 原函数x⁴/4，代端点得1/4，与导数值3不同。
三级提示：先识别题目要求点处变化率还是区间累积。 → 导数用差商，积分用原函数端点差。 → 比较结果量纲并核查积分区间。
近迁移：证明常数函数导数为0却在非零长度区间有非零积分。
远迁移：比较速度瞬时值与路程累积量。

## KB77-M06｜矩形线性系统满列秩与唯一解条件
来源：KB75-P060-S03｜ELECTIVE_B｜b404a57404dc74de0a40ba0552db3d653f709c004b155e78335e0ddb087dbf1f
定义：A为m×n实矩阵。若Ax=b有解且rank(A)=n，则解唯一；若rank(A)<n且有解，则解不唯一。
前提：明确m,n为正整数，b属于A的列空间才保证存在解；判断唯一性时不能把满列秩错当自动保证存在性
结论：A=((1,0),(0,1),(1,1))为3×2矩阵，b=(2,3,5)时唯一解为(2,3)。
逐步推理（待教师核对）：
1. 建立差方程：若x,y均满足Ax=b，则A(x-y)=0。
2. 利用满列秩：rank(A)=n时零空间只有零向量，故x-y=0。
3. 反向讨论：rank(A)<n则存在v≠0且Av=0，任一解x使x+v也是解。
4. 检查存在条件：对示例，第三行方程恰与前两行一致；若b3≠b1+b2，虽然满列秩却无解。
失效前提：满列秩不能保证每个b都可解，除非进一步满足相容性（或是方阵可逆）。
反例：将b改成(2,3,6)，同一满列秩矩阵无解：前两式强制x=2,y=3而第三式要求x+y=6。
典型错因：对3×2矩阵强行取行列式，或仅凭rank(A)=n宣布任何b都有唯一解。
原创教师侧例题：
- A三行分别(1,0),(0,1),(1,1)，b=(2,3,5)，求解。 → 前两行得x=2,y=3，第三行2+3=5，故唯一。
- 把b第三分量改成6，有解吗？ → 前两行仍强制(2,3)，第三行不成立，所以无解，不可因满列秩称有唯一解。
三级提示：先明确系数矩阵的行数和列数，不能直接对非方阵求行列式。 → 检查是否存在满足所有行的解。 → 最后用零空间判断该解是否唯一。
近迁移：比较欠定系统m<n为什么不能满列秩。
远迁移：用超定传感器标定说明‘可辨识’与‘数据一致’是两件事。

## KB77-M07｜二维连续联合密度与矩形区域概率
来源：KB75-P061-S02｜ELECTIVE_B｜6546d23ce038e26ff8f2efb3aa739f8229b5f7afe120e0354ffea67d294b3cc2
定义：非负函数f(x,y)若在R²的二重积分为1，是二维连续随机向量的联合密度；P((X,Y)∈R)=∬_R f(x,y)dxdy。
前提：本例支撑是单位正方形，区间端点在[0,1]；联合密度非负并且总积分为1
结论：f(x,y)=4xy于单位正方形满足归一且对应独立的边缘密度2x、2y；左下1/2正方形概率1/16。
逐步推理（待教师核对）：
1. 归一化：∫_0^1∫_0^1 4xy dydx=(2∫_0^1 xdx)²=1。
2. 计算边缘：固定x对y积分得2x，固定y对x积分得2y。
3. 判断独立：本例f(x,y)=f_X(x)f_Y(y)几乎处处成立，故X,Y独立。
4. 算矩形概率：∫_0^(1/2)∫_0^(1/2)4xy dydx=(1/2)²(1/2)²=1/16。
失效前提：若联合密度不归一或负值出现则不是合法密度；不允许将离散概率表直接当连续密度。
反例：只给边缘f_X=f_Y=1不能唯一确定联合依赖结构；同边缘可有不同联合分布。
典型错因：把f(1/2,1/2)=1说成该点概率为1，或不核对独立就乘边缘区间概率。
原创教师侧例题：
- 求本例P(X≤1/2,Y≤1/2)。 → 矩形二重积分为(1/4)(1/4)=1/16。
- 在给定二维联合密度模型下，求边缘概率P(X≤1/2)。 → 对y积分先得边缘f_X=2x，再积到1/2得到1/4。
三级提示：先验证非负和总积分为1。 → 画出联合密度支撑和目标矩形区域，明确两个积分上下限。 → 必要时先求边缘并核对独立性。
近迁移：把密度换成4(1-x)(1-y)后重新求矩形概率。
远迁移：在位置传感器二维误差模型中区分独立与相关噪声。

## KB77-M08｜K均值聚类的平方误差目标与因果边界
来源：KB75-P061-S04｜ELECTIVE_B｜6546d23ce038e26ff8f2efb3aa739f8229b5f7afe120e0354ffea67d294b3cc2
定义：给定有限二维点集和固定K个非空簇，K均值的簇内平方误差SSE=Σ_kΣ_{i∈Ck}||xi-μk||²，其中μk是该簇样本均值。
前提：K为介于1和样本数之间的正整数；每个样本恰属于一个非空簇，点有一致的量纲和特征尺度
结论：四点(0,0),(0,1),(10,10),(10,11)划为前后两簇时中心分别(0,1/2),(10,21/2)，SSE=1。
逐步推理（待教师核对）：
1. 计算各中心：两个簇的第一坐标均恒定，第二坐标分别是0,1与10,11的均值。
2. 计算每点残差：同一簇两个点到中心的平方距离各为1/4。
3. 累计目标：四个残差平方相加得到SSE=1，越小代表该划分簇内紧密。
4. 说明解释边界：优化几何分组目标并不建立分组原因或因果效应。
失效前提：K>样本数时不可能分为K个非空簇；两类标签本身不能推出自变量导致结果。
反例：把高身高簇的成绩较高直接推断身高导致成绩较好，缺乏干预或识别条件。
典型错因：直接用簇编号作为处理组随机分配结果，或忽略样本量纲。
原创教师侧例题：
- 计算(0,0),(0,1)的中心和SSE。 → 中心(0,1/2)，两点平方偏差各1/4，故SSE=1/2。
- 四点两两聚成两组时总SSE是多少？ → 两组各为1/2，总计1；这只评价给定划分，不证明全局最优。
三级提示：先确认二维特征的计量单位及需要构造的非空簇数K。 → 对每个非空簇内的全部样本逐坐标计算算术平均数。 → 计算每个点的平方欧氏距离并求和，再讨论局限。
近迁移：对原数据同时放大一个坐标10倍，比较SSE的变化。
远迁移：解释用户分群与A/B随机实验的区别。

## KB77-M09｜有限插值数据不能唯一确定曲线模型
来源：KB75-P063-S02｜ELECTIVE_B｜cb89de4cecde2842f95adefacf0ee2057b0d74b8fbea94f413847ebec610213b
定义：若给定三个不同横坐标x=0,1,2且y=x²，则二次多项式p(x)=x²插值这些点；但q(x)=x²+kx(x-1)(x-2)对任意实数k也通过三点。
前提：只给出三个离散观测点且不限定候选模型最高次数；横坐标为三个不同实数0,1,2
结论：即使三个点都在抛物线y=x²上，仍有无穷多条更高次多项式曲线穿过它们。
逐步推理（待教师核对）：
1. 构造原插值：p(0)=0,p(1)=1,p(2)=4，满足给定数据。
2. 构造零化因子：h(x)=x(x-1)(x-2)在三个观测横坐标上都为0。
3. 添加自由参数：q_k=p+kh在已观察点与p完全一致。
4. 展示外推差异：在x=3时p(3)=9,q_1(3)=9+3×2×1=15。
失效前提：不能把精确插值视为唯一真实机制，也不保证未观测区域预测准确。
反例：q_1和p对三点完全一致，但在x=3分别给出15和9。
典型错因：用三点完全拟合就宣布模型唯一正确，不检验模型复杂度和外推。
原创教师侧例题：
- 取k=1，求q(0),q(1),q(2)。 → 每个位置h(x)=0，所以得到0,1,4，与p一致。
- 取k=1，求q(3)并与p(3)比较。 → q(3)=15，p(3)=9，外推相差6。
三级提示：找出全部已观测横坐标。 → 构造在这些点为零的多项式。 → 添加任意倍数并检查未观测点。
近迁移：用四个离散点构造不同四次插值函数。
远迁移：比较模型拟合误差与未见数据预测误差。

## KB77-M10｜指数模型严格单调与非零周期的区分
来源：KB75-P063-S03｜ELECTIVE_B｜cb89de4cecde2842f95adefacf0ee2057b0d74b8fbea94f413847ebec610213b
定义：函数f(t)=2^t在R上严格递增，因此不存在T>0使所有t都有f(t+T)=f(t)；g(t)=sin(t)则满足g(t+2π)=g(t)。
前提：底数2大于1，t是实数；周期定义要求T>0且对定义域内所有t恒等成立
结论：指数增长模型不具有正周期，而正弦函数有正周期2π；有限观测相同并不充分判定模型。
逐步推理（待教师核对）：
1. 利用指数律：2^(t+T)=2^t·2^T。
2. 反证周期：若为周期，则2^T=1；底数2>1时只能T=0，违背T>0。
3. 证明正弦周期：由单位圆角度加整周性质sin(t+2π)=sin(t)。
4. 区分有限采样：少数采样点的重复可能是混叠，不能代替全域周期恒等式。
失效前提：指数底数1对应常数函数有任意正周期，不能将底数2的结论无条件推广。
反例：2^0=1,2^1=2，不满足T=1的周期等式，而sin(0)=sin(2π)=0。
典型错因：仅见两个时刻数值接近就宣布数据严格周期，或以单调指数强行套三角周期。
原创教师侧例题：
- f(t)=2^t，比较f(0)与f(1)。 → 分别为1和2，说明T=1不是周期。
- g(t)=sin(t)，求g(0)与g(2π)。 → 两者为0；验证周期还必须检查任意t，不能仅看这一点。
三级提示：从定义写出对所有t的等式。 → 用指数律或三角恒等式。 → 排除T=0，说明有限数据检验的局限。
近迁移：检查f(t)=(1/2)^t为何也没有正周期。
远迁移：分析潮汐时间序列可能受到长期趋势与周期项共同影响。

## KB77-M11｜经济建模的量纲一致性与盈亏平衡
来源：KB75-P066-S02｜ELECTIVE_C｜6df1ec50b0cfb1c0c09168756482c7cec2ec605ee3f37b9c5514e379a92a7609
定义：单价p（元/件）、单位可变成本c（元/件）、固定成本K（元）和销售量n（件）构成利润Π(n)=(p-c)n-K（元）；不能直接将不同量纲量相加。
前提：本例p,c,K为非负有理数且p>c，销售件数n为非负整数；本模型不含税费、折扣、容量和需求弹性
结论：p=8,c=5,K=30时盈亏平衡n=10；若销量必须为整数，至少10件才有非负利润。
逐步推理（待教师核对）：
1. 明确计量单位：(元/件)乘(件)得到元，才可以与固定成本K相减。
2. 写出利润：Π=8n-5n-30=3n-30。
3. 求平衡阈值：Π≥0当且仅当3n≥30，即n≥10。
4. 检查反例：n=9时利润为-3元；仅解实数方程还须核对整数可行域。
失效前提：若p≤c且K>0，不存在有限非负销量能令利润非负；不可再套正毛利率阈值公式。
反例：把8元/件和30元直接相减写成-22元/件属于量纲混乱。
典型错因：忽略单位或在p=c时除以(p-c)，制造零分母。
原创教师侧例题：
- p=8,c=5,K=30,n=9利润是多少？ → Π=(8-5)×9-30=-3元，仍亏损。
- 维持同样售价、单位成本及固定成本，销量n=11时利润为多少？ → 将销售量n=11代入利润模型Π=(8-5)n-30，得到3元且利润为正。
三级提示：为售价、成本、销量与利润分别写出正确量纲，拒绝直接混加。 → 先将收入和成本统一成元。 → 解不等式并核对销售量整数限制。
近迁移：若每件售价9元、成本5元、固定成本31元，求最小整数销量。
远迁移：讨论折扣导致单价随销量改变时线性模型失效。
