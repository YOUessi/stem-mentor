## KB87-M01｜古典概型中等可能样本点的计数法

来源：KB80-A031-L014 / COMPULSORY；审核：REVIEW_PENDING。

**正式定义：**有限样本空间Ω={ω1,…,ωn}中若P({ωi})=1/n，则任一事件A⊆Ω的概率P(A)=|A|/n。

**记号：**Ω:有限非空样本空间；A⊆Ω:随机事件；n=|Ω|>0

**前提：**样本空间有限且非空；每个基本结果具有相同概率；A由这些结果组成

**数学陈述：**只有在确实等可能的有限样本空间里，才可用有利情况数除以全部可能情况数。

**逐步推理（待独立教师核对）：**
1. **等可能性：**由有限可加性和n个单点总概率为1，全部单点概率共同等于1/n。
2. **事件拆分：**A是|A|个互斥单点事件的并，故P(A)=∑_{ω∈A}P({ω})。
3. **计数结论：**逐项代入1/n得到P(A)=|A|/n；对于空事件结果是0。
4. **适用范围：**若基本结果概率不同，必须改为逐个权重求和而非数目相除。

**合法性说明：**从概率有限可加性得出该方法；数字测试只核对离散示例，不能建立现实装置的均匀性。

**反例/不适用边界：**不均匀六面骰：若P(1)=1/2，其余各面各1/10，事件{1,3,5}概率为7/10而非3/6。

**典型错因：**看到六个标签就默认每个发生概率1/6，忽略实验物理机制或样本点权重。

**教师侧题族（不得直接泄漏给自主挑战学生）：**
1. 题目：公平六面骰出现奇数的概率。**教师解答：**A={1,3,5}共3个结果，Ω共6个且每面等可能，所以P(A)=3/6=1/2。
2. 题目：公平六面骰出现大于4的概率。**教师解答：**A={5,6}有2个有利结果，六面等可能，故概率为2/6=1/3。

**学生提示阶梯（不直接输出教师答案）：**
1. 明确列出随机实验的一次基本结果。
2. 核实全部基本结果是否真的等可能。
3. 再写成事件集合，用可加性计算概率。

**近迁移：**给公平八面骰的素数面事件写出样本点及概率。

**远迁移：**对购物点击事件给出不同页面曝光权重，说明不能数页面直接算概率。

**先修主题（未完成官方ID核对）：**随机试验和事件集合；有限可加性

**独立有限核验：**classical_uniform → 1/2；
非法边界→CONDITIONS_NOT_ESTABLISHED。

## KB87-M02｜分层总体均值的加权合成与抽样边界

来源：KB80-A032-L014 / COMPULSORY；审核：REVIEW_PENDING。

**正式定义：**若总体分为互不重叠且穷尽的H层，第h层人数Nh>0、真实层均值μh，则总体均值μ=ΣNhμh/ΣNh。

**记号：**Nh:层总体大小；μh:第h层真实总体均值；μ:整体总体均值

**前提：**每个个体被计入恰好一层；每层人数为正且有限；各层变量量纲与目标一致

**数学陈述：**总体层均值的合成必须按实际层人数加权；样本层均值作估计时还需审查各层抽样机制。

**逐步推理（待独立教师核对）：**
1. **总量拆分：**总体变量取值总和等于各层所有观测值的和，且各层无重叠。
2. **层内均值：**每层总量等于层人数乘该层真实均值Nhμh。
3. **总体均值：**将各层总量相加并除以总体人数ΣNh，得到加权平均公式。
4. **抽样警告：**若μh是样本估计而不是真实层均值，则等式给出加权估计而非无误差真值。

**合法性说明：**这是有限总体分区恒等式，不能凭此推断有偏抽样自然消除选择偏差。

**反例/不适用边界：**80人均值10与20人均值30的总体均值为14，而不加权平均(10+30)/2=20。

**典型错因：**直接对两个样本层均值取算术平均，忽略层人数不同、抽样不等比例。

**教师侧题族（不得直接泄漏给自主挑战学生）：**
1. 题目：A层80人均值10，B层20人均值30，求总体均值。**教师解答：**总和80×10+20×30=1400，总人数100，所以总体均值14。
2. 题目：A层50人均值8，B层50人均值12，求总体均值。**教师解答：**两层同权重，总和50×8+50×12=1000，总人数100，均值10。

**学生提示阶梯（不直接输出教师答案）：**
1. 明确分层互斥且覆盖全体。
2. 统计每层真实人数而不是随意使用样本样本量。
3. 求加权总和并除以总人数，同时说明是否为估计。

**近迁移：**某两层样本抽取比例不同，设计加权估计并说明需要哪些权重。

**远迁移：**比较便利抽样、分层随机抽样与加权事后修正的可识别条件。

**先修主题（未完成官方ID核对）：**总体与样本；算术平均数及加权平均

**独立有限核验：**weighted_strata → 14；
非法边界→CONDITIONS_NOT_ESTABLISHED。

## KB87-M03｜超几何分布的无放回概率及期望

来源：KB80-A047-L025 / SELECTIVE_COMPULSORY；审核：REVIEW_PENDING。

**正式定义：**总体N件中有K件成功对象，无放回等可能抽n件，X为选中的成功件数。则P(X=k)=C(K,k)C(N−K,n−k)/C(N,n)，E[X]=nK/N。

**记号：**N:总体容量；K:成功对象个数；n:抽取个数；k:抽到成功个数

**前提：**N为正整数且0≤K≤N；n为0到N的整数；所有大小n的子集等可能；k满足max(0,n−N+K)≤k≤min(n,K)

**数学陈述：**有限总体不放回抽样的成功计数遵从超几何分布；其均值来自抽中各成功个体的指示变量和。

**逐步推理（待独立教师核对）：**
1. **分母计数：**无放回抽取的等可能n元素子集共有C(N,n)种。
2. **分子计数：**恰有k件成功可先选成功子集C(K,k)，再选失败子集C(N−K,n−k)。
3. **概率式：**两部分选择互不冲突，使用乘法计数并除以全部等可能子集。
4. **期望推导：**设每个成功个体是否入样的指示量Ij，每个入样概率n/N；E[X]=ΣE[Ij]=K·n/N，不要求Ij独立。

**合法性说明：**线性期望不需要不同抽中指示量独立；抽样本身是不放回的依赖结构。

**反例/不适用边界：**若改为有放回且各次独立抽取，则通常转向二项模型，不能继续直接应用超几何式。

**典型错因：**把无放回抽取错误设为独立伯努利试验，套二项公式计算所有k。

**教师侧题族（不得直接泄漏给自主挑战学生）：**
1. 题目：N=8,K=3,n=2，恰取一件成功的概率。**教师解答：**从3个成功对象选1件、5个失败对象选1件：3×5/C(8,2)=15/28。
2. 题目：同一总体和样本量下X的期望。**教师解答：**每件成功对象入样概率2/8，共3件，故E[X]=3×2/8=3/4。

**学生提示阶梯（不直接输出教师答案）：**
1. 先判断抽样是否无放回。
2. 列出全部子集数和成功失败分别选取的数量。
3. 核对k上下界，再使用概率式或指示变量求期望。

**近迁移：**改为N=10,K=4,n=3，求k=2概率并检查支持集。

**远迁移：**在无放回质量抽检与有放回随机生成器之间选择正确模型并解释差别。

**先修主题（未完成官方ID核对）：**排列组合；条件概率与期望的线性性

**独立有限核验：**hypergeometric → 15/28；
非法边界→CONDITIONS_NOT_ESTABLISHED。

## KB87-M04｜皮尔逊样本相关系数的零方差边界

来源：KB80-A048-L011 / SELECTIVE_COMPULSORY；审核：REVIEW_PENDING。

**正式定义：**成对样本xi,yi的皮尔逊r=Σ(xi−x̄)(yi−ȳ)/√(Σ(xi−x̄)²Σ(yi−ȳ)²)，其定义要求两个平方和都严格正。

**记号：**xi,yi:成对观测；x̄,ȳ:各变量样本均值；r:皮尔逊样本线性相关

**前提：**样本量至少2且为完整成对观测；两个中心化平方偏差和均非零

**数学陈述：**相关系数度量成对观测的线性方向及强度；任一变量无变异时公式分母为零，r未定义而不是0。

**逐步推理（待独立教师核对）：**
1. **中心化：**分别从每个变量观测中减去对应均值，形成偏差向量。
2. **分母条件：**两个偏差向量的欧氏长度之积作为归一化分母，必须大于0。
3. **标准化：**向量内积除以长度乘积由Cauchy–Schwarz保证r位于[-1,1]。
4. **退化情况：**若y全相同，则所有yi−ȳ=0，分母与分子都为0，不能把0/0定义为0。

**合法性说明：**有限例题核验r取值；一般|r|≤1的数学证明依赖Cauchy–Schwarz且两个平方和非零。

**反例/不适用边界：**x=(1,2,3),y=(5,5,5)时r未定义；不能把常量变量的相关性写为零。

**典型错因：**对中心化方差为0的变量强行除以0，或因两个均值接近就断言r接近1。

**教师侧题族（不得直接泄漏给自主挑战学生）：**
1. 题目：x=(1,2,3),y=(2,4,6)求r。**教师解答：**y=2x且x有变化，两个偏差向量同向，故r=1。
2. 题目：x=(1,2,3),y=(5,5,5)求r。**教师解答：**y的中心化偏差全为0，分母为零，所以皮尔逊r未定义。

**学生提示阶梯（不直接输出教师答案）：**
1. 先确认数据是逐行成对样本。
2. 分别计算两个偏差平方和是否严格大于0。
3. 再求中心化乘积和并归一化，注意r不是因果系数。

**近迁移：**把y改成(-2,-4,-6)求r，说明符号变化。

**远迁移：**解释销售额和广告费共同受季节影响时，强相关不能证明直接因果。

**先修主题（未完成官方ID核对）：**成对数据与平均数；向量内积与柯西不等式

**独立有限核验：**pearson → 1；
非法边界→CONDITIONS_NOT_ESTABLISHED。

## KB87-M05｜双解释变量线性回归最小二乘的满秩条件

来源：KB80-A057-L013 / ELECTIVE_A；审核：REVIEW_PENDING。

**正式定义：**设计矩阵X有截距和两个解释变量共3列。若rank(X)=3，则最小二乘目标||Xβ−y||²唯一达到β=(XᵀX)⁻¹Xᵀy。

**记号：**X:观测数m乘3设计矩阵；y:响应向量；β:含截距的三维系数向量

**前提：**m≥3且观测值有限；设计矩阵三列线性无关，XᵀX可逆；该结论仅关于代数拟合的唯一性

**数学陈述：**最小二乘唯一性需要设计矩阵满列秩；并非任何双自变量数据都能唯一确定截距和两个斜率。

**逐步推理（待独立教师核对）：**
1. **展开目标：**L(β)=(Xβ−y)ᵀ(Xβ−y)，展开为βᵀXᵀXβ−2βᵀXᵀy+yᵀy。
2. **一阶条件：**求梯度得2XᵀXβ−2Xᵀy=0，即正规方程。
3. **满秩正定：**rank(X)=3保证任意非零v有vᵀXᵀXv=||Xv||²>0。
4. **唯一最小点：**严格正定二次型的驻点唯一且全局极小，解为(XᵀX)⁻¹Xᵀy。

**合法性说明：**正规方程的计算是有限精确代数；模型因果正确性、噪声独立和外推能力需另行验证。

**反例/不适用边界：**若第二解释变量始终等于第一解释变量，则列重复、rank(X)<3，系数不唯一。

**典型错因：**不检查XᵀX的秩就直接求逆或把无唯一回归系数写成已认证结果。

**教师侧题族（不得直接泄漏给自主挑战学生）：**
1. 题目：样本设计行(1,0,0),(1,1,0),(1,0,1),(1,1,1)，响应1,3,4,6，求系数。**教师解答：**四个观测精确满足y=1+2x1+3x2，三列独立，唯一最小二乘系数(1,2,3)。
2. 题目：若所有记录满足x2=x1，系数是否唯一。**教师解答：**X的第2、3列相同，XᵀX奇异；截距以外只能识别两斜率的和，无法分别唯一确定。

**学生提示阶梯（不直接输出教师答案）：**
1. 先写出包含常数截距列的设计矩阵。
2. 检查三个列向量是否线性无关。
3. 只有满列秩才使用逆矩阵正规方程；否则明确表示系数不唯一。

**近迁移：**设计矩阵加入一个完全重复的解释变量，解释预测可相同但参数不唯一。

**远迁移：**比较多变量回归中的预测准确率、线性代数可识别性与因果识别性。

**先修主题（未完成官方ID核对）：**矩阵秩与线性方程组；二次函数最优化

**独立有限核验：**bivariate_ols → 1,2,3；
非法边界→CONDITIONS_NOT_ESTABLISHED。

## KB87-M06｜平面抛体参数模型斜率的非零水平速度条件

来源：KB80-A064-L006 / ELECTIVE_B；审核：REVIEW_PENDING。

**正式定义：**忽略空气阻力、初始坐标取原点、水平速度vx固定且重力加速度g>0时x(t)=vxt，y(t)=v0t−gt²/2；vx≠0才可写dy/dx=(v0−gt)/vx。

**记号：**t≥0:时间；vx:水平速度；v0:初始竖直速度；g>0:重力加速度

**前提：**采用恒定重力理想模型且不计空气阻力；vx非零；时间t在物理合理的运动区间内

**数学陈述：**参数轨迹求斜率需先检查dx/dt≠0；若水平速度为0，不能用链式除法得到有限斜率。

**逐步推理（待独立教师核对）：**
1. **参数导数：**对t求导得dx/dt=vx及dy/dt=v0−gt。
2. **链式合法性：**当vx≠0时，局部x随t可逆，故dy/dx=(dy/dt)/(dx/dt)。
3. **算例检查：**取vx=2,v0=10,g=2,t=3，斜率=(10−6)/2=2。
4. **失效反例：**vx=0时x(t)=0为竖直轨迹，dx/dt=0，不能套上式作为实数斜率。

**合法性说明：**这是理想抛体的有限参数式推导，实际弹道若考虑阻力必须改变微分方程。

**反例/不适用边界：**若vx=0分母为0，甚至消去t写y为x的单值函数也不成立。

**典型错因：**强行在vx=0时写dy/dx=∞并当作有限的符号求导结果。

**教师侧题族（不得直接泄漏给自主挑战学生）：**
1. 题目：vx=2,v0=10,g=2,t=3求此刻轨迹斜率。**教师解答：**先求导dx/dt=2，dy/dt=10−2×3=4，所以dy/dx=4/2=2。
2. 题目：维持v0=10,g=2但令vx=0还能算原斜率公式吗。**教师解答：**水平位移恒为0，dx/dt=0，不能做该除法，也不能把无穷当有限斜率。

**学生提示阶梯（不直接输出教师答案）：**
1. 写出参数t和两坐标函数。
2. 分别求dx/dt与dy/dt并检查分母非零。
3. 只有满足合法条件才做比值，同时判断运动模型是否适用。

**近迁移：**取vx=5,v0=12,g=4,t=2计算瞬时斜率。

**远迁移：**讨论加入线性空气阻力后恒定水平速度假设为什么失效。

**先修主题（未完成官方ID核对）：**导数链式法则；二次函数与运动学

**独立有限核验：**projectile_slope → 2；
非法边界→CONDITIONS_NOT_ESTABLISHED。

## KB87-M07｜二乘二列联表卡方统计量及边际条件

来源：KB80-A048-L021 / SELECTIVE_COMPULSORY；审核：REVIEW_PENDING。

**正式定义：**两类分组形成非负整数频数矩阵O，行合计ri、列合计cj、总数n>0。独立性零假设下期望频数Eij=ricj/n，统计量χ²=Σ(Oij−Eij)²/Eij。

**记号：**Oij:观测频数；Eij:独立假设下期望频数；ri,cj:行列边际和；χ²:检验统计量

**前提：**观测为独立且按约定抽样的频数；所有行列边际严格为正；渐近显著性检验还需足够的期望频数

**数学陈述：**列联表的χ²统计量可以由频数计算，但显著性、p值与因果解释均需要额外模型前提。

**逐步推理（待独立教师核对）：**
1. **列出边际：**由表内频数计算行总和和列总和并检验全表总数一致。
2. **零假设期望：**独立性模型给出Eij=(ri/n)(cj/n)n=ricj/n。
3. **构造统计量：**逐格以(Oij−Eij)²/Eij累计；各Eij必须正。
4. **推断边界：**得到χ²数值不等于自动拒绝独立性零假设，还须检查近似条件和临界规则。

**合法性说明：**只核对这一固定表格的有理数χ²值，不把卡方分布近似认证为精确小样本分布。

**反例/不适用边界：**若某行或某列总数为0，至少部分Eij=0导致除零；小期望频数可能需要精确检验。
