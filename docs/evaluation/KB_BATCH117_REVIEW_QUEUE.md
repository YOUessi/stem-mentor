## 二、按风险优先的课程原子审校任务

1. **P0 来源失真**：第35页 PDFKit 抽取出现控制字符。必须以Mac本地原PDF页面图像逐项核对建模/探究活动的要求、公式和列表，再写原子；禁止对损坏提取结果自动认证。
2. **P0 跨轨边界**：第51、69、73页必须按页内内容分段，不得按页号推断选修A–E唯一归属；第73页特别注意选修E从中途起始。
3. **P0 数学符号**：第21、22、58、59页的分式、上下标及特殊数学符号须逐项与Mac PDF原图核对，当前索引状态不表示已纠正公式。
4. **P1 必修未审范围**：第13、14、16、27–36页等，逐段识别概念、定理、方法和实践能力，区分内容要求、学业要求和教学建议。
5. **P1 选择性必修未审范围**：第37–50页逐章拆分数列/导数、空间向量/解析几何、计数概率统计及课题研究；列出命题前提和课程归属。
6. **P1 选修扩展**：第52–73页追溯A–E各类选修专题的**适用对象和授课要求**。新增候审题族不能被误当作通用必修范围。
7. **P2 所有后续修订**：每条原子必须有课标版本、印刷页、章节段、类型、原创内容ID和教研审核状态；缺少来源或跨轨争议时保持不可发布。
