## 2. 20 篇新增原创教师审核稿与独立数学检查

| 模块 | 新增编辑审核稿 | 核心数学前提/失败边界 |
|---|---:|---|

- 每篇均为原创知识内容：正式表述、适用域与全部必要假设、先修、**3 个有依据的独立推理阶段**、1 个具有具体反例的典型错因、**2 道教师例题及推理**、**3 层针对性的非剧透提示**、近迁移与远迁移。实际合计 **20篇 / 40例题 / 20具体反例 / 60推理阶段 / 60提示 / 40迁移**。
- 原创内容按同一固定 JSONL 生成可复核稿 `KB_BATCH50_SELECTIVE_MANUSCRIPTS.md` 与逐条机器审计 `KB_BATCH50_SELECTIVE_AUDIT.json`。三篇研究方法单元是研究流程讲解，**不强行冒充需要证明的数学定理**。
- 新增 `backend/app/kb_batch50_exact.py`：**17 类有界精确计算见证**。概率用 `fractions.Fraction` 和 `math.comb`，包括二项概率与超几何、条件概率与列联表、期望频数、卡方统计量、回归斜率、相关系数边界、正态对称性、解析几何伪根筛选；拒绝零分母、零方差、超域、负频数、缺失字段、额外字段、嵌套恶意负载、权限伪造及自由文本推导。

- **数学结论强度：** `FINITE_EXACT_CASE_ONLY` 只说明该受控有限实例的精确运算成功；**一般命题未形式认证、学生自由书写步骤未认证、教师审批未发生**。三篇研究方法单元不制造数学数值证明。
- 独立回归包含全部 313 项项目编辑候选行、全部 20 篇新版审稿、17 类正负前提/形状注入、组合概率枚举归一性、超几何支持集全列举和小整数二乘二列联表精确闭式交叉验算。真实调用 `student_evidence_lookup` 和 `draft_next_question` 检查未经批准的新稿不能进入学生侧检索或暴露教师完整答案，测试不发出云端 API 请求。
