## 1. 二次方程判别式为何必须要求 a≠0

**命题**：实数 (a,b,c) 中 (a\ne0) 时，方程 (ax^2+bx+c=0) 的实根个数由 (Delta=b^2-4ac) 的符号决定。

**分步论证**：

1. 先使用 (a\ne0)，使乘上 (4a) 可逆，得到 (4a(ax^2+bx+c)=0)，与原方程等价。
2. 恒等展开 (4a^2x^2+4abx+4ac=(2ax+b)^2-(b^2-4ac))，即 ((2ax+b)^2=Delta)。
3. 若 (Delta<0)，实数平方不能为负，无实根；若 (Delta=0)，唯一解 (x=-b/(2a))；若 (Delta>0)，两解 (x=(-b\pm\sqrt\Delta)/(2a)) 且不同，因为 (sqrt\Delta>0) 且 (2a\ne0)。
4. 反向代回可恢复原方程：全部等价变换均有 (a\ne0) 的条件保障。

**不适用例**：(a=0,b=1,c=1) 时只有一次方程 (x+1=0)，不得套二次判别式对根数下结论。受控 oracle 计算具体有理系数的 (Delta) 与根数，不表示自动证明所有实系数情况。

## 2. 抛物线焦点—准线与标准方程的双向等价

**命题**：在欧氏平面上取 (p\ne0)、焦点 (F=(p,0)) 与准线 (l:x=-p)。点 (P=(x,y)) 到焦点和准线距离相等当且仅当 (y^2=4px)。

**分步论证**：

1. 焦点距离 (PF=\sqrt{(x-p)^2+y^2}\ge0)；点到准线距离 (d(P,l)=|x+p|\ge0)。
2. 两侧非负，因此 (PF=d(P,l)) 与 (PF^2=d(P,l)^2) **双向等价**；这一步不能省略非负性。
3. 展开相减 ((x-p)^2+y^2-(x+p)^2=y^2-4px)，故平方相等等价于 (y^2-4px=0)。
4. 反向使用同一恒等式及平方根非负性，得到原几何距离相等。

**退化边界**：(p=0) 时焦点落在准线上，几何定义不再给出非退化抛物线；形式上 (y^2=0) 是整条直线，必须拒绝将其当常规抛物线。本批有限测试对 (p\in\{-2,-1,1,2\}) 和整数网格点验证平方差，**不替代上面的数学论证**。

## 3. 有限实向量柯西—施瓦茨：零向量与等号条件

**命题**：对 (u,v\in\mathbb R^n)（(n\ge1)），\((u\cdot v)^2\le \|u\|^2\|v\|^2\)，等号当且仅当 (u,v) 线性相关（包括零向量）。

**代数论证**：

1. 有限求和展开乘积
   \[
   \left(\sum_i u_i^2\right)\left(\sum_jv_j^2\right)
   -\left(\sum_i u_iv_i\right)^2
   =\sum_{i<j}(u_iv_j-u_jv_i)^2.
   \]
   等式可将左边的 (i=j) 项消去，再按 (i<j) 配对，分别得到两个平方项与交叉项。
2. 右侧逐项非负，因此左侧非负，得到不等式；整个步骤**没有除以** (\|v\|^2)，所以 (u=0) 或 (v=0) 都可直接覆盖。
3. 若 (v\ne0)，等号表示所有 (2\times2) 子式为零，选择某个 (v_j\ne0)，则 (u_i=(u_j/v_j)v_i) 对每个 (i) 成立，即 (u=tv)；反向显然。若 (v=0)，等号直接成立，零向量与任何 (u) 线性相关。

**不合法步骤**：未排除 (v=0) 就令 (t=(u\cdot v)/\|v\|^2)。代码对有限有理向量精确检查拉格朗日恒等式，不能将对测试样本的检查标为原始自然语言证明的形式认证。

## 4. 对数乘法定律：真数的「分别严格为正」不可省略

**命题**：(a>0,a\ne1,x>0,y>0) 时，\(\log_a(xy)=\log_a x+\log_a y\)。

**分步论证**：

1. 由于 (a>0,a\ne1)，实指数函数 (t\mapsto a^t) 严格单调，是 \(\mathbb R\) 到 \((0,\infty)\) 的双射，可定义其逆函数 (\log_a)。
2. 因 (x,y>0)，存在实数 (u=\log_a x,v=\log_a y)，满足 (a^u=x,a^v=y)。
3. 指数乘法 (a^{u+v}=a^ua^v=xy>0)。将双方施加合法的逆映射得到 \(\log_a(xy)=u+v\)。
4. 因而结论成立；并不需要 (a>1)，当 (0<a<1) 时逆函数仍存在。

**反例/域错误**：取 (x=-2,y=-3,a=2)，虽然 (xy=6>0) 且左边有定义，右侧的两项实数对数均无定义。因此只检查 (xy>0) **不足以**支持拆分。本批 oracle 只提供正真数与合法底数的计算域守卫；不把域守卫本身误称为对数恒等式的形式证明。

## 5. 两圆相交：先处理同心分支，避免把重合圆误判为内切

设 (r_1,r_2>0)，两圆心距离为 (d\ge0)。

1. **(d=0)**：圆心相同。若半径相同，则两圆重合，有无穷多个交点；若半径不同，交点为零。因此不能机械把 (d=|r_1-r_2|=0) 当作普通内切一点。
2. **(d>0)**：若交点 (P) 存在，三点 (C_1,P,C_2) 的边长 (r_1,r_2,d) 满足 ( |r_1-r_2|\le d\le r_1+r_2)（含退化三角形）。
3. 当 ( |r_1-r_2|<d<r_1+r_2)，存在非零高度，圆心连线的两侧各有一个对称交点，恰为两个；当任一等号成立时高度为零且 (d>0)，只有一个交点。
4. 当严格不等式不满足时没有交点。代码只对有理数圆心和半径的有限输入检查这些分支。

## 6. 并集上界与「概率为零≠集合为空」

**命题**：任意同一概率空间事件 (A,B)，有 (P(A\cup B)\le P(A)+P(B))，等号当且仅当 (P(A\cap B)=0)。

1. 对任意样本点 \(\omega\)，示性函数逐点恒等式
   \(1_{A\cup B}(\omega)=1_A(\omega)+1_B(\omega)-1_{A\cap B}(\omega)\)。
2. 在同一概率测度下取期望，得到 \(P(A\cup B)=P(A)+P(B)-P(A\cap B)\)。
3. 因为事件概率非负，上界成立；等号当且仅当减去的交概率为零。
4. **不能进一步推出交集为空**：在 (\Omega=\{0,1,2\}) 上，给权重 (1/2,0,1/2)，令 (A=\{0,1\},B=\{1,2\})。交集为 \(\{1\}\ne\varnothing\)，但 (P(A\cap B)=0)，仍可取等号。

本批受控校验同时接受合法的零概率原子和拒绝权重之和不为 1 的伪概率分布。

## 7. 商法则：点上分母非零与邻域合法性

**命题**：在 (x_0) 处可导的 (u,v)，且 (v(x_0)\ne0)，则商 (u/v) 在 (x_0) 可导，导数为
\[
\left(\frac{u}{v}\right)'(x_0)=
\frac{u'(x_0)v(x_0)-u(x_0)v'(x_0)}{v(x_0)^2}.
\]

1. 可导蕴含连续，故 (v(x_0)\ne0) 保证存在邻域使 (v(x)\ne0)，倒数可定义。
2. 令 (w(x)=1/v(x))。精确通分得到
   \[
   \frac{w(x)-w(x_0)}{x-x_0}
   =-\frac{v(x)-v(x_0)}{(x-x_0)v(x)v(x_0)}.
   \]
3. 取极限，分子差商趋于 (v'(x_0))，分母其余部分趋于 (v(x_0)^2>0)，得 (w'(x_0)=-v'(x_0)/v(x_0)^2)。
4. 结合乘积求导法则应用于 (u\cdot w)，得到商法则结论。

**拒绝例**：(u(x)=1+2x,v(x)=x-1,x_0=1)，分母为零，商函数在该点无定义。代码针对多项式有限有理数点计算商法则与 SymPy 符号微分结果对照，不涵盖任意可导函数的形式证明。

## 8. 超几何分布：支撑集与等可能性必须同时成立

**命题**：有限总体共 (N\ge1) 个可区分对象，恰有 (K) 个成功对象；从中**等可能不放回**选取 (n\) 个对象。成功数 (X) 的质量函数为
\[
P(X=k)=\frac{\binom Kk\binom{N-K}{n-k}}{\binom Nn},
\quad \max(0,n-(N-K))\le k\le\min(n,K).
\]

1. 前提为整数 (0\le K\le N,0\le n\le N)，且每个大小为 (n) 的子集等可能；总样本数 \(\binom Nn>0\)。
2. 事件 (X=k) 要求从 (K) 个成功中选 (k) 个、从 (N-K) 个失败中选 (n-k) 个，计数乘法法则得分子。
3. 两个组合数的参数合法性同时要求 (0\le k\le K\) 与 (0\le n-k\le N-K\)，交集正是上述支撑界。
4. 取各可能 (k) 求和，Vandermonde 恒等式给总概率 1；其组合解释是按成功数划分所有大小 (n) 的子集，无重复、无遗漏。

**拒绝例**：(N=10,K=4,n=3,k=4)：不能抽 3 个却得到 4 个成功。若改成放回抽样，分布一般变为二项型，不能复用超几何式。本批在小总体参数空间对概率和做全量有限枚举核验。
