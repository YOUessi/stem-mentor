# 质量与学习效果评测计划

## 三层评测
1. **软件正确性**：接口、数据库持久化、模式切换、浏览器流程、异常处理及安全边界。
2. **教学策略模拟**：限定题卡场景下，教师动作是否符合规则；提示是否过度、历史是否真实、微考点是否限频。
3. **真实教学有效性（未执行）**：实际学生的独立解题、近远迁移、延迟保持与教师盲评；模拟器不得用作此层证据。

## 对照计划（真实模型和学生接入后）
A 普通问答；B 普通知识 RAG；C 结构化方法 + 教学动作；D C + 个人真实记忆与遗忘管理。评估条件与目标识别、方法选择、突破口发现、无提示新题表现。不得只以模型答案正确率充当教学质量。

## 必须覆盖的自动回归
- 逻辑分析首轮引导条件/目标；推理模式在卡住时切换目标导向；自主模式无求助时仅保存。
- 切换模式不丢历史/草稿；数据重启后可恢复。
- 回忆只出现曾实际完成过、且结构方法相似的题；不同学生隔离。
- 完成无提示经历不自动等于正确作答或掌握。
- 间隔复习正确与错误调整时间和盒级；微考点时间与语境优先，不强制插话。
- 数学未验证明确标记；不支持题目保守处理。
- 模拟页面可完整操作；无需外部密钥和在线网络。
- 可持续集成在每次提交执行独立测试。

## 实验留痕
每次实验按日期存配置、Git commit、环境、种子/题卡版本、测试数、通过/失败、缺陷定位、修复和复测结果。真实学生研究必须先完成审查与同意。
