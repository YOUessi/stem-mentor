## KB76-M01｜数列收敛的ε-N定义与非例
- 来源待审候选：KB75-P052-S02（ELECTIVE_A）
- 数学断言：a_n=1/n收敛到0;有界性本身不蕴含收敛。
- 前提：论域是从n=1起的实数数列；ε为任意严格正的实数,而不是某个指定阈值
  1. 明确量词顺序：先任取ε>0,再选N,最后必须对所有n≥N成立。
  2. 构造N：由阿基米德性质存在正整数N>1/ε。
  3. 逐项核验：当n≥N时0<1/n≤1/N<ε,故|a_n-0|<ε。
  4. 给出不适用边界：b_n=(-1)^n有界却有两个不同常值子列,不能收敛到单个实数。
- 失效反例：(-1)^n交替取-1和1,两条子列极限不一致。
- 教师侧原创例题：任取N=5,对所有n≥5有1/n≤1/5<1/4。；只需N>10,可取N=11;所有n≥11满足2/n<1/5。
- 错法：将观察前10项靠近零误当成对任意ε的尾项证明。

## KB76-M02｜函数极限存在并不推出连续
- 来源待审候选：KB75-P052-S03（ELECTIVE_A）
- 数学断言：f(x)=x²(x≠0)而f(0)=1在0的极限为0,但并不连续。
- 前提：考察点0在函数定义域内；左右趋近时遵守邻域内的函数定义
  1. 处理去心邻域：当0<|x|<δ时使用x²,不能把f(0)=1混入极限。
  2. 验证极限：任取ε>0,选δ=√ε,则0<|x|<δ使|x²-0|<ε。
  3. 核对点值：按题设f(0)=1,因此极限0≠1。
  4. 判定结论：连续的三项条件未同时满足,0为可去间断点。
- 失效反例：g(x)=x²(x≠0),g(0)=1在0处不连续,尽管两侧极限同为0。
- 教师侧原创例题：极限为0,点值1,因此不连续;连续所需的相等条件失败。；其余保持x²,极限与点值均为0,故在0连续。
- 错法：把函数图像的邻近趋势当作端点赋值。

## KB76-M03｜微积分基本定理与求导积分前提
- 来源待审候选：KB75-P052-S04（ELECTIVE_A）
- 数学断言：在上述条件下,∫_0^2 2x dx=4,不能忽略连续性及原函数检验。
- 前提：g在[a,b]连续；F在区间内可导且F'(x)=g(x)；a≤b且均为有限实数
  1. 说明原函数存在性：连续性允许定义G(x)=∫_a^xg(t)dt并在区间内部有G'=g。
  2. 证明导数相同：若F'=g,则(G-F)'=0,连通区间上的G-F为常数。
  3. 计算端点差：由G(a)=0得G(b)=F(b)-F(a),即定积分值。
  4. 核对具体例子：F(x)=x²满足F'=2x,所以∫_0^2 2x dx=2²-0²=4。
- 失效反例：g(x)=2x,错误选F=x³时F'=3x²≠2x,端点差会得到错误值。
- 教师侧原创例题：F=x²的导数为2x,端点差4-0=4。；F=x³的导数为3x²,端点差1-0=1。
- 错法：不检查F'=g,只凭形式相似写出上下限代入。

## KB76-M04｜二维联合分布边缘化与独立性
- 来源待审候选：KB75-P056-S03（ELECTIVE_A）
- 数学断言：合法联合概率表的行列边缘可精确计算;共同边缘相同也不能保证独立。
- 前提：两维取值集合均有限；联合表所有概率非负且总和恰为1
  1. 核验归一化：示例表四格1/8,3/8,1/4,1/4总和为1。
  2. 计算行边缘：按各行两个联合格子求和,得到行边缘分别为1/2和1/2。
  3. 计算列边缘：两列分别3/8和5/8,行列各自都归一。
  4. 检验独立：左上格若独立应为(1/2)(3/8)=3/16,但实际1/8,故不独立。
- 失效反例：有相同边缘(1/2,1/2)的独立四格1/4与完全依赖对角线1/2属于不同联合表。
- 教师侧原创例题：求和1/8+3/8=1/2,因为两格属于同一个X取值的全部Y情形。；1/8+1/4=3/8,不能直接认为行边缘等于列边缘。
- 错法：把两个边缘相乘当作所有联合事件概率,漏掉独立性假设。

## KB76-M05｜一元最小二乘直线与因果推断的边界
- 来源待审候选：KB75-P061-S03（ELECTIVE_B）
- 数学断言：对(0,1),(1,3),(2,5),唯一最小二乘斜率为2,截距1。
- 前提：n≥2且样本x不全相等；仅声明有限样本平方误差最小,没有假定因果性
  1. 展开损失：最小化Σ(y_i-a-bx_i)²,分别对a,b求导并令其为0。
  2. 解正规条件：第一个条件得a=ȳ-bx̄,代入另一个得b的协方差/方差比。
  3. 检查分母：Σ(x_i-x̄)²>0时斜率解唯一,否则斜率不可识别。
  4. 代入实例：x̄=1,ȳ=3,分子4,分母2,得到b=2,a=1。
- 失效反例：x全部为1时无论y如何变化,不能通过上述公式得到唯一斜率。
- 教师侧原创例题：x均值1,y均值3,中心乘积和4,x平方偏差和2,得斜率2。；中心化y均为0,斜率0,截距5,并不代表x会导致y恒定。
- 错法：把b>0解释为x必然导致y上升或直接除以零方差。

## KB76-M06｜三维叉积的垂直性与交换顺序
- 来源待审候选：KB75-P060-S01（ELECTIVE_B）
- 数学断言：a×b与a,b正交且b×a=-(a×b);若a,b线性相关则叉积为零。
- 前提：三维右手标准正交坐标系；分量为有限实数并采用通常欧氏内积
  1. 定义分量：按右手定向的坐标公式逐分量构造。
  2. 核对正交：a·(a×b)展开后正负项两两相消为0,b·(a×b)同理。
  3. 交换次序：互换a,b后每个分量都改变符号。
  4. 讨论退化：a,b平行时各2×2行列式为0,叉积为零但没有唯一非零法向量。
- 失效反例：e1×e2=e3而e2×e1=-e3,只在叉积为零时二者相同。
- 教师侧原创例题：叉积(0,0,1),同时与a、b内积都为0。；叉积(1,-1,1),点乘a得0,点乘b也得0。
- 错法：把叉积和内积混淆,或者忘记右手坐标系方向。

## KB76-M07｜参数曲线斜率及参数导数零分母
- 来源待审候选：KB75-P063-S04（ELECTIVE_B）
- 数学断言：t0=1时x'=2,y'=3,斜率3/2;在t0=0不能直接作0/0,但这不代表没有切线。
- 前提：参数函数在t0附近连续可导；x'(t0)≠0是按商式求切线斜率的必需前提
  1. 求参数导数：由幂函数求导,x'=2t,y'=3t²。
  2. 检查非退化：t0=1时x'=2≠0,故局部可用x作坐标。
  3. 使用链式法则：dy/dt=(dy/dx)(dx/dt),于是dy/dx=3t/2。
  4. 核对零分母：t0=0时x'=0,y'=0,公式0/0无定义;须改用点集或极限独立研究切线。
- 失效反例：x=t²,y=t³在t=0得到0/0,却具有水平半切线方向,需分别研究。
- 教师侧原创例题：dx/dt=2,dy/dt=3,所以斜率3/2。；dx/dt=-2,dy/dt=3,因此斜率-3/2,不同参数可能指向不同切向。
- 错法：把y'(t)直接当作dy/dx或消去dx/dt=0。

## KB76-M08｜非均匀连续密度与零点质量
- 来源待审候选：KB75-P056-S02（ELECTIVE_A）
- 数学断言：对密度f(x)=2x, P(0≤X≤1/2)=1/4;f(3/4)=3/2>1不矛盾。
- 前提：密度非负且在全实轴可积并归一；本例概率区间均位于[0,1]
  1. 检查归一：∫_0^1 2x dx=[x²]_0^1=1,且密度非负。
  2. 计算区间质量：从0积到1/2得(1/2)²=1/4。
  3. 解释单点：积分在长度为0的单点为0,不能把f(x0)当作P(X=x0)。
  4. 区分均匀：f随x变化并非常数,所以不能套用均匀分布长度比。
- 失效反例：f(3/4)=3/2而P(X=3/4)=0,证明密度高度与点质量不同。
- 教师侧原创例题：积分∫_0^{1/2}2x dx=1/4。；积分∫_{1/2}^1 2x dx=1-1/4=3/4。
- 错法：拿密度函数的高度替代区间积分或错误套用均匀长度公式。
