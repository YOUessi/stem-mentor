# 高中数学知识库完整性审计（2026-10-20）

**结论：工程模拟功能逐步可用，但知识库尚未达到“完整高中数学教材 + 经审核教学内容 + 可验证数学推理”的程度。**

审计范围：MacBook Air `~/Documents/文件/stem-mentor`，基于合并后的 GitHub main v0.13 和本地运行代码；数据由 `.venv/bin/python scripts/audit_knowledge.py --json` 读取。统计反映**数量和字段存在性**，不代表数学审核或真实教学效果。

目前定位为：**绿色离线学习 Agent 工程原型 + 高中数学知识点索引 + 受控可视工具 + 小规模自编方法 RAG**。

## 2. 正在工作的内容

- **数学工具层**：函数与导数、平面/空间直角坐标、圆锥曲线、三角形、数列、集合/区间、复平面、概率统计。
- **提示与流程层**：ANALYZE/GUIDE/INDEPENDENT三模式、学生自报阶段、卡点逆推和桥梁提问、主动渐进帮助。
- **检索层**：26篇本地自编方法/策略笔记，通过FTS5中文二元词及受控标签/适用边界门控提供可追溯引用。
- **记忆与迁移层**：合成学生原始思考、受控旧题结构召回、独立基线冻结、回忆后尝试，所有学业结果仍然未验证。
- **复习层**：13个易漏微考点卡及间隔复习规则演示。

## 4. 建议的知识建设次序

**Phase K1 — 建立 Schema 与审校约束。** 将课程知识点、定理、方法、题族、错因、提示、反例、微考点和个人记忆分开，所有结论带来源与许可/审核状态；默认没有教师审核就不当作权威教学答案。

**Phase K2 — 深化一组基础核心内容。** 优先从函数定义域/单调/极值、三角形SSA、数列公比特例、圆锥曲线条件、平面向量、基本不等式等选择20—30个高频、容易出错的**项目自编**知识点；每条都配严格推导、反例、边界和至少两个变式。数量应以完成内容和审查质量为准，不以堆叠页面数为目标。

**Phase K3 — 以真实内容驱动 RAG。** 由“检索26条方法摘要”升级为能够导航定理→证明→方法条件→样题→学生历史结构的多层检索；采用“学生仅拿提示、教师侧保留完整证据”的可见性规则。

**Phase K4 — 对学习结果做真实区分。** 知识讲义准确 ≠ 数学答案正确 ≠ 无提示独立完成 ≠ 新题迁移成功；四者必须独立评估，避免 Agent 为追求表面互动次数伪造学习成绩。
