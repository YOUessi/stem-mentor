## 01. 定积分的有向面积与无符号面积

**审核ID**：math.hs.editorial.batch35.kb33.a.p054.a001；**选修方向**：ELECTIVE_A；**原课标印刷页**：54；**编辑候选**：将可积函数的定积分表示为有向面积并检查面积非负条件。

**类型**：method；**记号**：∫_a^b f(x)dx。

### 准确定义 / 命题 / 方法

在[a,b]可积时，定积分是带符号的累积量；若f≥0则与曲线下方几何面积相同，变号时面积为∫|f|。

**全部声明的使用假设**：a≤b，函数在闭区间黎曼可积；用几何面积解释时必须声明坐标轴与符号。

### 逐步推导与依据（教师审核前不可自动批准）

1. 先定位零点及各段符号 **依据**：有向面积正负取决于函数值符号
2. 利用积分可加性逐段计算 **依据**：分割区间后定积分可逐段相加
3. 计算面积时对负段换符号 **依据**：非负几何面积不能由正负部分相互抵消

### 错因 / 反例 / 适用边界

**错误主张**：任何定积分都等于几何面积。

**具体反例**：f(x)=x在[-1,1]的积分为0，而两边三角形总面积为1。

**失效原因**：把带符号积分和非负面积混为一谈。

**适用边界**：积分区间端点倒序时还会变号。

**修复提问**：请指出题目中真正缺少的前提，并用反例解释为什么不能越界。

### 教师侧例题（不对独立学习泄漏）

1. 原函数为x²/2

**教师答案**：2；**复核**：因x≥0，面积也为2

**例题2**：求f(x)=x在[-1,1]围成的面积

1. 分割x=0两段

## 02. 空间法向量与方向向量的非零检验

**审核ID**：math.hs.editorial.batch35.kb33.a.p055.a004；**选修方向**：ELECTIVE_A；**原课标印刷页**：55；**编辑候选**：使用法向量和方向向量判别空间位置并检查非零条件。

**类型**：method；**记号**：n·v=0。

### 准确定义 / 命题 / 方法

对已知非零法向量n与非零方向向量v，n·v=0意味着v平行于对应平面；判两平面平行可比非零法向量是否成比例。

**全部声明的使用假设**：空间欧氏内积；平面由非零法向量定义；直线方向向量非零。

### 逐步推导与依据（教师审核前不可自动批准）

1. 首先检查描述对象的向量非零 **依据**：零向量不确定唯一方向或平面
2. 计算内积检查正交 **依据**：方向向量与法向量正交即方向平行平面
3. 再判断位置关系中的包含情况 **依据**：向量判据不区分直线在面内还是严格平行

### 错因 / 反例 / 适用边界

**错误主张**：内积为零便能证明直线与平面不相交。

**具体反例**：z轴所在直线的方向(0,0,1)与平面x=0法向(1,0,0)正交，但z轴就在平面内。

**失效原因**：方向平行平面并不排除直线包含于平面。

**适用边界**：若法向为零则平面表达失效。

**修复提问**：请指出题目中真正缺少的前提，并用反例解释为什么不能越界。

**教师答案**：平行方向；**复核**：直线过(0,0,1)时与平面不交

## 03. 概率密度不是点发生概率

**类型**：concept；**记号**：P(a<X<b)=∫_a^b f(x)dx。

### 准确定义 / 命题 / 方法

绝对连续随机变量的密度f(x)可大于1，但单点概率恒为0；区间概率需要对密度积分。

**全部声明的使用假设**：f非负、可积且全实数积分为1，所讨论变量具有绝对连续分布。

### 逐步推导与依据（教师审核前不可自动批准）

1. 验证f的积分和非负性 **依据**：不规范的曲线不能当概率密度
2. 计算区间概率时积分密度 **依据**：概率是区间下的面积而非单点高度
3. 将区间缩到单点时积分为零 **依据**：绝对连续分布对单点给零质量

### 错因 / 反例 / 适用边界

**错误主张**：密度最大值不可超过1。

**具体反例**：在[0,1/2]均匀分布密度为2，仍是有效密度。

**失效原因**：把函数高度当作概率违反连续概率定义。

**适用边界**：混合型分布可能含点质量，不能套用单点为零。

### 准确定义 / 命题 / 方法

**全部声明的使用假设**：离散联合表每格非负且总和为1；EX、EY及EXY有限。

### 逐步推导与依据（教师审核前不可自动批准）
