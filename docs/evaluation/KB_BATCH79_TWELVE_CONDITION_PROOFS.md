## KB79-P01｜正数算术几何平均不等式

**原有风险步骤**：math.hs.inequality.amgm#1（SHA256: 89283cfb1b6061c3e21defa8f89494c13884502ed127bafd75ad47120b9d31cc）
**准确命题**：对任意正实数a,b，有(a+b)/2≥√(ab)，且等号仅当a=b。
**前提**：a>0；b>0；实数范围

**分步论证（待教师确认）**
1. a,b正保证√a、√b及√ab在实数中存在。
2. 平方(√a−√b)²≥0得到a+b≥2√ab，除以正数2保持不等号。
3. 等号成立当且仅当√a=√b，等价于a=b；不把这个结论逆向套给负数。

**违反前提的反例**：a=-2,b=8时√(ab)在实数无定义，不能引用正数版定理。
**典型错因**：忽略非负开方定义域，或声称所有实数均满足。
**例题**：a=2,b=8时比较均值。
**教师侧解答**：(2+8)/2=5，√16=4，所以5≥4；两值不同，严格不等。
**三级提示**：先检查a、b是否允许在实数中开平方。 → 把√a与√b的差平方，寻找一个始终非负的表达式。 → 考察差的平方何时为零，用它判断等号条件而非直接代值。
**近迁移**：检验a=5,b=5为何等号成立。
**远迁移**：用于两项非负代价优化时，先核实变量符号再调用。

**发布状态**：REVIEW_PENDING / TEACHER_ONLY / NOT_FORMALLY_VERIFIED

## KB79-P02｜二维柯西—施瓦茨不等式

**原有风险步骤**：math.hs.vector.cauchy-schwarz#1（SHA256: 49424aa65510af64439845b736e1e59bf3388bfa2d40c36308d8ca5310f4d1ff）
**准确命题**：对任意u=(u₁,u₂),v=(v₁,v₂)∈R²，有(u·v)²≤(u·u)(v·v)。
**前提**：u,v同属R²；分量均为实数

**分步论证（待教师确认）**
1. 直接展开(u·u)(v·v)−(u·v)²。
2. 配方得到(u₁v₂−u₂v₁)²≥0，此步对任意实数成立且没有除法。
3. 把非负平方移项得到不等式；等号当且仅当两个向量线性相关（零向量亦满足）。

**违反前提的反例**：u属于R²而v属于R³时内积未在同一空间中定义。
**典型错因**：把u·v当作任意异维向量的运算，或错误要求向量都非零。
**例题**：u=(1,2),v=(3,4)检验不等式。
**教师侧解答**：u·v=11，平方121；||u||²||v||²=5×25=125；差4=(1×4−2×3)²。
**三级提示**：检查两个内积是否发生在同一个二维实向量空间。 → 尝试展开两个平方范数的积与内积平方之差。 → 识别行列式型平方项，并检查零向量情形的等号。
**近迁移**：取u=(1,2),v=(2,4)说明等号。
**远迁移**：推广到R³时应换用相应恒等式，不能照搬二维交叉项。

**发布状态**：REVIEW_PENDING / TEACHER_ONLY / NOT_FORMALLY_VERIFIED

## KB79-P03｜有限等比数列求和的q≠1分支

**原有风险步骤**：math.hs.sequence.geometric-sum#4（SHA256: 0a73b2674588476438a19b841104a43be95a687684eb8b3038f9b91082b936fb）
**准确命题**：对n≥1整数、首项a和公比q≠1，有Σₖ₌₀ⁿ⁻¹a qᵏ=a(1−qⁿ)/(1−q)。
**前提**：n为正整数；q≠1；a,q为实数

**分步论证（待教师确认）**
1. 把有限和写为S=a+aq+⋯+aq^(n−1)，再写qS=aq+⋯+aqⁿ。
2. 逐项相减严格得到(1−q)S=a(1−qⁿ)，没有使用无穷级数极限。
3. q≠1确保除法合法；若q=1单独计算S=na，不能套零分母形式。

**违反前提的反例**：取q=1,n=4,a=3时原和12存在，但分式出现0/0。
**典型错因**：把有限公式误写成无穷级数，或忘记q=1分支。
**例题**：a=3,q=2,n=4求和。
**教师侧解答**：直接3+6+12+24=45；分式3(1−16)/(1−2)=45，逐步一致。
**三级提示**：分别写下n项原和S与同样n项的qS。 → 逐项抵消两个有限和，保留首项与末项。 → 在除以1−q之前检查是否等于零；若等于零改用常数和。
**近迁移**：考察q=0和n=1的边界。
**远迁移**：迁移到贷款现金流求和前先说明每期折现率和有限期数。

## KB79-P04｜复合函数定义域的双层约束

**前提**：f的定义域t≠0；g对所有实数x有定义；g(x)须属于f的定义域

**三级提示**：先区分内函数的定义域与外函数允许的输入。 → 找出g(x)什么时候让分母成为零，而不是只看g本身。 → 用排除后的自变量测试复合表达式，并重核外层是否有定义。

## KB79-P05｜有限等可能样本空间中的贝叶斯公式

**原有风险步骤**：math.hs.probability.bayes-partition#3（SHA256: 628ea06485d4165f1540edc362675292d9d427a1f593287862ea7812f25bc1db）
**准确命题**：同一有限等可能样本空间中P(A)>0且P(B)>0时，P(A|B)=P(B|A)P(A)/P(B)。
**前提**：样本空间有限非空且等可能；A,B合法事件；P(A)>0；P(B)>0

**分步论证（待教师确认）**
1. 按条件概率定义P(A|B)=P(A∩B)/P(B)。
2. 同理P(B|A)=P(A∩B)/P(A)，因此P(B|A)P(A)=P(A∩B)。
3. 由于P(B)>0，合法除以P(B)得到结论；条件事件为零概率时两种写法不能照用。

**违反前提的反例**：B=空集时P(A|B)无定义，即使交集概率为0也不可除以0。
**典型错因**：把P(A|B)与P(B|A)混淆，或遗漏条件事件非零。
**例题**：六等可能结果A={1,2,3},B={1,2,3,4}求P(A|B)。
**教师侧解答**：交集大小3、B大小4，所以P(A|B)=3/4；Bayes右侧(3/3)(3/6)/(4/6)=3/4。
**三级提示**：把A与B作为同一样本空间的事件，找出两个条件概率的分母。 → 先将两种条件概率各自写成交集概率除以条件事件概率。 → 检查分母为正后再进行代数整理，别把两个条件的方向交换。
**近迁移**：令A与B不相交但都非空，验证结果为零。
**远迁移**：将事件先验变更带入诊断概率，检查是否错误认为条件概率可交换。

**发布状态**：REVIEW_PENDING / TEACHER_ONLY / NOT_FORMALLY_VERIFIED

## KB79-P06｜介值定理与二分法的严格异号门槛

**原有风险步骤**：math.hs.function.bisection-root#2（SHA256: 7ad2ee52ce128a3cbe4acc0b8ca7687dd158ad5fa248c0fd7943ce35f0509134）
**准确命题**：连续f(x)=x²−c(c>0)若a<b且f(a)f(b)<0，则(a,b)存在零点。
**前提**：c>0；a<b；f为连续多项式；f(a)f(b)<0

**分步论证（待教师确认）**
1. 多项式在实数闭区间[a,b]连续，因此可调用介值定理。
2. 端点函数值严格异号，0严格处于两值之间，于是存在ξ∈(a,b)使f(ξ)=0。
3. 二分时在包含异号端点的半区间继续，不能把异号条件误说成任意区间均有根，也不能据此声称根唯一。

**违反前提的反例**：f=x²−2在[2,3]两端均正，不能以异号介值定理保证根。
**典型错因**：不检查连续性或端点符号，或把存在性冒充唯一性。
**例题**：f=x²−2在[1,2]执行首次二分。
**教师侧解答**：f(1)=-1、f(2)=2；中点3/2，f(3/2)=1/4>0，新的异号括区为[1,3/2]。
**三级提示**：检查f的连续性以及区间端点是否严格异号。 → 使用介值定理先证明至少存在一个零点，不要直接断言唯一。 → 在中点求f值后决定应保留哪对异号端点；中点为根则停止。
**近迁移**：讨论f(a)=0时为何无需再断言开区间有根。
**远迁移**：比较f=x²−1在[-2,2]的多根情况，解释介值定理不证明唯一性。

**发布状态**：REVIEW_PENDING / TEACHER_ONLY / NOT_FORMALLY_VERIFIED

## KB79-P07｜抛物线焦点—准线距离定义

**原有风险步骤**：math.hs.geometry.parabola-focus#1（SHA256: 879fc25353c0bc3f95942f5e836bb51632c81b2e9a6435959ef34476491d957d）
**准确命题**：对p>0，曲线y²=4px上任一点P到F=(p,0)与准线x=−p距离相等。
**前提**：p>0；P=(x,y)实坐标；y²=4px

**分步论证（待教师确认）**
1. 点P到焦点距离平方为(x−p)²+y²。
2. 利用曲线条件y²=4px变换为(x+p)²，且p>0保证曲线点x≥0从而x+p>0。
3. 至准线x=−p的距离为|x+p|，两种非负距离平方相等，故距离相等。

**违反前提的反例**：p=0时方程退化为直线y=0，焦点—准线重合，不能当作非退化抛物线。
**典型错因**：把任何满足y=0的直线点当作p=0的抛物线点。
**例题**：p=2、P=(2,4)验算。
**教师侧解答**：4²=4×2×2=16；到焦点(2,0)距离4；到直线x=-2距离4。
**三级提示**：写出点到焦点与点到竖直准线的两个距离。 → 先比较距离的平方，并将曲线方程代入消去y²。 → 把平方相等转回距离相等时确认两边都是非负的。
**近迁移**：改变p与合法整数点验证平方距离恒等。
**远迁移**：把焦点定义推广到旋转抛物线时先给出旋转坐标与准线。

## KB79-P09｜圆的一般方程配平方与非退化半径

## KB79-P10｜一元带截距最小二乘的唯一性条件

## KB79-P11｜总体型经验方差的仿射变换

## KB79-P12｜三角形余弦定理及退化边界

**原有风险步骤**：math.hs.triangle.cosine-law#4（SHA256: 6355593cf29608e87c8798e4f6b7f3196a64335cfb8986523d5c0e2593b54208）
**准确命题**：在非退化三角形中，夹角C对应对边c、邻边a,b时cos C=(a²+b²−c²)/(2ab)。
**前提**：a,b,c>0；严格三角形不等式；a,b为夹角的邻边

**分步论证（待教师确认）**
1. 在角C的两条邻边上取向量u,v，长度分别为a,b，夹角C。
2. 对边向量为u−v，故c²=||u−v||²=a²+b²−2u·v。
3. u·v=ab cos C且ab>0，合法移项并除2ab，得到公式；退化边长不得套用内角定义。

**违反前提的反例**：边长1,1,3违反三角形不等式，代公式得到越界余弦值，不能称三角形内角。
**典型错因**：只检查余弦公式的代数值，却没有判断三条边能否构成非退化三角形。
**例题**：a=3,b=4,c=5时求C。
**教师侧解答**：cos C=(9+16−25)/(2×3×4)=0，所以C=90°。
**三级提示**：先验证三边能组成严格非退化的三角形。 → 把夹角两边看作向量，利用对边等于它们的差。 → 展开差向量的平方范数后检查能否合法除以2ab。
**近迁移**：构造等边三角形验证cos60°。
**远迁移**：迁移到三维向量求夹角时检查非零向量和角的取值范围。
