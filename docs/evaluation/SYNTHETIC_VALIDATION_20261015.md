## 发现与修复
1. 旧版按关键词选择提示，重复卡住可能重复问同样的问题。新增显式阶段自报与 `P50_REPEATED_STUCK_SWITCH`，检查“连续两次停滞→寻找两端桥梁”分支。
2. 旧版检索只看字面和方法标签。新增自编语料 + 本地倒排索引、透明排序、必要结构门控和失效情形排除。已验证“椭圆焦点定和”不是“椭圆切线”同一方法。
3. 初次自检显示独立模式虽输出 WAIT，却在 JSON 的 `knowledge_refs` 中暴露了候选方法 ID。改为学生接口默认不返回候选方法编号，重新跑评测为 19/19。
4. 不可靠的自由文本“检查步骤”仍不能直接判定正确。新增白名单表达式恒等检验，只支持限定形式，拒绝恶意表达式，标记 domain caveat。
5. 所有学习证据仍只是合成示例和自述完成；不得当成学生已经掌握或真实教学效果数据。

## 不得误读指标
- 19/19 是人工编写的**场景-策略符合率**，不属于 LLM 教学质量、学习成绩或数学泛化性能测量。
- 36 项通过意味着接口和规则的指定行为通过测试，并不是对真实中高考试题全覆盖。
- 8 条文档为自编待教师审核材料，不是实际教材库和经过版权确认的完整外部 RAG。
