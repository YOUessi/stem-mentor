## 1. 自然常数的正项级数部分和｜KB33-A-P052-A005

**数学命题：** 数列s_n=∑_{k=0}^n 1/k!严格递增且小于3，因而收敛，所得极限定义自然常数e。
**符号：** s_n=∑1/k!; 0!=1
**条件：** n为非负整数；各项1/k!为正

**逐步推导（每步说明理由）：**

1. 相邻两项部分和差1/(n+1)!严格正。依据：阶乘为正，故单调递增。
2. k≥2时k!≥2^{k-1}。依据：逐因子比较，可由归纳证明。
3. 后缀项和小于对应等比级数1，故s_n<3并收敛。依据：实数单调有界收敛定理。

**典型错误：** 任意正项级数必收敛
**具体反例：** 调和级数∑1/k虽为正项级数，其部分和却无上界
**不适用原因：** 正项保证单调，不保证上界

**教师例题1：** 请按步骤计算：求s_3
步骤：①列出0!、1!、2!、3!的倒数；②求和1+1+1/2+1/6。
答案：8/3。验证：8/3在2和3之间。

**教师例题2：** 比较s_4与s_3
步骤：①计算差s_4−s_3；②差等于1/4!=1/24。
答案：s_4>s_3。验证：严格正项使其上升。

**方法边界：** 本稿不证明自然常数其他极限构造的等价性；课标编辑候选关联不构成官方条文逐条认证或旧稿数学等价认证。
**错因与修复问题：** 任意正项级数必收敛；正项保证单调，不保证上界；如何检查该主张遗漏的数学适用条件？
**三级提示：** 比较相邻部分和，先找出多出来的那一项。 → 只讨论从 k=2 起的尾部，找一个便于求和的几何级数上界。 → 检查该上界能否随 n 统一成立，再决定能否使用单调有界定理。
**近迁移：** 先核查前提，再分步完成：用等比上界估计s_5

## 2. 矩阵乘法的维数与非交换性｜KB33-A-P054-A005

**数学命题：** A为m×n而B为n×p时乘积AB合法且为m×p；通常AB不等于BA，后者甚至可能无定义。
**符号：** (AB)_ij=Σ_{k=1}^n a_ik b_kj
**条件：** 矩阵元素为实数；内维必须匹配

**逐步推导（每步说明理由）：**

1. 检查左矩阵列数和右矩阵行数相等。依据：共享的求和下标k必须能逐项配对。
2. 输出位置是左矩阵第i行与右矩阵第j列内积。依据：依据该公式的定义及适用条件：有限求和的定义。
3. 交换顺序前必须重新检查内维，不能用数乘交换律。依据：依据该公式的定义及适用条件：矩阵乘法不交换。

**典型错误：** AB合法就说明BA合法且相等
**具体反例：** A为2×3、B为3×4时AB合法，BA无法定义
**不适用原因：** 反向内维4与2不同

**教师例题1：** 1×2矩阵(1,2)乘2×1矩阵(3,4)
步骤：①内维2一致；②1·3+2·4=11。
答案：[[11]]。验证：代入原题数据核对：输出1×1。

**教师例题2：** A=[[1,1],[0,1]],B=[[1,0],[1,1]]，两积是否相等
步骤：①AB=[[2,1],[1,1]]；②BA=[[1,1],[1,2]]。
答案：不相等。验证：矩阵乘法不交换。

**方法边界：** 逐元素乘法不同于矩阵乘法；课标编辑候选关联不构成官方条文逐条认证或旧稿数学等价认证。
**错因与修复问题：** AB合法就说明BA合法且相等；反向内维4与2不同；如何检查该主张遗漏的数学适用条件？
**三级提示：** 先分别写下两个矩阵的行数和列数。 → 检查共享维度后，选一个输出位置写出逐项内积。 → 尝试倒置乘法顺序，确认其乘积有定义才进一步比较。

## 3. 初等行变换的解集保持｜KB33-A-P055-A001

**数学命题：** 交换两行、某行乘非零数、某行加另一行倍数，作用于增广矩阵时都保持线性方程组解集。
**符号：** R_i↔R_j;R_i←cR_i(c≠0);R_i←R_i+cR_j
**条件：** 实线性方程组；常数列同步变换；倍乘因子不为0

**逐步推导（每步说明理由）：**

1. 交换两行只改变方程顺序。依据：联立约束的顺序不影响真假。
2. 倍乘非零数可通过乘倒数撤销。依据：非零数的乘法逆元存在。
3. 加上另一方程倍数可通过反向减法撤销。依据：保留另一行时操作可逆。

**典型错误：** 乘零也是保解集的初等行变换
**具体反例：** x=1乘0后变0=0，解集扩大为所有实数
**不适用原因：** 因子零导致不可逆

**教师例题1：** 对x+y=3及x−y=1施行R2←R2−R1
步骤：①第二行得到−2y=−2；②解得y=1，代回x=2。
答案：(2,1)。验证：两个原方程均成立。

**教师例题2：** x=1整体乘零是否保持解集
步骤：①原解集仅有x=1；②新约束0=0不限制x。
答案：不保持。验证：无法用逆操作恢复。

**方法边界：** 只改系数而不改增广常数列会改变约束；课标编辑候选关联不构成官方条文逐条认证或旧稿数学等价认证。
**错因与修复问题：** 乘零也是保解集的初等行变换；因子零导致不可逆；如何检查该主张遗漏的数学适用条件？
**三级提示：** 把每一行看作一个必须同时满足的等式约束。 → 思考某一步能否用对应的逆操作还原旧方程。 → 特别检查行倍乘为零时是否失去原来的约束。
**近迁移：** 先核查前提，再分步完成：消元求解一个三元系统
**远迁移：** 讨论近零主元为何影响浮点计算

## 4. 秩判相容性和解的自由度｜KB33-A-P055-A002

**数学命题：** Ax=b相容当且仅当rank(A)=rank([A|b])；相容时自由变量数是未知数数n−rank(A)。
**符号：** rank(A)=rank([A|b]); free=n−rank(A)
**条件：** A为m×n实矩阵，b为m维列向量

**逐步推导（每步说明理由）：**

1. 若阶梯形有0=c≠0的增广行则无解。依据：零系数行与非零常数矛盾。
2. 没有矛盾行则可任意指定自由变量再回代。依据：高斯消元的主元解法。
3. 主元数等于rank(A)，剩下n−rank(A)个自由参数。依据：主元列和非主元列的划分。

**典型错误：** 秩等于方程条数必然有唯一解
**具体反例：** 两方程x=1,y=2对三个未知数x,y,z的系数秩2，z自由
**不适用原因：** 唯一性要比较未知数数目n

**教师例题1：** x+y=2,2x+2y=4的解数
步骤：①行相关且一致；②取y=t得x=2−t。
答案：无穷多。验证：rank(A)=rank([A|b])=1<2。

**教师例题2：** x+y=2,2x+2y=5是否相容
步骤：①消元得0=1；②系数秩1，增广秩2。
答案：无解。验证：代入原题数据核对：秩不等。

**方法边界：** 近似最小二乘解不等于精确相容；课标编辑候选关联不构成官方条文逐条认证或旧稿数学等价认证。
**错因与修复问题：** 秩等于方程条数必然有唯一解；唯一性要比较未知数数目n；如何检查该主张遗漏的数学适用条件？
**三级提示：** 先对系数矩阵和增广矩阵分别数主元。 → 出现零系数而常数非零的行时，检查是否还有解。 → 相容后对比未知量个数与系数主元数，判断自由度。
**近迁移：** 先核查前提，再分步完成：分析三元单方程的自由度
**远迁移：** 说明传感器超定拟合何时没有精确解

## 5. 克拉默法则非零行列式条件｜KB33-A-P055-A003

**数学命题：** 对n阶实方阵A且det(A)≠0，Ax=b唯一解的第i分量是det(A_i)/det(A)。
**符号：** x_i=det(A_i)/det(A), det(A)≠0
**条件：** A是n×n方阵；A_i替换第i列为b

**逐步推导（每步说明理由）：**

1. 非零行列式保证A可逆，解唯一。依据：可逆矩阵的行列式判别。
2. 用b=Σ_j x_j a_j代入替换列。依据：行列式对列的线性性质。
3. 除第i项外均出现重复列而为0。依据：交替性给det(A_i)=x_i det(A)。

**典型错误：** det(A)=0就等于无解
**具体反例：** x+y=3,2x+2y=6时det=0却有无穷多解
**不适用原因：** 奇异只排除克拉默唯一解公式

**教师例题1：** 2x+y=5,x+y=3求x
步骤：①det(A)=1；②det(A_1)=2，除得2。
答案：2。验证：代入原题数据核对：代回y=1。

**教师例题2：** x+y=2,2x+2y=5能否套用
步骤：①det(A)=0；②分母为0，先做秩检查。
答案：不可套用。验证：代入原题数据核对：该系统无解。

**方法边界：** 病态但非奇异矩阵还需浮点稳定性分析；课标编辑候选关联不构成官方条文逐条认证或旧稿数学等价认证。
**错因与修复问题：** det(A)=0就等于无解；奇异只排除克拉默唯一解公式；如何检查该主张遗漏的数学适用条件？
**三级提示：** 首先确认系数阵是否为方阵，是否具备唯一解条件。 → 计算行列式并先判断能否除以它。 → 若行列式为零，改用行消元检查相容性，不套分式。

## 6. 连续概率密度与混合分布｜KB33-A-P056-A001

**数学命题：** 非负可积f在全实轴积分为1时可作为纯连续分布密度，区间概率是其积分；混合分布可能含有正单点概率。
**符号：** f≥0 a.e.;∫_R f=1;P(a≤X≤b)=∫_a^b f
**条件：** f可测且可积；仅讨论纯密度型概率测度

**逐步推导（每步说明理由）：**

1. 积分的非负性保证区间概率非负。依据：依据该公式的定义及适用条件：f几乎处处非负。
2. 全轴积分1保证总质量合法。依据：依据该公式的定义及适用条件：概率规范化。
3. 单点集合积分为0，因此纯密度分布点质量为0。依据：单点Lebesgue测度为零。

**典型错误：** 所有随机变量的P(X=0)都为0
**具体反例：** X有一半概率为0，另有一半概率在[0,1]均匀分布
**不适用原因：** 此例有离散原子，无法仅由常规密度表示全部质量

**教师例题1：** f(x)=2x在[0,1]、别处为0，是否合法
步骤：①各处非负；②积分0至1的2x得1。
答案：合法。验证：归一积分为1。

**教师例题2：** f(x)=2在[0,1]是否合法
步骤：①积分得到2；②超过总概率1。
答案：不合法。验证：代入原题数据核对：规范化失败。

**方法边界：** 密度值本身可以大于1，不等于概率；课标编辑候选关联不构成官方条文逐条认证或旧稿数学等价认证。
**错因与修复问题：** 所有随机变量的P(X=0)都为0；此例有离散原子，无法仅由常规密度表示全部质量；如何检查该主张遗漏的数学适用条件？
**三级提示：** 区分密度函数的函数值和事件的概率。 → 先检查非负性，再计算全空间上的总积分。 → 遇到单点事件时，先判断变量是否含离散质量。

## 7. Pearson拟合优度与小样本前提｜KB33-A-P057-A003

**数学命题：** 互斥穷尽类别的观察计数O_i与正期望计数E_i可形成χ²=Σ(O_i−E_i)²/E_i；其参考卡方分布是附条件的渐近近似。
**符号：** χ²=Σ(O_i−E_i)^2/E_i
**条件：** E_i>0，各O_i与E_i总和相同；渐近检验另需随机抽样和适当期望频数

**逐步推导（每步说明理由）：**

1. 按原假设概率计算每类E_i=np_i。依据：概率模型和样本量给出预期计数。
2. 平方残差按E_i标准化并求和。依据：各分母正且各项非负。
3. 区别统计量可算与参考分布近似可信。依据：过小期望频数或参数估计会改变近似表现和自由度。

**典型错误：** 算出χ²就总能用k−1自由度给出精确p值
**具体反例：** n=2分10类等概率时E_i=0.2，渐近近似不可靠
**不适用原因：** 小样本条件不满足

**教师例题1：** 四类O和E都为(10,10,10,10)求χ²
步骤：①每类残差为0；②总和0。
答案：0。验证：没有观测偏差。

**教师例题2：** O=(12,8), E=(10,10)求χ²
步骤：①每类贡献4/10；②合计8/10。
答案：0.8。验证：总观察与期望数都为20。

**方法边界：** 估计了分布参数后自由度可能需要减少；课标编辑候选关联不构成官方条文逐条认证或旧稿数学等价认证。
**错因与修复问题：** 算出χ²就总能用k−1自由度给出精确p值；小样本条件不满足；如何检查该主张遗漏的数学适用条件？
**三级提示：** 列出每个互斥类别的观察次数和模型期望次数。 → 逐项检查期望计数为正，再决定能否计算统计量。 → 计算完成后单独审查样本量和参数估计对参考分布的影响。
**近迁移：** 算三类(8,12,10)对(10,10,10)

## 8. 二阶导数判凸的充分条件｜KB33-B-P058-A002

**数学命题：** 二次可导实函数在区间上f''≥0可推出凸；f''>0可推出严格凸，但不是严格凸的必要条件。
**符号：** f''≥0⇒凸
**条件：** 在开区间二次可导，导数符号对区间每点成立

**逐步推导（每步说明理由）：**

1. f''≥0意味着f'非减。依据：对一阶导函数应用中值定理。
2. 斜率非减给出凸组合不等式。依据：割线斜率的有序关系。
3. 严格凸不要求二阶导数逐点严格正。依据：x^4严格凸而在0处二阶导为0。

**典型错误：** 严格凸要求f''处处严格大于0
**具体反例：** x^4严格凸，但f''(0)=0
**不适用原因：** 充分性不能反推必要性

**教师例题1：** x²是否严格凸
步骤：①二阶导恒2；②正二阶导给严格凸。
答案：是。验证：适用全体实数。

**教师例题2：** −x²是否凸
步骤：①二阶导恒−2；②中点函数值不满足凸不等式。
答案：否。验证：f(0)=0大于f(−1),f(1)平均−1。

**方法边界：** 二阶不可导时须回到凸性定义；课标编辑候选关联不构成官方条文逐条认证或旧稿数学等价认证。
**错因与修复问题：** 严格凸要求f''处处严格大于0；充分性不能反推必要性；如何检查该主张遗漏的数学适用条件？
**三级提示：** 先找到函数的定义区间与二阶导数是否存在。 → 若二阶导非负，考虑一阶导数的斜率如何变化。 → 不要将充分条件反推为必要条件；测试导数等于零的点。
**近迁移：** 先核查前提，再分步完成：验证|x|为凸函数

## 9. 中值定理与导数单调充分条件｜KB33-B-P058-A003

**数学命题：** 在闭区间连续、内部可导且f'≥0，则函数非减；若f'>0则严格递增，但逆向断言一般不成立。
**符号：** f(y)−f(x)=f'(c)(y−x)
**条件：** a<b，f在[a,b]连续、(a,b)可导，全区间内部导数符号给定

**逐步推导（每步说明理由）：**

1. 任取x<y，在[x,y]使用中值定理。依据：连续可导前提在子区间继承。
2. 函数差等于某个内点导数乘正差y−x。依据：拉格朗日中值定理。
3. 导数符号决定函数差符号。依据：依据该公式的定义及适用条件：正实数乘积保号。

**典型错误：** 严格递增必有处处正的导数
**具体反例：** f(x)=x³严格递增，f'(0)=0
**不适用原因：** 充分条件不是必要条件

**教师例题1：** x³在[-1,1]是否严格递增

**数学命题：** 名义年利率j每年m次计息、每期利率j/m且1+j/m>0时，t期金额为P(1+j/m)^t，有效年利率为(1+j/m)^m−1。
**符号：** F_t=P(1+j/m)^t;EAR=(1+j/m)^m−1
**条件：** P>0，m正整数，固定分期利率且无额外费用

**逐步推导（每步说明理由）：**

1. 从名义j按m个计息期得到每期j/m。依据：名义复利报价约定。
2. 逐期按同一因子1+j/m递推。依据：依据该公式的定义及适用条件：等比递推公式。
3. 一年恰m期后用终值除初值减一。依据：有效年增长率定义。

**典型错误：** 名义年利率一定等于实际年利率
**具体反例：** j=12%、m=12时(1.01)^12−1>12%
**不适用原因：** 增加计息频率改变复利效果

**教师例题1：** 本金100，j=10%，半年复利一次，一年末
步骤：①每期利率5%；②100×1.05²。
答案：110.25。验证：有效年利率10.25%。

**教师例题2：** 本金100，j=10%，一年复利一次，一年末
步骤：①每期利率10%；②100×1.1。
答案：110。验证：实际年利率10%。

**方法边界：** 浮动利率、税费及违约不在此固定模型内；课标编辑候选关联不构成官方条文逐条认证或旧稿数学等价认证。

## 20. 固定期末年金现值与零利率分支｜KB33-E-P073-A007

**数学命题：** 期末等额A支付n期、固定贴现率i>−1时，现值PV=Σ_{k=1}^n A/(1+i)^k；i≠0时为A[1−(1+i)^(−n)]/i，i=0时为nA。
**符号：** PV=Σ A/(1+i)^k; i=0⇒PV=nA
**条件：** A≥0，n正整数，固定每期利率i>−1，付款均在期末

**逐步推导（每步说明理由）：**

1. 每期期末第k笔现金流折现k期。依据：依据该公式的定义及适用条件：现值定义。
2. i≠0可用等比级数有限和。依据：公比(1+i)^−1≠1。
3. i=0每笔折现系数都是1。依据：依据该公式的定义及适用条件：此时不可除以i。

**典型错误：** 零利率仍可将年金闭式直接除以i
**具体反例：** i=0时闭式分母为零，正确PV=nA
**不适用原因：** 公式有必须单独处理的分支

**教师例题1：** 每期末付100共2期、i=0时现值
步骤：①每期折现因子1；②100+100。
答案：200。验证：代入原题数据核对：等于nA。

**教师例题2：** 每期末付110两期，i=10%时现值
步骤：①第一笔折现110/1.1=100；②第二笔110/1.1²=1000/11。
答案：2100/11。验证：约190.909。

**方法边界：** 期初支付和浮动利率改变折现指数，不可沿用本公式；课标编辑候选关联不构成官方条文逐条认证或旧稿数学等价认证。
**错因与修复问题：** 零利率仍可将年金闭式直接除以i；公式有必须单独处理的分支；如何检查该主张遗漏的数学适用条件？
**三级提示：** 先确认每次付款在期初还是期末。 → 逐期写出折现因子，观察是否构成等比数列。 → 套用求和闭式前，先把贴现率为零的情形单独处理。
