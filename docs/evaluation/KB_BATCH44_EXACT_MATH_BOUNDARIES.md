# STEM Mentor Batch44｜20 个有限精确数学见证：数学边界与适用条件

> 对应 `backend/app/kb_batch44_exact.py`，代码以 Mac 原始整数与 `fractions.Fraction` 运算。所有合法实例的状态是 `FINITE_EXACT_CASE_ONLY`；未验证自由文本、一般定理、真实教师批准、学生发布均为 **false**。这些检查不是 SymPy 定理证明，不支持任意 Python 表达式、`eval` 或动态执行。

## 按课程编辑目标绑定的算子与合法性

| 序号 | 算子 | 受控数学陈述 / 条件 | 代表性负例 |
|---:|---|---|---|
| 01 | `set_predicate` | 固定有限且元素互异的整数论域；筛选 `x>threshold` 且 `x mod divisor=0` | 整除数为 0；论域重复 |
| 02 | `set_symdiff` | 两集合必须均为已固定全集的子集，计算成员真假异或 | 某成员不在全集 |
| 03 | `function_table` | 每一输入只有唯一输出；重复输入同输出合法 | 相同输入对应不同输出 |
| 04 | `maximum_on_interval` | 仅针对 `f(x)=x` 且有限整数端点的区间：右端点纳入才取到最大值 | 左端不小于右端，或端点标记不是 0/1 |
| 05 | `real_power_domain` | **既约**分数 `p/n` 且 `n>0`；负底数需奇分母，零的负幂及 `0^0` 拒绝 | `(-16)^(1/2)` 或 `0^0` |
| 06 | `rational_power` | 底数为有界整数，`p/n` 既约；仅返回整数完美 `n` 次根下的精确有理数值 | 负数偶次根；不能精确表示的无理根返回 `CONDITIONS_NOT_ESTABLISHED`，不是“数学上不存在” |
| 07 | `positive_exp_law` | 正**整数底数**和整数指数的精确幂运算律测试；不涵盖全体实指数 | 非正底数 |
| 08 | `positive_exp_monotonic` | 有界正有理底数 `a≠1`，比较两个整数位置 `x<y` | 底数 1、零分母或未严格排序 |
| 09 | `log_inverse_integer` | `a>1` 为有界整数，`x=a^k` 且整数 `k` 的构造见证，不支持一般实对数求值 | 底数 1 |
| 10 | `angle_degree_to_radian` | `degree/180·π` 的精确有理系数，角度整数范围 `[-720,720]` | 浮点、布尔角、越界角 |
| 11 | `vector_equal` | 两个二维整数向量逐分量比较 | 非二维输入 |
| 12 | `zero_vector_direction` | 仅判零向量是否具有通常的几何方向，不推断“与其他向量垂直” | 非二维向量 |
| 13 | `displacement` | `B−A` 的二维坐标差 | 点坐标不是二维 |
| 14 | `triangle_vector` | `(B−A)+(C−B)=C−A`，在整数分量上独立检查左右值 | 缺失第三点分量 |
| 15 | `vector_scale` | 二维整数向量乘精确有理标量，允许负标量和 0 | 标量分母为零 |
| 16 | `vector_dot` | 二维标准欧氏内积，不因某向量为零而拒绝代数内积 | 错误维度 |
| 17 | `vector_projection` | 参照向量 `v≠0`，输出 `(u·v)/(v·v)·v`，再验证残差与 `v` 正交 | 参考向量为零 |
| 18 | `complex_parts` | `a+bi` 的实/虚部两项必须为真实整数输入 | 将 `real` 注入字符串 |
| 19 | `complex_equal` | 两复数实、虚部独立相等 | 布尔伪装成整数 |
| 20 | `complex_modulus_sq` | 返回复平面点 `(a,b)` 和模长平方 `a²+b²`；不把同模长误判为同点 | 浮点参数或超范围数值 |

## 需要进一步审查的数学与教学风险

1. **等价和充分条件方向**：有限见证只能验证给定输入；“所有实数”“所有集合”等无限论域的定理仍需人工检查逐步证明的每个量词与前提。
2. **负底数有理指数**：必须先将指数化为既约分数，再讨论奇分母；任意负底数的 `exp(p ln a)` 不是实数模型。代码只认证可确切写成整数根的有界案例，不能把不支持的无理根误报为数学错误。
3. **最大值**：算子只覆盖 `f(x)=x` 的具体区间，不能据此推出任意函数在开闭区间上的最值存在性。
4. **向量夹角**：零向量数量积可以计算，但零向量的单位化、夹角和投影方向未经定义。零内积不可无条件推出“两向量夹角为 90°”。
5. **复数**：模长相等并不意味着复数相等；虚部是实系数，不是 `bi` 这一整项。
6. **安全边界**：所有算子严格限定 JSON 字段，拒绝超额字段、非法类型、超长数组、非有限整数和伪造审批字段。算法没有执行字符串；学生侧审核稿检索投影为空。
7. **课程边界**：20 个目标来自此前项目自编、尚未完成官方等价认证的课程编辑账本；不等于已经确认的课标原子分母。未经真实教师审核始终 `REVIEW_PENDING`。
