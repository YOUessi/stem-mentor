## KB68-ATOM-01 · 元素属于与集合包含的类型区别

**来源坐标**：KB61-P015-L010（课标印刷页15；局部 SHA=4498250c58f78733…）。
**关联父级草案**：KB64-DEEP-01。官方条款审核仍未完成。

**数学陈述**：在论域明确且元素类型固定时，x∈A表示对象属于集合；B⊆A表示集合B的每个元素属于A，两者左右对象类型不同。

**适用前提**：论域D明确；A、B均为D的子集；x是D的对象

**教师侧论证（未形式认证）**

1. 先固定x和B分别是什么类型，属于关系的左侧是元素。
2. 再把B⊆A改写为∀t∈B,t∈A，逐元素验证。
3. 空集是任意集合的子集，但它不必是该集合的一个元素。

**教师侧例题（不得用于独立挑战提示直接泄漏）**

- 题：A={1,2}，判断1∈A及{1}⊆A。 解析：两者均真；前者元素1在A内，后者单元素集合的全部元素在A内。
- 题：A={1,2}，判断{1}∈A及∅⊆A。 解析：前者假，后者真；A的元素是数字，空集包含关系没有反例。

**不适用例/边界**：若A={∅}，则∅∈A恰好为真；不能一概说空集不是元素。

**典型错法**：把1⊆{1,2}当作普通子集命题。
**错误原因**：数字和集合类型混用，不能通过枚举元素得到正确判断。

**分层提示**：确认题中左侧究竟是一个对象还是对象构成的集合。 → 将子集关系展开成对集合内每个元素的检验。 → 比较空集及单元素集合在两种关系中的不同。

**近迁移**：设A={0,1}分别判断{0}⊆A与{0}∈A。
**远迁移**：数据库的一条记录是结果集合的元素，筛选条件所定义的子集是记录集合，两者含义不同。

**审核**：REVIEW_PENDING；证明 NOT_FORMALLY_CERTIFIED；学生发布 false。

## KB68-ATOM-02 · 双向包含判定集合相等

**来源坐标**：KB61-P015-L015（课标印刷页15；局部 SHA=91a4c245e607db61…）。
**关联父级草案**：KB64-DEEP-02。官方条款审核仍未完成。

**数学陈述**：两个集合A=B当且仅当A⊆B且B⊆A，不能仅靠一侧包含或元素个数相同推出相等。

**适用前提**：A与B均已定义，且在同一论域中讨论成员资格

**教师侧论证（未形式认证）**

1. 证明A⊆B保证A中每个元素都属于B。
2. 证明B⊆A保证B中每个元素都属于A。
3. 双向包含表明成员资格逐对象一致，按外延定义得到A=B。

**教师侧例题（不得用于独立挑战提示直接泄漏）**

- 题：A={1,2},B={2,1,1}，判定相等。 解析：相等；重复和排列次序都不改变集合。
- 题：A={1},B={1,2}，判定A=B。 解析：不相等；尽管A⊆B，但2∈B且2∉A。

**不适用例/边界**：两个有限集合都有两个元素但{1,2}≠{1,3}。

**典型错法**：检查A⊆B后直接宣布相等。
**错误原因**：缺少B⊆A方向，可能有B独有元素。

**分层提示**：先尝试从A找一个不属于B的对象。 → 再反向检查B是否含有A没有的元素。 → 分别检验两个方向后再决定能否写等号。

**近迁移**：判断{n∈Z|n²=1}与{-1,1}是否相等。
**远迁移**：比较两个解方程集合时分别证明每个解满足原式及原式每个解进入候选集。

**审核**：REVIEW_PENDING；证明 NOT_FORMALLY_CERTIFIED；学生发布 false。

## KB68-ATOM-04 · 双向蕴含与等价命题判定

**来源坐标**：KB61-P016-L007（课标印刷页16；局部 SHA=b4885ca7a81590c1…）。
**关联父级草案**：KB64-DEEP-04。官方条款审核仍未完成。

**数学陈述**：P是Q的充分且必要条件等价于P⇒Q与Q⇒P同时成立；任一方向单独成立不足以得到等价。

**适用前提**：P、Q是同一论域下可判定的命题

**教师侧论证（未形式认证）**

1. 从P出发推出Q建立充分性。
2. 反方向从Q出发推出P建立必要性。
3. 两个方向都完成才可以写P⇔Q。

**教师侧例题（不得用于独立挑战提示直接泄漏）**

- 题：实数x，P为x=2，Q为2x=4。 解析：P⇔Q，因为实数域中除以2合法且两向都成立。
- 题：实数x，P为x=1，Q为x²=1。 解析：P⇒Q，但Q⇒P不成立，x=-1是反例。

**不适用例/边界**：x²=4不能等价成x=2，因为x=-2同样满足原式。

**典型错法**：仅代入一个正例便使用等价变形箭头。
**错误原因**：见证一个满足实例不构成全称蕴含的证明。

**分层提示**：把命题分为前提P与结论Q两个方向。 → 先做P推Q，再尝试寻找Q成立但P不成立的见证。 → 两个方向都通过才考虑使用等价箭头。

**近迁移**：比较x>2与x²>4在实数域是否等价。
**远迁移**：编程前置条件P足以保障安全Q，不代表Q成立时P必然成立。

**审核**：REVIEW_PENDING；证明 NOT_FORMALLY_CERTIFIED；学生发布 false。

## KB68-ATOM-05 · 带明确论域的存在命题

**来源坐标**：KB61-P016-L014（课标印刷页16；局部 SHA=fecc925075ce5859…）。
**关联父级草案**：KB65-DEEP-01。官方条款审核仍未完成。

**数学陈述**：存在量词∃x∈D:P(x)为真，只需给出D内一个满足P的见证；为假则必须说明D内不存在见证。

**适用前提**：论域D明确；P(x)在D上有确定真假值

**教师侧论证（未形式认证）**

1. 从D选择一个允许的候选x。
2. 验证该x满足谓词P，即构成存在性证明。
3. 若要否定存在性，需论证对每个x∈D均不成立，而不是举一个失败候选。

**教师侧例题（不得用于独立挑战提示直接泄漏）**

- 题：D={-2,0,3}，P(x)为x<0，是否存在？ 解析：存在，x=-2是合法见证。
- 题：D={0,2,4}，P(x)为x²=1，是否存在？ 解析：不存在；三个候选的平方都不等于1。

**不适用例/边界**：在D=Z时∃x,x²=2为假；改成实数论域时为真，必须固定论域。

**典型错法**：检验x=0不满足后宣布不存在任何解。
**错误原因**：未对其他可能值排除，失败的一个例子不是全称否定。

**分层提示**：明确候选对象必须来自哪个论域D。 → 要证明存在，只需给出一个满足谓词的对象。 → 如果要否定存在，检查是否排除了整个论域。

**近迁移**：给出∃n∈Z:n²=9的两个见证。
**远迁移**：在有限数据表中找至少一条满足筛选条件的记录可见证存在，但查无数据要保证查询覆盖全集。

**审核**：REVIEW_PENDING；证明 NOT_FORMALLY_CERTIFIED；学生发布 false。

## KB68-ATOM-06 · 存在否定变全称的量词律

**来源坐标**：KB61-P016-L016（课标印刷页16；局部 SHA=4ce79f3a2c7b7f09…）。
**关联父级草案**：KB65-DEEP-02。官方条款审核仍未完成。

**数学陈述**：¬(∃x∈D:P(x))等价于∀x∈D:¬P(x)；否定量词时既交换量词又否定内部谓词。

**适用前提**：固定论域D；P在D上可判定

**教师侧论证（未形式认证）**

1. 存在命题为假，意味着论域内所有候选都不满足P。
2. 对每个候选的谓词取否定正好表达该条件。
3. 故不存在见证与所有候选均不满足是同一真假条件。

**教师侧例题（不得用于独立挑战提示直接泄漏）**

- 题：D={1,2,3}，否定∃x∈D:x<0。 解析：得到∀x∈D:x≥0，真假都为真。
- 题：D={-1,1}，否定∃x∈D:x=0。 解析：得到∀x∈D:x≠0；两者都为真。

**不适用例/边界**：把¬∃写为∃¬是错的：D={0,1}时∃x,x=0为真且∃x,x≠0也真。

**典型错法**：只给谓词加否定但不交换存在与全称。
**错误原因**：原式与新式同时可能为真，故不构成逻辑否定。

**分层提示**：先说明原命题要求找到怎样的见证。 → 思考使原命题为假的条件是没有任何合格见证。 → 否定时同时处理量词与谓词，而不是只改一个符号。

**近迁移**：否定∃n∈N:n<0并说明真值。
**远迁移**：权限系统中“不存在不合规记录”要求逐条满足合规条件，不能只找到某条合规记录。

**审核**：REVIEW_PENDING；证明 NOT_FORMALLY_CERTIFIED；学生发布 false。

## KB68-ATOM-07 · 方程除式与不等式的非零条件

**来源坐标**：KB61-P016-L024（课标印刷页16；局部 SHA=0dadc4fd03872509…）。
**关联父级草案**：KB65-DEEP-03。官方条款审核仍未完成。

**数学陈述**：由A(x)B(x)=A(x)C(x)推出B(x)=C(x)必须另有A(x)≠0；否则只能推出A(x)[B(x)-C(x)]=0。

**适用前提**：A、B、C在指定实数域定义；除法须已证明因子非零

**教师侧论证（未形式认证）**

1. 将两边移到同侧并提取A(x)为公因子。
2. 积为零说明A(x)=0或B(x)=C(x)，不能直接排除前者。
3. 仅在A(x)≠0的分支才可合法约去该因子。

**教师侧例题（不得用于独立挑战提示直接泄漏）**

- 题：解x²=x。 解析：x(x-1)=0，故x=0或1；除x会丢掉零根。
- 题：已知x≠0且x²=3x，求x。 解析：可以合法除以x，得到x=3；x=0被已知条件排除。

**不适用例/边界**：x=0时等式0·2=0·3成立但2≠3，直接反驳无条件消去律。

**典型错法**：把未知因子约去后未回代检查。
**错误原因**：约去操作不在因子为零处可逆，解集可能缩小。

**分层提示**：检查准备约去的表达式是否可能取零。 → 先写出乘积为零对应的两个分支。 → 只有在能证明非零的分支，才允许消去该因子。

**近迁移**：解(x-2)(x+1)=3(x-2)。
**远迁移**：分式约分与方程消元前必须保留原始分母零点的排除条件。

**审核**：REVIEW_PENDING；证明 NOT_FORMALLY_CERTIFIED；学生发布 false。

## KB68-ATOM-08 · 均值不等式的等号与定义域边界

**来源坐标**：KB61-P016-L026（课标印刷页16；局部 SHA=8669065b1e2d0601…）。
**关联父级草案**：KB64-DEEP-05。官方条款审核仍未完成。

**数学陈述**：对a,b≥0，有(a+b)/2≥√(ab)，等号当且仅当a=b；非负是实数平方根及结论的前提。

**适用前提**：a,b是非负实数；平方根为非负主值

**教师侧论证（未形式认证）**

1. 由于(√a-√b)²≥0，可展开为a+b-2√(ab)≥0。
2. 移项并除以正数2，得到均值不等式。
3. 等号等价于√a=√b，也就是a=b。

**教师侧例题（不得用于独立挑战提示直接泄漏）**

- 题：a=1,b=9，比较算术均值与几何均值。 解析：5≥3，且因a≠b严格大于。
- 题：a=b=4时求等号。 解析：(4+4)/2=4=√16，恰好取等号。

**不适用例/边界**：a=-1,b=-4时√(ab)=2，但(a+b)/2=-5/2，盲目套不等式会得到假命题。

**典型错法**：认为任意实数都能代入并取等号。
**错误原因**：忽略两数非负及等号a=b两项前提。

**分层提示**：列出均值不等式要求a和b满足的符号条件。 → 尝试研究两个平方根的差的平方是否为负。 → 分析平方差什么时候为零来判断等号。

**近迁移**：求非负a,b且a+b=10时ab的最大值。
**远迁移**：资源分配中的“均衡最优”只在模型的非负与总和固定条件下可由本不等式推出。

**审核**：REVIEW_PENDING；证明 NOT_FORMALLY_CERTIFIED；学生发布 false。

## KB68-ATOM-09 · 抛物线零点与重根的联系

**来源坐标**：KB61-P017-L009（课标印刷页17；局部 SHA=ed06d0509e6e3d89…）。
**关联父级草案**：KB65-DEEP-04。官方条款审核仍未完成。

**数学陈述**：非退化二次方程ax²+bx+c=0在a≠0且Δ=b²-4ac=0时有唯一实数根x=-b/(2a)，根的重数为2。

**适用前提**：a,b,c为实数，并且二次项系数a严格不为0

**教师侧论证（未形式认证）**

1. 配方得到(2ax+b)²=Δ。
2. Δ=0时左侧平方只能为零。
3. 因此2ax+b=0并得唯一实数根，二次因式重合。

**教师侧例题（不得用于独立挑战提示直接泄漏）**

- 题：x²-4x+4=0的根。 解析：Δ=0，唯一实数根2，且(x-2)²=0。
- 题：2x²+8x+8=0的根。 解析：Δ=64-64=0，唯一实数根-2。

**不适用例/边界**：a=0时不能套除以2a，例如0x²+2x-4=0是一次方程仍有实根。

**典型错法**：把Δ=0解释为两个不同的实数根。
**错误原因**：两根计重数为2，但它们数值相同。

**分层提示**：先确认方程确实具有非零二次项。 → 计算判别式并判断根是否会合并。 → 用配方法解释根的数值与重数的区别。

**近迁移**：写出以3为重根且首项系数为1的二次方程。
**远迁移**：数值算法在重根附近的函数值变动较小，不能将数值重复检测等同于两个不同根。

**审核**：REVIEW_PENDING；证明 NOT_FORMALLY_CERTIFIED；学生发布 false。

## KB68-ATOM-10 · 二次不等式判别式与边界点选择

**来源坐标**：KB61-P017-L012（课标印刷页17；局部 SHA=c20a110c0e8cd1ad…）。
**关联父级草案**：KB65-DEEP-05。官方条款审核仍未完成。

**数学陈述**：严格二次不等式ax²+bx+c>0的零点一律不属于解集；若a>0且两实根r1<r2，则解集为(-∞,r1)∪(r2,∞)。

**适用前提**：a>0且Δ>0；r1<r2为二次方程两实根

**教师侧论证（未形式认证）**

1. 将多项式分解为a(x-r1)(x-r2)。
2. 当x在根外侧时两因子同号，积乘a>0仍为正。
3. 零点处表达式等于0，不满足严格大于0。

**教师侧例题（不得用于独立挑战提示直接泄漏）**

- 题：解x²-1>0。 解析：x<-1或x>1；x=±1不满足严格不等式。
- 题：解2(x-1)(x-3)>0。 解析：x<1或x>3，根1和3排除。

**不适用例/边界**：同一表达式若改为≥0，则应包括两个根；边界由不等号决定。

**典型错法**：求根后把闭区间[-1,1]也并入>0解。
**错误原因**：忽略符号表或将严格不等式与非严格不等式混同。

**分层提示**：标出真实零点并区分严格与非严格不等号。 → 分别选择根左侧、两根之间及右侧的测试值。 → 根据因子符号推断整个区间并检查端点。

**近迁移**：求解-(x-1)(x-3)>0并解释开区间。
**远迁移**：参数化约束的可行域边界可能影响最优点是否取到，应保留端点开闭。

**审核**：REVIEW_PENDING；证明 NOT_FORMALLY_CERTIFIED；学生发布 false。

## KB68-ATOM-11 · 分段函数不同表示的同一性

**来源坐标**：KB61-P019-L013（课标印刷页19；局部 SHA=97b056feef8dabee…）。
**关联父级草案**：KB64-DEEP-06。官方条款审核仍未完成。

**数学陈述**：分段函数的定义须保证每个自变量在其定义域内有唯一函数值；重叠分支在交界点给不同值将不构成函数。

**适用前提**：每个分支有明确条件；交界点归属已指定

**教师侧论证（未形式认证）**

1. 先列出全部分支条件覆盖的自变量集合。
2. 对重复覆盖的自变量，检查不同分支赋值是否一致。

## KB68-ATOM-31 · 有限增量与线性近似误差的区分

**来源坐标**：KB61-P058-L035（课标印刷页58；局部 SHA=d76ed7329578e4d4…）。
**关联父级草案**：KB65-DEEP-17。官方条款审核仍未完成。

**数学陈述**：可微函数在x处的微分dy=f'(x)h是对有限增量Δy=f(x+h)-f(x)的线性主部，一般Δy≠dy。

**适用前提**：f在x处可微；h表示自变量增量

**教师侧论证（未形式认证）**

1. 可微定义保证Δy=f'(x)h+o(|h|)，其中余项随h趋零比|h|更小。
2. 定义dy=f'(x)h，故误差为Δy-dy=o(|h|)。
3. 非零有限h下余项通常不为零，不能把近似号改成等号。

**教师侧例题（不得用于独立挑战提示直接泄漏）**

- 题：f(x)=x²,x=2,h=1，比较Δy与dy。 解析：Δy=9-4=5，dy=4，误差1。
- 题：同函数x=2,h=1/2。 解析：Δy=25/4-4=9/4，dy=2，误差1/4。

**不适用例/边界**：f(x)=x²在x=0时dy=0但h=1的Δy=1；线性主部不等于有限变化。

**典型错法**：把dy=f'(x)h误写成任意步长的精确Δy。
**错误原因**：忽略非零二阶及高阶余项，只有极限意义的一阶近似。

**分层提示**：先写出实际有限增量，再写出导数的一阶线性项。 → 分别计算两者，观察差值如何随步长缩小。 → 只有说明余项规模后，才可把有限增量近似为微分。

**近迁移**：求f(x)=x³在x=1,h=1/10时的Δy与dy。
**远迁移**：误差传播计算中线性化只适合足够小的扰动，需要报告截断误差规模。
