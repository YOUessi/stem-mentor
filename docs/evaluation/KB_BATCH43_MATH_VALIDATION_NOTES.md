# Batch43｜24 个有限精确数学算子的定义域与独立审查（教师审核材料）

本文件对应 `backend/app/kb_batch43_exact.py`，不是课标官方分母、一般定理形式证明或学生自由作答证明的认证。运行结果 `FINITE_EXACT_CASE_ONLY` 只表示**在给定有界输入上**，程序按所列数学规则得到一个精确结果。格式无效、前提不满足、越界时应返回 `CONDITIONS_NOT_ESTABLISHED`，未知算子返回 `UNSUPPORTED`。目前没有任何真实教师批准记录。

## 一、24 个算子的数学定义和必须保留的前提

| 算子 | 精确计算内容 | 必要限制与常见反例 |
|---|---|---|
| `subset` | 在明确有限全集中检查 `∀x∈A, x∈B` | 集合元素必须属于全集；不能靠集合元素个数判断包含关系 |
| `complement` | `U\\A` | 补集依赖固定全集；改变全集会改变答案 |
| `sufficient` | 真值行逐项检查 `P⇒Q ≡ ¬P∨Q` | 输入仅为列明的有限真假行；不能声称覆盖无限论域 |
| `equivalent` | 各行检查 `P⇔Q`，两个方向都成立 | 只证 `P⇒Q` 并不能推出等价 |
| `neg_exists` | 有限论域 `¬∃x P(x)⇔∀x ¬P(x)` | 输入列举的真假行必须覆盖本次指定论域；空域可真，但不推广到未知域 |
| `quadratic_inequality` | 有限整数测试点上判断 `ax²+bx+c≤0` | `a≠0`；结果只是列出的测试点，并不是整个实数解集 |
| `change_base` | `log_(b^q)(b^p)=p/q` | `b>1`、`p,q>0`；底数为 1 或负数时实对数非法 |
| `unit_identity` | 检查 `u²+v²=d²` 是否成立 | `d>0`；仅验证归一化值的平方恒等式，不证明给定数来自某角 |
| `bisection` | 对 `f(x)=x²-c` 折半并保留根所在区间 | `c>0`、`0≤lo<hi`、端点严格异号，且 `f` 连续；不能用于不连续函数 |
| `parallel_nonzero` | 二维行列式 `u₁v₂-u₂v₁=0` | 两个二维向量必须均非零；零向量方向直观不能混用 |
| `perpendicular_nonzero` | 二维内积 `u·v=0` | 为几何夹角解释要求两向量非零；零向量没有通常意义下的夹角 |
| `ssa_acute` | 对锐角 `A`、对边 `a` 和邻边 `b` 以高 `h=b sin A` 分流 | `a,b>0`、`0<sin A<1` 且明确 `A` 为锐角；`a<h` 0 解，`a=h` 1 解，`h<a<b` 2 解，`a≥b` 1 解 |
| `induction_sum` | 有限 `Σ_{k=1}^n k=n(n+1)/2` 核对 | `1≤n≤100`；逐项有限值一致不是替代归纳证明 |
| `quadratic_derivative` | `[f(x+h)-f(x)]/h=2ax+b+ah`，同时报告 `2ax+b` | `h≠0`；令 `h=0` 直接代入差商是除零；导数来自极限 |
| `fermat_quadratic` | `f(x)=a(x-c)²+s` 的严格极值类型、**位置 c** 和函数值 **s** | `a≠0`，`a>0` 极小、`a<0` 极大；只针对该平方完成式，不能反推“所有驻点都是极值” |
| `plane_distance_squared` | `[n·(p-p₀)]²/(n·n)` | `n∈R³, n≠0`；零法向量不能定义平面，必须拒绝 |
| `line_slope` | `(y₂-y₁)/(x₂-x₁)` 或 `UNDEFINED` | 两点不同；竖直直线斜率不存在而不是零 |
| `circle_line` | 比较圆心到真直线的距离平方与 `r²` | `r>0` 且 `A²+B²>0`；相切时须允许等号 |
| `permutation` | `P(n,r)=n!/(n-r)!` | `0≤r≤n≤12`，位置顺序有意义；`r=0` 结果 1 |
| `combination` | `C(n,r)=n!/[r!(n-r)!]` | `0≤r≤n≤12`，内部顺序不重要；不能与排列数混淆 |
| `binomial_coefficients` | 枚举 `C(n,0),…,C(n,n)` | `0≤n≤12`；`n=0` 时只有一项 1 |
| `total_probability` | `Σ wᵢ sᵢ/(total·trials)` | 权重正且和为 total，`0≤sᵢ≤trials`；分组必须互斥完备 |
| `bayes_posterior` | `wⱼ lⱼ/Σwᵢlᵢ` | 先验权重归一、证据总分母严格正；似然不等于后验 |
| `discrete_moments` | `E[X]=Σpᵢxᵢ`，`Var(X)=Σpᵢ(xᵢ-E[X])²` | 概率非负且归一；这不是样本无偏方差 `Σ(x-μ)²/(n-1)` |

## 二、修复的具体失效案例：二次函数极值点平移

上一版 `fermat_quadratic` 的返回值硬编码 `MINIMUM|0` 或 `MAXIMUM|0`，虽然输入同时提供 `center` 与 `shift`，却从未参与结果。只检查 `f(x)=x²` 的例题时这个缺陷不会暴露。

本次把算子的数学对象明确为

\[
f(x)=a(x-c)^2+s,\qquad a\ne0.
\]

由于平方项非负，`a>0` 时所有实数 `x` 满足 `f(x)≥s` 且只在 `x=c` 取等号，因此严格极小点为 `c`、极小值为 `s`；`a<0` 时不等号反向，为严格极大点。导数 `f'(x)=2a(x-c)` 在 `x=c` 为零，但“驻点”一般不能反推“极值”，反例 `f(x)=x³`。

新增回归分别核对 `a=2,c=7,s=-5` → `MINIMUM|7|-5`、`a=-3,c=-4,s=6` → `MAXIMUM|-4|6`，并拒绝 `a=0` 的非严格极值假设。这种**变换平移与负曲率**的交叉测试是为了防止原点特例掩盖算法错误。

## 三、符号检查与范围边界

新增测试使用 SymPy 对二次多项式差商、导数、有限 `n=0…9` 的二项式展开、二点离散方差恒等式和非零贝叶斯证据归一进行独立符号检查。测试还独立核对 `C(n,r)` 对称性、`P(n,r)=C(n,r)r!`、数列有限求和以及各验证器的无效参数拒绝。

但一般三角恒等式、空间定理、抽样推断假设、长文本推导和学生自主证明**不在这些算子的自动证明能力范围内**。`general_theorem_certified=false` 和 `student_freeform_step_verified=false` 不能因 CI 通过而修改；教师批准及学生发布仍均为 0。
