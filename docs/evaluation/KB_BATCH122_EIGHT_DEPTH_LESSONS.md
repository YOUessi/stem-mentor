## 集合补集相对全集的元素判断（COMPULSORY）

**定义／定理表述**：在固定全集U中，A⊆U的补集是U\A={x∈U:x∉A}，它依赖所选全集，不是一个无上下文的绝对集合。

**符号**：U为研究全集；A为U的子集；\表示集合差；∈、∉为属于与不属于；∅表示空集。

**使用前提**：补集只能在明确的全集内定义，所有集合元素的类型与成员判定必须一致；要求A⊆U。

**为什么成立**：补集由两个同时满足的判断构成：在全集U中，且不在A中；去掉其中一个条件都会引入错误元素。

1. **固定论域**：先写U，再核对A⊆U；不在U内的元素不可出现在补集中。
2. **执行双重成员判据**：对每个x∈U，判断x是否在A，未在A中的元素进入U\A。
3. **复核分拆性质**：A∪(U\A)=U且A∩(U\A)=∅；利用两个等式交叉验证。

**边界条件与反例**：若U变更，A的补集随之改变；若A不是U的子集，需要先纠正对象约定。

**典型错误解法**：错误解法：U={1,2,3}、A={2}，因4不在A就把4放进补集。

**错误原因**：4不属于U，因此即使4不在A，也不满足补集定义中的x∈U条件。

### 教师示范解答（学生挑战不可直接检索）

1. U={1,2,3,4}, A={2,4}，求U\A。
   - 推理：从U中逐一检查是否属于A。；保留1与3，剔除2与4。
   - 结果：{1,3}
   - 精确检查：该集合与A不交，并集恰为U。
2. U={a,b,c}, A=∅，求U\A。
   - 推理：空集没有元素。；每个U中的元素都不在A。
   - 结果：{a,b,c}
   - 精确检查：A∪(U\A)=U且交集为空。

**三级提示**：先指出在哪个全集里取补集。 → 在U中逐一去除属于A的成员。 → 用并集为U、交集为空做复核。

**近迁移**：若U={0,1,2,3}，A={0,2}，比较补集与集合{1,3,4}是否相等。

**远迁移**：数据库查询中，NOT IN是否会自动得到所有数据？解释查询表的总体范围与NULL值为何会破坏直接类比。

## 充要条件的双向蕴含核验（COMPULSORY）

**定义／定理表述**：两个命题P、Q在同一个论域上充要等价，当且仅当P⇒Q与Q⇒P都成立；符号P⇔Q。

**符号**：P、Q为固定论域上的命题；⇒表示蕴含；⇔表示双向蕴含；反例是使前件真后件假的情况。

**使用前提**：等价判断需覆盖论域内所有允许取值；分别证明两个方向，而不是只展示若干个共同成立的实例。

**为什么成立**：P⇔Q在真值逻辑上等于(P⇒Q)∧(Q⇒P)，因此一个方向成立不能替代另一个方向的证明。

1. **明确共同论域**：例如讨论整数n或实数x，不在证明中变更对象类别。
2. **证明正向P⇒Q**：假设P成立，运用定义或已证事实推导Q，列出每步依据。
3. **证明反向Q⇒P**：独立假设Q成立推导P；若失败，寻找Q真而P假的具体反例。

**边界条件与反例**：逆命题并不自动成立；对平方关系x²=9要保留正负两个根，不能偷偷补入x≥0条件。

**典型错误解法**：错误解法：实数x=3能推出x²=9，所以x=3当且仅当x²=9。

**错误原因**：x=-3使x²=9成立却不满足x=3，正向成立但逆向失败。

### 教师示范解答（学生挑战不可直接检索）

1. 实数x，验证x²=9⇔x∈{-3,3}。
   - 推理：由x²−9=(x−3)(x+3)=0得x=±3。；分别代入±3均满足原等式，故两方向成立。
   - 结果：等价成立
   - 精确检查：零积定律与代入检验两方向完整。
2. 实数x，x>2与x>1是否充要等价？
   - 推理：x>2必有x>1。；x=3/2满足x>1却不满足x>2，逆向不成立。
   - 结果：不等价
   - 精确检查：反例3/2使逆蕴含为假。

**三级提示**：先问论域是整数还是实数。 → 把充要改写为两个明确方向。 → 尝试为逆命题寻找真前件、假后件。

**近迁移**：对实数x，判断x²=4与|x|=2是否等价，分两向证明。

**远迁移**：数学程序的输入验证条件只保证合法输入不会报错时，能否反推所有不报错输入都是合法输入？

## 分段函数按输入归属分支求值（COMPULSORY）

**定义／定理表述**：分段函数在不同输入子域采用不同的表达式；每个有效输入必须且只能对应一个函数值。

**符号**：D为定义域；D_i为分支子域；f_i为分支表达式；x为输入；端点包含性由<、≤、>、≥确定。

**使用前提**：分支子域需要覆盖整个定义域，重叠处必须表达式给出相同值；查询一个输入先判分支，后代入公式。

**为什么成立**：每个x属于哪个分支由条件确定，代入不适用分支等于将不属于该表达式定义域的规则误用于x。

1. **列明各分支域**：把严格与非严格不等号写清，例如x<0和x≥0恰好分割实数域。
2. **按输入选择分支**：检查给定输入满足哪个条件，分支重叠时核对输出是否一致。
3. **计算并检查边界**：只代入生效表达式，并对等号端点单独检查。

**边界条件与反例**：分支覆盖不完整会让某些点未定义；两规则在交集取不同值不是合法单值函数。

**典型错误解法**：错误解法：f(x)=x²(x<0)、x+1(x≥0)，计算f(0)=0，因为直接代入x²。

**错误原因**：x=0只满足x≥0的分支，正确值为1；0不属于第一段定义域。

### 教师示范解答（学生挑战不可直接检索）

1. f(x)=x²(x<0)，x+1(x≥0)，求f(-2)与f(0)。
   - 推理：-2<0，得(-2)²=4。；0≥0，得0+1=1。
   - 结果：f(-2)=4, f(0)=1
   - 精确检查：两点分别属于唯一有效分支。
2. g(x)=2x(x≤1)，3−x(x>1)，求g(1)与g(3)。
   - 推理：1≤1，得2。；3>1，得3−3=0。
   - 结果：g(1)=2, g(3)=0
   - 精确检查：端点1用第一分支而非第二分支。

**三级提示**：先看输入落在哪个区间。 → 注意端点的严格或非严格不等号。 → 只在所选分支代入表达式并复核结果。

**近迁移**：对f的第二段改为x+2，求f(0)，并判断f在0处是否连续。

**远迁移**：电子计费中不同区间收取不同费率时，为什么必须明确阈值属于左侧还是右侧区间？

## 连续函数异号端点的零点存在性（COMPULSORY）

**定义／定理表述**：若实函数f在闭区间[a,b]连续，且f(a)与f(b)异号，则开区间(a,b)至少存在c满足f(c)=0。

**符号**：a<b为实端点；f:[a,b]→R连续；f(a)f(b)<0；c是零点；闭区间连续性不能替换为端点存在。

**使用前提**：要求整个闭区间连续且端点严格异号；此结论保证存在性，不自动给唯一性或算法误差界。

**为什么成立**：由介值定理，介于f(a)与f(b)的数0必在函数取值中；端点不为零，故对应点位于内部。

1. **核对连续性**：需说明为什么f在整个[a,b]连续，例如多项式在全体实数连续。
2. **验证严格异号**：分别代入端点并计算乘积<0，保证零介于两函数值之间。
3. **引用介值定理**：得到存在c∈(a,b)使f(c)=0；若要证明唯一，另需单调性等条件。

**边界条件与反例**：阶跃函数在端点两侧异号但可以跳过0；端点同号时也可能有偶重根，不能作否定推理。

**典型错误解法**：错误解法：只因为f(-1)<0、f(2)>0，就认定任何函数都有且只有一个零点。

**错误原因**：不连续函数可跳过0；连续函数如x(x²−1)在[-2,2]有三个零点，异号不足以推出唯一。

### 教师示范解答（学生挑战不可直接检索）

1. f(x)=x²−2，在[-1,2]中说明零点存在。
   - 推理：多项式连续，f(-1)=-1<0。；f(2)=2>0，因此存在一个内部零点。
   - 结果：至少存在零点c=√2
   - 精确检查：√2位于(-1,2)，且c²-2=0。
2. f(x)=x³−x−1，在[1,2]中证明至少一零点。
   - 推理：多项式在[1,2]连续。；f(1)=-1，f(2)=5异号，故存在内部根。
   - 结果：至少存在一内部零点
   - 精确检查：异号端点及连续性已充分；不声称精确根式。

**三级提示**：先判断函数在整个闭区间连续与否。 → 分别计算f(a)和f(b)，要求严格异号。 → 只宣布至少一个零点；不要从异号推唯一性。

**近迁移**：对f(x)=x²−4在[-3,3]，端点同号时是否可以否定零点存在？请举出实际零点。

**远迁移**：数值二分法若函数在区间内发生不连续跳跃，异号端点为何不足以保证算法逼近真零点？

## 伯努利试验的二项分布建模条件（SELECTIVE_COMPULSORY）

**定义／定理表述**：独立重复n次成功概率固定为p的伯努利试验，其成功次数X服从二项分布P(X=k)=C(n,k)p^k(1−p)^(n−k)。

**符号**：n为非负整数；p∈[0,1]；X为成功次数；k∈{0,…,n}；C(n,k)为组合数。

**使用前提**：每次只有成功失败两结果，各次独立且成功概率相同；若不放回抽样造成依赖，需改用超几何模型。

**为什么成立**：某个固定成功失败序列有k次成功的概率为p^k(1-p)^(n-k)；恰有C(n,k)种序列且事件互斥，概率相加得公式。

1. **验证试验结构**：逐次确认二结果、相同p与独立性，不以试验次数n替代独立性假设。
2. **算一种成功位置序列概率**：因独立，k次成功和n-k次失败的联合概率为幂的乘积。
3. **统计所有位置组合**：有C(n,k)种安排，每一种互斥且概率相同，乘组合数得结论。

**边界条件与反例**：当p=0或1分布退化；不独立或异概率情形一般不能使用同一二项公式。

**典型错误解法**：错误解法：盒子里2红3蓝不放回取2个，认为第二次抽到红球概率仍固定为2/5。

**错误原因**：第一次抽到红球后剩1红4总，第二次红概率变成1/4，因此两次不独立。

### 教师示范解答（学生挑战不可直接检索）

1. n=3,p=1/2，求恰有2次成功概率。
   - 推理：C(3,2)=3。；乘(1/2)²(1/2)¹得3/8。
   - 结果：3/8
   - 精确检查：用独立三次伯努利公式得精确分数。
2. n=4,p=1/4，求一次也不成功概率。
   - 推理：k=0组合数为1。；计算(3/4)^4=81/256。
   - 结果：81/256
   - 精确检查：0次成功即全部4次失败且独立。

**三级提示**：先确认是否真的独立且每次成功概率相同。 → 组合数计算成功的k个位置。 → 一个指定序列概率乘以排列数量。

**近迁移**：把n=3,p=1/2题改成至少两次成功，列出k=2和k=3互斥两项。

**远迁移**：抽样检测若每件取样不放回，为什么样本数量接近总体时不应继续使用二项分布近似？

## 超几何分布的不放回抽样概率（SELECTIVE_COMPULSORY）

**定义／定理表述**：总体N件含K件目标物，不放回均匀抽取n件时，恰含k件目标物的概率为C(K,k)C(N-K,n-k)/C(N,n)。

**符号**：N,K,n为整数，0≤K≤N、0≤n≤N；k在max(0,n−(N−K))至min(K,n)间；C为组合数。

**使用前提**：总体内样品可区分，所有大小为n的无序子集等可能；不放回；分母C(N,n)>0。

**为什么成立**：全部大小为n的样本共有C(N,n)个，含k目标的样本需从K个目标选k个并从N-K非目标选n-k个，两选择独立计数组合。

1. **确定样本空间**：不放回且全部n元子集等可能，故分母为C(N,n)。
2. **分类计数有利样本**：分别挑k个目标与n-k个非目标，乘两种组合数。
3. **核验范围并约分**：只有可行k有非零概率；检查全部可行k概率和为1。

**边界条件与反例**：有放回抽取时样本空间改变，不能直接套超几何公式；k不在允许范围时概率严格为0。

**典型错误解法**：错误解法：N=5,K=2,n=2，恰好1件目标的概率直接写成2/5。

**错误原因**：2/5只是一抽命中率；两抽恰一命中时有C(2,1)C(3,1)=6个有利二元子集，总共10个。

### 教师示范解答（学生挑战不可直接检索）

1. N=5,K=2,n=2，求P(X=1)。
   - 推理：有利样本C(2,1)C(3,1)=6。；总样本C(5,2)=10，故6/10=3/5。
   - 结果：3/5
   - 精确检查：精确无序计数为6/10。
2. N=6,K=2,n=3，求P(X=2)。
   - 推理：有利样本C(2,2)C(4,1)=4。；总样本C(6,3)=20，故4/20=1/5。
   - 结果：1/5
   - 精确检查：k=2在可行支持集合中。

**三级提示**：先确认是有放回还是不放回。 → 分母计算总体抽n个的组合数。 → 分子按目标数与非目标数分别选取。

**近迁移**：将第1题改为恰好零件目标，写出完整组合数公式和结果。

**远迁移**：产品质检从一小批产品中连续抽样不放回时，为什么前几次结果会改变后续合格率估计？

## Pearson样本相关系数的定义域和范围（SELECTIVE_COMPULSORY）

**定义／定理表述**：成对观测(x_i,y_i)的Pearson样本相关系数r=Σ(x_i−x̄)(y_i−ȳ)/sqrt(Σ(x_i−x̄)²Σ(y_i−ȳ)²)，其值在[-1,1]。

**符号**：x̄、ȳ为样本均值；Σ为全部成对样本求和；r描述样本线性相关方向及标准化强度。

**使用前提**：至少两组成对观察，两个变量各自的样本离差平方和严格大于零；分母为零时r未定义。

**为什么成立**：中心化向量u,v的内积除以各自长度即夹角余弦，由柯西不等式得到|r|≤1；它不验证独立或因果。

1. **计算样本均值**：确保所有(x_i,y_i)同序配对，分别计算x̄与ȳ。
2. **中心化并检查分母**：形成u_i=x_i−x̄、v_i=y_i−ȳ；若任一平方和为0则停止。
3. **标准化内积**：分子为Σu_iv_i，分母为sqrt((Σu_i²)(Σv_i²))，所得r落在[-1,1]。

**边界条件与反例**：r=0表示样本没有线性相关，不表示统计独立；含异常值时r可能非常敏感。

**典型错误解法**：错误解法：所有x_i相同仍按公式把分母为0的r算作0，断言没有相关。

**错误原因**：零方差导致分母严格为0，相关系数不存在而非等于0；相关不意味着因果。

### 教师示范解答（学生挑战不可直接检索）

1. x=[1,2,3],y=[2,4,6]，计算r。
   - 推理：中心化x=[-1,0,1]，y=[-2,0,2]。；分子4，分母sqrt(2·8)=4。
   - 结果：r=1
   - 精确检查：两组中心化向量同向成比例。
2. x=[1,2,3],y=[6,4,2]，计算r。
   - 推理：中心化x=[-1,0,1]，y=[2,0,-2]。；分子-4，分母4。
   - 结果：r=-1
   - 精确检查：中心化向量反向成比例。

**三级提示**：样本必须一一成对，不能分别排序后再计算。 → 先检查两个变量是否都有非零方差。 → 把两个中心化向量的内积除以长度乘积。

**近迁移**：对x=[1,2,3]、y=[2,2,2]，解释为何不能算出r=0。

**远迁移**：预测模型使用Pearson相关很高的数据却在另一个地区失效，为什么相关不意味着因果及跨域稳定性？

## 三元齐次线性方程组的自由变量（ELECTIVE_B）

**定义／定理表述**：齐次实线性方程组Ax=0总存在零解；存在非零解当且仅当rank(A)<未知数个数n，解空间维数n−rank(A)。

**符号**：A为m×n实矩阵；x∈R^n；rank(A)为列秩；ker(A)为零空间；n为未知数个数。

**使用前提**：线性齐次方程组，使用保持解集的初等行变换或秩-零度定理；非齐次Ax=b须另外检查相容性。

**为什么成立**：映射T:R^n→R^m由T(x)=Ax定义；秩-零度定理给dim ker(A)=n−rank(A)，因此维数正才有非零向量。

1. **检查是否齐次**：确认右端确为零向量，故x=0总是可行解。
2. **行消元求矩阵秩**：使用可逆初等行操作求主元数r，保证新系统与原系统解集相同。
3. **计算自由度并构造解**：自由变量数n−r；若>0取一个自由变量非零可得非零解。

**边界条件与反例**：rank(A)=n时唯一解是零；rank(A)<n表示无穷多实解，不表示方程无解。

**典型错误解法**：错误解法：三元齐次方程组只要有两条独立方程就无解，因为条件少于未知数。

**错误原因**：两条独立方程给rank=2<3，至少有1个自由变量，事实上存在无穷多解。

### 教师示范解答（学生挑战不可直接检索）

1. A=diag(1,1,0)，求Ax=0的通解。
   - 推理：方程x1=0,x2=0，第三行恒等于0。；x3自由，写x=(0,0,t)。
   - 结果：(0,0,t), t∈R
   - 精确检查：rank(A)=2，零空间维数为1。
2. A=I3，求Ax=0的通解。
   - 推理：三行方程分别为x1=0,x2=0,x3=0。；rank(A)=3=n，故只有零解。
   - 结果：只有(0,0,0)
   - 精确检查：rank=3，零空间维数0。

**三级提示**：确认右边全是零，否则不是齐次系统。 → 消元找主元数，不要把方程数当秩。 → 用未知数数目减主元数得到自由变量维数。
