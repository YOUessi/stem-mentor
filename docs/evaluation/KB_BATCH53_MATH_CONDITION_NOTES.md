# STEM Mentor｜Batch53 K07 有界精确见证与课程前提边界

本批 K00 对 35 项课标来源编辑候选建立跨页**主题线索**；K07 追加七种独立有限例证，针对其中高风险的数学条件提供可重放负例。这些结果**不**认证通用定理、不构成老师批准，也不认证任何学生自由文本证明。

| 来源审计目标 | 有界精确例证 | 未满足前提 / 典型错法 |
|---|---|---|
| 第34页 U01/U02 古典概型 | 两个结果分别赋权 1 和 3，第二结果概率精确为 \\(3/4\\) | 只有有限个结果仍不能用 \\(1/2\\)；若要求古典等可能模式须拒绝 |
| 第41页 U03 部分和与通项 | \\(S_1,S_2,S_3,S_4=(2,5,10,17)\\) 对应 \\(a_1,a_2,a_3,a_4=(2,3,5,7)\\) | \\(a_n=S_n-S_{n-1}\\) 仅在 \\(n\\ge2\\) 直接调用既有的 \\(S_{n-1}\\)；首项 \\(a_1=S_1\\)（若另明确定义 \\(S_0=0\\) 才能统一） |
| 第41页 U04/U05 导数与求导法则 | \\(f(x)=5-3x+2x^2\\)，\\(f'(1/2)=-1\\)；\\(g(x)=(2x+3)^2\\)，\\(g'(1)=20\\) | 漏乘内层导数 2 会得到错误的 10；此处仅检验多项式与整指数线性复合 |
| 第34页 U03/U04 统计总体与采集 | 总体身份集 \\(\{a,b\}\\)，记录 \\([a,a]\\)，虽然数量相同仍不完整 | 计数相同不意味着逐一覆盖，必须核对身份与重复 |
| 概率跨单元的条件概率前提 | 权重 \\([1,3,1,5]\\)，事件 \\(A=\{0,1\}\\)，条件 \\(B=\{1,2\}\\)，得到 \\(P(A\\mid B)=3/4\\) | \\(P(B)=0\\) 时不定义，不能返回任意数字 |
| 第65页选修C U07 计息模型 | 名义年利率 \\(1/5\\) 每年复利两次，则实际年利率 \\((1+1/10)^2-1=21/100\\) | 未给计息频率不能混用名义与实际利率；选修案例不得作为全国必修课标覆盖 |
| 第35页数学建模活动 | 只对“数学结果可算”和“测量身份是否吻合”进行有限实例计算 | 计算例证无法证明现实模型外部适用性，也无法将探究活动变成形式化定理 |
