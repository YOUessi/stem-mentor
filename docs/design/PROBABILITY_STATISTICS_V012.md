## 九个数学场景

| 场景 ID | 可探索内容 | 核心边界 |
|---|---|---|
| prob-choose | 组合数 C(n,k)，与排列对照 | 不计排列顺序；k>n 不可能 |
| prob-permute | 排列数 A(n,k) | 计顺序；只在安全整数范围 |
| prob-tree | 两阶段条件概率树 | 四个叶子总概率=1；条件事件概率为0时条件概率未定义 |
| prob-binomial | 二项分布理论概率柱图 | p=0/1、n=0、均值方差、归一化 |
| prob-hypergeo | 有限总体无放回抽样 | 成功个数和样本量不超过总体；不独立 |
| prob-normal | 正态密度曲线和区间面积 | 密度高度不等于单点概率；σ>0；区间积分近似 |
| stats-bernoulli | 固定种子频率模拟 | 模拟频率≠理论概率，短时波动不能冒充证明 |
| stats-summary | 五个合成样本的描述统计 | 均值/中位数/众数、总体方差分母n、样本方差分母n−1 |
| stats-regression | 固定种子散点与线性拟合 | 样本相关不等于因果；x恒定时斜率未定义 |

工程实现为 apps/web/lab/probability_math.js 和 probability2d.js：纯数学固定模型与本地渲染分离，没有任意代码求值和在线模型调用。受控预设在 curriculum/highschool_math/extend_v012.py，所有内容标记项目自编和待教师审核。

## 防误导数学规则

- 组合和排列采用整数边界校验。二项与超几何只对合法事件返回概率；所有有效分布应满足概率质量总和为1。
- P(A)=0 时 P(B|A) 未定义；P(A)=1 时 P(B|非A) 未定义。零权重分支参数只用于构图，不是实际已定义的条件概率。
- 正态分布展示密度函数和有限区间数值积分；单点密度与区间事件概率是不同对象。
- 在线均值/二阶矩计算降低大偏移样本的数值误差；标准差与样本方差范围必须检查。
- 固定种子只用于合成数据复现；伯努利样本频率不是准确的理论概率，也不用于评价学生掌握。
- 回归在固定样本上求解，不宣称因果或对未知数据的普遍规律。

## 学习方式及权限边界

课程知识映射仍以原113条工程规划为基准，新建基础场景后才能更新具体条目；这些条目绝非官方高考逐条考纲，也不构成完整授课。正式使用前需教研审核、教材授权和未成年人隐私方案。
