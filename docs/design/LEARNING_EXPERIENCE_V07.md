# 绿色学习工作台 v0.7：数学表达、几何探索与思维关系图

日期：2026-10-17
代码与执行设备：MacBook Air
仓库位置：~/Documents/文件/stem-mentor
规则模拟模式，不调用任何 LLM API。不使用 Tang。

## 目标和边界

保留用户选择的 v0.5 白色/米白背景、绿色柔和主色、原有左右教学工作台与三种模式。只增加数学学习所需的精确能力，**不重绘整个页面**。

核心约束：
1. 学生看到的公式只能来自受控题目里已经公开的题设；不主动泄露完整标准解法。
2. 学生自由拖动几何点以形成观察和猜想；只有主动选择后才可沿题目约束探索，不能默认直接画出定比问题的完整轨迹。
3. 学生绘制思维联系时，必须标注“待验证”；任何连线都不代表证明成立。
4. 个人草稿仅按合成学生 ID 和会话 ID 缓存在浏览器本地；发送给后端后才成为真实学习事件。
5. 项目并未接入 OCR、真实几何证明、通用数学大模型或在线题库，不声称支持所有数学题目。
6. 本地合成学习会话无正式认证，不应采集未成年人真实数据。

## 一、公式排版与自主表达

- 数学排版使用 MathJax 3.2.2 的本地 tex-svg 打包文件、Apache-2.0 许可；不使用 CDN，不包含可下载的独立字体文件。
- 受控题库通过公开的 /api/study/visual/{problem_id} 返回题目已知表达式的 LaTeX，不含教师侧完整思维解法与隐藏证明。
- 15 道示例题全部设有已知数学表达式，其中定比轨迹、焦点距离和、椭圆切点附带几何探索场景。
- 草稿预览允许学生输入 \(...\) 内的受控数学命令，支持少量分数、平方根、基本不等号与运算；文本由 textContent 写入 DOM，而不是直接插入不可信 HTML。
- 预览严格限制长度、数量和命令集合，对不支持的命令保留原文并提示，不假装公式已经通过数学验证。
- 浏览器 MathJax 脚本并不参与学生答案评分；代数等价验证沿用已有受限 SymPy 接口。

## 二、可交互几何画板

已支持的受控题目场景：

| 题目 ID | 观察对象 | 默认展示 | 学生主动操作 |
| --- | --- | --- | --- |
| distance-ratio | A、B、P 的距离比 | 两定点、可拖动 P、比值实时读数 | 选择“沿题目条件探索”后可以观察自己的运动轨迹 |
| ellipse-focus | 动点到两定点的距离和 | 两焦点与实时距离和；不提前描绘答案曲线 | 在题设距离和约束下移动 P、尝试认识轨迹 |
| ellipse-tangent | 椭圆与曲线上动点 | 已给出椭圆和可拖动 P、代入方程值 | 可自主选择沿已知曲线拖动 P |

设计说明：
- 画板不绘制未知轨迹的“标准答案”；条件探索只显示学生自己拖动过的路径，不自动绘制完整圈/曲线。
- 默认是自由拖动；“沿条件探索”必须由学生明确点击。自主挑战模式也遵循该规则，不自动提供数学模型。
- 清除观察路径可随时重来；轨迹不会加入学生掌握度分数或当作数学证明。
- 可拖动 SVG 场景没有第三方图形 API，离线正常工作；读数仅为浮点数近似。
- 没有几何场景的题目不展示空画板。当前不支持开放题目自动生成可信几何图。

## 三、学生个人思维关系图

数据来源：GET /api/sessions/{session_id}/reasoning-map。该接口只包含题目明示的条件与目标及本会话学生的实际尝试，不包含教学结构图中的 teacher_only 节点。

- 已知条件/问题目标固定为图上的两个起始节点。
- 正向探索、卡点、逆向分析、寻找桥梁、常规计算等学生真实步骤依据诊断记录归类。
- 细灰虚线只代表学生尝试发生的先后顺序，**不表达数学蕴含**。
- 用户点击“连接我的两步思路”，再选择两个节点，并可填写理由；POST /api/sessions/{id}/thinking-links 将其记录为 STUDENT_HYPOTHESIS_UNVERIFIED，所有链接 verified=false。
- 关联必须从当前会话可见节点构成，禁止同节点自连、隐藏教师步骤、虚构节点；已完成的会话不能再编辑。模拟限制 30 条关联/会话。
- 点击节点能查看原始内容与未验证状态；刷新后重新加载真实数据库中的学生关联。
- 手机窄屏不将复杂 SVG 强行压到难以辨认，而切换到大字条件/目标卡和思维步骤列表，连线功能仍可操作。

## 四、工程结构

- apps/web/index.html：只在既有绿色卡片间增加公式、可折叠画板、预览和思维图容器。
- apps/web/styles.css：历史绿色主题原封不动；新增能力的局部绿色样式位于 apps/web/study_tools.css。
- apps/web/study_tools.js：只负责数学排版、几何交互、思维图读写、浏览器本地草稿；保留旧 app.js 业务 API。
- apps/web/vendor/mathjax/：固定版本的 tex-svg.js 和 LICENSE，离线运行。
- knowledge/study_visuals.json：明确受控题目的已知表达式与几何观察场景，禁止隐藏解决方案。
- backend/app/study_visuals.py：校验与读取可见数据。
- backend/app/storage.py：thinking_links 增量表，保存学生提出的未验证关联。
- backend/app/reasoning.py：思维图增加只读学生猜想边，保证 teacher_only 内容不可见。
- backend/app/main.py：只增加两个模拟接口，不改变现有对话功能。

## 五、验收规范

软件测试应区分：
- 后端接口规则、跨会话和隐藏节点访问限制、数据持久化。
- Chrome 真浏览器的 SVG 公式、距离数值拖动、主动轨迹显示、手机布局、草稿恢复。
- 同一学生正推→卡点→逆推后的结构化思维图是否展示真实步骤。
- 学生新建候选思维联系，刷新仍存在，且必须标注未验证。
- CSS 背景与主色继续是绿色/米白；没有替换成深色和蓝紫色方案。
- Playwright 没有外部 API 请求，用户草稿不能通过 unsafe innerHTML 注入。

教育效果验证仍须未来真实学生、教师参与的独立研究，本轮自动化模拟不能代替。
