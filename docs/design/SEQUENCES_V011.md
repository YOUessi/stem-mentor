# STEM Mentor v0.11：有限数列与启发式探索

日期：2026-10-19
工作设备：**MacBook Air**，目录 `~/Documents/文件/stem-mentor`。
保持原始绿色/米白护眼布局，不使用 Tang、不接入 LLM API，不上传真实学生数据。

## 用户需求与设计原则

数列教学重点是先观察条件、写下猜想、变换参数、检验例外，再解释方法迁移；
不是默认展示通项公式、完整求和步骤或把动画操作当成绩。
当前是规则模拟：根据学生自选 ANALYZE/GUIDE/INDEPENDENT 模式和自报思考阶段提供不同教学动作，没有对学生自由文本进行真正语义诊断，所有材料待教师审核。

## 一、数学内核

位于 `apps/web/lab/sequences_math.js`，可被 Node 与浏览器共同调用：

- 等差有限数列：首项 `a1`、公差 `d`、从 `n=1` 编号。
- 等比有限数列：`a1`、公比 `q`，明确 `q=1`、`q=0`、`q=-1` 和负公比。
- 一阶递推：`a[n+1]=r*a[n]+c`，兼容 `r=1`、`r=0` 等情况。
- 两项递推：`a[n+2]=a[n+1]+a[n]`，必须提供两个初值。
- 有限部分和：用 Kahan 补偿求和逐项计算，避免 `q≈1` 时直接套 `(1-q^n)/(1-q)` 引起 `0/0` 或严重消去误差。
- 有限范围等差/等比增长比较：显式标记“有限项观察，不能由有限实验直接证明无穷极限”。

范围：1≤n≤30 整数；所有输入必须有限；结果绝对值超出可显示上限明确报错，拒绝绘制 NaN/Infinity。

## 二、新增八个场景

| 场景ID | 内容 | 可观察的数学问题 |
|---|---|---|
| seq-arithmetic | 等差数列 | 相邻差是否保持不变？负公差能否迁移方法？ |
| seq-geometric | 等比数列 | 公比与符号、项增长或衰减的关系 |
| seq-geometric-edge | q=1、0、−1 等 | 求和公式的特殊情况、奇偶与退化 |
| seq-linear-recurrence | 一阶仿射递推 | 由当前项构造下一项，初值的影响 |
| seq-two-term | 二项和递推 | 为什么只有一个初值通常不够？ |
| seq-partial-sum | 部分和Sₙ | 从数列项到前n项和的关系 |
| seq-growth | 有限项比较 | 等差与等比的有限项绝对值对比 |
| seq-fixed-point | 固定点探索 | 何时有固定点，有限观察能否代替证明？ |

累计场景 **57** 个，九类实验室；高中数学工程知识目录保持 **113** 条，其中 **63** 条连接到具体基础实验，**50** 条仍规划中。
本清单是工程映射，不能冒充官方高考逐条考纲。

## 三、前端操作和规则教学

- 离散数列用“数列项/项号”散点及竖线，而非误连成连续函数。
- 默认只展示前五项（若n不足五则显示实际项数）；学生明确勾选后才展开全部n项与部分和第二张图。
- 支持“记录我的猜想”“需要一点启发”“重新独立思考”及三层渐进提示；可自选 START/FORWARD/STUCK/BACKWARD/CALCULATION/REFLECTION 阶段；提示不会声称智能理解学生自由输入。
- 当前显示的数学结构和参数由可信预设固定定义，不执行学生提交的脚本。
- 所有学生当前猜想只存在当前实验场景内，不写入个人学习成绩、完成题目或已掌握知识数据库。
- `sequence_policy.js` 额外根据三种学习模式及学生自报思维阶段提供确定性教学动作，仍不是 LLM。
