# STEM Mentor v0.11b：闭区间最值、驻点、端点与不可导点

日期：2026-10-19。保持原绿色/米白 STEM Mentor 界面，仅在 MacBook Air `~/Documents/文件/stem-mentor` 开发，Tang 不参与，模型 API 不调用，真实学生数据不使用。

## 教学目标

这批工具针对容易产生的错误认识：“求最大最小值，只要令 f'(x)=0。” 通过可见闭区间 [L,R]、端点 L/R、学生猜想及主动显示的候选点，训练三件事：

1. 判断候选点来自端点、驻点，还是不可导点；
2. 在题设的**闭区间内**比较候选点函数值，而非把局部极大自动认为全局最大；
3. 特殊参数（a=0）、常值函数、越过对数定义域等情况下明确说明限制和退化。

已有 `derivative-*` 画板继续保留，新增场景负责全局候选点的比较。展示数值是启发式可视化，不自动生成数学证明或判定学生掌握。

## 本批5个场景

| 场景 | 固定函数类型 | 候选规则 |
| --- | --- | --- |
| extrema-quadratic | `ax²+bx+c` | 端点 + 区间内部符合条件的驻点；a=0 退化 |
| extrema-cubic | `a(x³-3x)+k` | 端点 + x=±1（仅当属于区间且a≠0） |
| extrema-absolute | `a|x-h|+k` | 端点 + 区间内不可导折点 h；a=0 常值 |
| extrema-sine | `A sin(ωx+φ)+k` | 端点 + 实际位于区间内的三角驻点；支持负振幅/负角频率 |
| extrema-log | `ln(x)` | 整个闭区间严格 x>0 时，比较端点；否则拒绝输出假最值 |

数学内核 `extrema_math.js` 只支持这五个预设函数，`analyze` 不执行任意用户表达式，返回候选点、类别、全局候选值与`isProof:false`。常值函数返回所有区间内点均是最值位置；参数或区间不合法时返回`valid:false`。

画板 `extrema2d.js` 独立生成缩放后的绿色二维坐标，范围仅突出闭区间内函数图像；L/R 端点默认可见，内部候选点及最大/最小数值在学生主动勾选后才呈现。可以写下当前猜想，再逐级查看三层提示；草稿仅存在当前本地实验内，不改学习成绩或学生画像。

## 已发现并修复

- 正常求解 x=0 候选时可能产生 JavaScript -0；Node strictEqual 区分 -0 与 0，但数学坐标不应区分。先出现失败测试，再统一正规化为0。
- 生成器隔离重放测试需要同步引入新增的`extend_v011b.py`文件，避免“仓库本地能跑、临时重建失败”。
- 既有v0.11序列总数断言固定57；历史测试仍检查既有场景集合，v0.11b单独严格验证62场景。

## 边界

不支持任意输入的复杂函数、符号参数分岔或完整高考自动解题，不从数值绘图推断数学证明、真实学生效果或任何掌握度。闭区间连续函数的端点/驻点/不可导点比较原理由教师审核后可作为课堂材料。该版仍无开放式语言理解。
