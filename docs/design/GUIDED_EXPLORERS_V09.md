## 结构

- exploration_math.js：不依赖 DOM 的纯数学函数；Node 测试直接调用同一内核。
- explorers2d.js：复用已有二维坐标；只渲染本轮平面向量、单位圆与导数探究。
- sections3d.js：计算真实几何交点后复用已有三维投影，不通过屏幕像素估算截面积。
- controller.js：统一切换、参数联动、辅助图形显隐、键盘焦点恢复；共享文件由单一集成者维护。
- extend_v09.py：预设和课程证据映射；生成器可确定性复建版本化 JSON。
- check_v09.sh：并发运行 Node 数学、Python 后端、浏览器回归，保存每个进程退出码与日志摘要。

## 关键计算

### 向量与投影

加减、数乘、数量积和范数使用明确坐标运算。b 非零时，a 在 b 上的投影为 ((a·b)/|b|²)b；目标为零向量时返回 null 和未定义提示，而不是 NaN 或假定一个方向。投影场景不保留与计算无关的数乘 k 滑块。

### 差商与解析导数

二次函数差商使用 2x+h，三次函数使用 3x²+3xh+h²−3，避免极小增量下直接相减损失精度。对数使用 log1p(h/x)/h，且先检查 x>0、x+h>0。h=0 时可显示已经定义的解析导数，但绝不伪造差商。

默认先观察差商；解析切线须由学生主动选择。绝对值原点会显示左右差商不同，并不绘制唯一切线。这里是四个固定函数模型，不支持输入任意函数的自动微分。

### 凸多面体与平面相交

把平面归一化；计算各顶点到平面的有向距离；遍历真实棱并插值求交；按容差去重；在平面的正交基中按角度排序，得到真实截面多边形。截面积来自三维交点的平面面积公式，不随相机旋转变化。

零个、一点、两点和多边形分别返回 EMPTY、POINT、SEGMENT、POLYGON。球截面独立使用球心到平面的距离，返回 EMPTY、POINT、CIRCLE。数值容差不能代替严格数学证明。

## 教学与交互约束

辅助向量、投影、切线与切平面均支持学生主动显隐；不把一次可视化操作记录为独立掌握。数学实验室保持只读探究，不自动生成已解决题目或学习成绩。

二维/三维切换时清除旧场景的指针回调。SVG 重绘时仅恢复原本处于画布内的逻辑端点焦点，不抢走滑块或文字输入焦点。固定构图的单位圆与旧三角形不展示不起作用的缩放控件。

手机保留绿色/米白背景，场景与参数顺序阅读；照片/截图仅使用合成演示数据。

## 评测及局限

包括28个 Node 真值测试（其中一个循环检查240组截面）、后端完整回归、实际 Chrome 的全部39场景、20组极端参数、新增交互与连续键盘操作。每次验收记录代码版本、时间和真实退出码；不能把场景数、断言数、随机样本数相加冒充独立测试数。

当前没有子 Agent 调度工具，因此不声称使用多个 AI 代理。并行的是独立测试进程，使用临时数据库；实现和整合由当前执行者完成。代码审查是本次执行者的检查加自动化验证，不标为独立专家或教师审查。
