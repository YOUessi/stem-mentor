# 结构化数学推理、教学决策与检索引擎 v0.4

## 边界
当前是**无模型 API 的可复现离线原型**。学生真实输入尚未由通用语义模型解析；不支持任意题、任意数学证明或未经审核教材。下述模块均可通过实际接口运行与自动测试，但不代表具有真实 LLM 教学能力。

## 1. 结构化数学关系图
`knowledge/reasoning_graphs.json` 定义六道数学题的受控图，包含：`GIVEN`（题目已知）、`GOAL`（待求）、`FORWARD`（可能的正向推导）、`BACKWARD`（从目标反推的子目标）、`BRIDGE`（正反两端的潜在连接）、`BOUNDARY`（数学适用条件）。边标记 `POSSIBLE_DERIVATION`、`BACKWARD_SEARCH_NOT_PROOF`、`PROOF_OBLIGATION` 等关系，全部保留“未自动证明”状态。探索性逆向分析不能被当成形式证明。

`backend/app/reasoning.py` 校验图 ID/边/阶段，并为教学策略提供符合当前思维阶段的启发语。`GET /api/sessions/{id}/reasoning-map` 只返回**题目给定/目标+学生本人历史尝试**，不提前暴露教师内部桥梁节点；学生原始推导默认为 `STUDENT_CLAIM_UNVERIFIED`。

## 2. 可解释教学决策
`diagnosis.py`：显式学生自报阶段优先；否则保守地匹配有限的文本信号并附带来源与不确定性，无法从文本可靠判断真实思维状态。

`tutor.py`：实现 `P00–P56` 规则；先保护自主挑战不泄露，之后处理主动回忆、验证请求、反思，再对已覆盖题卡选择观察、目标反推、桥梁验证与边界检查。连续两次卡住时调整策略，避免重复同一句。只查找同一个学生真实完成过的、满足方法与结构共同条件的解题经历。

每轮响应返回 `next_action/decision_reason/decision_trace`，持久化到 `turn_annotations` 表中，便于复测；暴露给学生端的元信息不会包含隐藏的解法节点或检索到的候选方法编号。教学动作原因是规则判断依据，不是对学生心理活动的诊断结论。

## 3. 真实本地知识检索
`knowledge/corpus/methods.json` 当前为 8 条**自编数学方法与策略文档**，每条均包括知识解释、触发特征、先修知识、边界、来源、使用许可和审核状态 `PENDING`。这里的“真实”指从实际的独立文档索引中检索，不是逐题硬编码字符串筛选；**尚未接入外部开放教育资源、向量嵌入、教师审核完成的语料库**。

`retrieval.py` 构建 SQLite FTS5 倒排索引，中文通过连续二元字串（bigram）分词，英文/数学关键词分词，按 BM25 与结构标签匹配进行透明排序。必须通过 `requires` 的必要结构门控；如“椭圆焦点定和题”即使检索词有“椭圆切线”，切线方法也会被标记为条件不成立/无法建立。曲线外点或奇异点的切线捷径会触发禁用条件。仅仅匹配数学结构的标签仍不是严格的定理条件验证。

API：`POST /api/knowledge/search`，请求 `{query, problem_id?, top_k?, include_excluded?}`。返回实际命中的文档及摘要、来源、边界、条件状态、命中词和排序分项；`excluded` 可用于复盘拒绝理由。保留 `methods` 兼容原网页。仅将受控知识 **ID 数量** 给教学决策层作为信息输入，默认不泄露给自主挑战学生。

## 4. 受限符号计算验证
`POST /api/math/equivalence` 请求 `{problem_id, expr_left, expr_right}`。只接受白名单变量、整数、算术运算和 0–5 次文字指数，经 Python AST 白名单转换成 SymPy；不执行学生输入中的函数调用、属性访问、列表推导等代码。特定示例题 `inequality-bridge` 使用已知 `x+y=1` 代数代入，结果必须附带非零分母等限制。

结果 `EQUIVALENT_ON_DOMAIN` **只代表相应条件下的代数恒等检查**，不证明完整不等式、几何轨迹或任意自然语言推导；`NOT_EQUIVALENT_AS_IDENTITY` 不等于发现学生个人解题错误，`UNSUPPORTED` 明确说明无法验证。

## 5. 数据与 API
SQLite 额外 `turn_annotations` 表（`CREATE TABLE IF NOT EXISTS` 兼容旧演示库）记录阶段诊断和可复现决策记录。旧会话保留，没有相关注释时返回旧数据，不强制回填虚构诊断。

网页新增：自主报告当前思考阶段、查看决策动作编号、受限等价检查、知识检索结果与来源边界。教师解题图中的未揭示节点**不得**直接透传至前端。

## 6. 仍需研究的困难
- 真实自然语言数学语义解析、跨题同构检测，不可用简单双字串/标签代替。
- 证明构造、几何图形、非线性不等式与显式 domain proof 的验证。
- 教师审核语料、许可、真实中高考题纲及区域年份适配。
- 根据学生错误归因而不是关键词判断思维卡点。
- 有对照组的真实学习效果、提示渐退、迁移与延迟保持测量。
