# v0.10 高中基础数学对象：复平面、集合、区间与不等式

2026-10-19。目的：在已有绿色数学实验室内补齐已批准路线中的基础对象，让学生先观察输入、形成猜想，再主动显示结果进行核对；不生成整题解答，不自动判断掌握。

## 1. 交互范围

新增10个受控场景与3个工具族：
- 复平面：复数的点/模/辐角/共轭；两个复数的加减乘除；以原点为中心的旋转和非负比例缩放。
- 有限集合：U={1,...,N}，N为1至12；A、B的成员由学生编辑；交并差/对称差；相对U的补集与两条德摩根等式。
- 实数轴：一个区间、两个区间的交并差与相对R补集；开放或闭合有限端点、无穷射线；点的归属；一次、二次和|x-h|与r比较的不等式。

原39场景与三个教学模式保持。新的总计49场景、8类工具。113知识条目仍是工程清单，新增支持仅绑定实际预设；不改动官方课程来源、不冒充教师审核。

## 2. 数学真值与边界

### 复数
使用实虚部数组表示复数。除数精确为零才判未定义，不把小的非零数当零。零复数的辐角未定义；一般辐角为atan2结果（主值）；旋转含负角和多圈，缩放系数rho>=0。坐标和结果均写明数值近似，不声称任意输入的符号代数。

### 集合
全集、A、B都由真实有限成员计算，不靠圆的重叠面积或圆心距离决定集合关系。编辑表提供加入/移出A/B的开关，元素按所属区域排列，空集/包含关系通过成员与文字说明而不是改变圆的面积。补集严格相对于当前U。U变化后清理越界成员并告知；空集合、重复输入、U外输入有一致规则。

### 区间
内部单段表示{lo,hi,loClosed,hiClosed}，结果是排序、可并合的多个区间。lo>hi为空，不自动交换学生的两个端点；lo=hi只在两端皆闭时表示单点。无限端点永远开放。相接两段只要共享边界至少一段闭合才可合并；两侧都开放时保留缺口。补集相对实数集R，而不是当前屏幕显示窗口。

### 不等式
比较符为lt/le/gt/ge。一次按斜率符号决定方向；a=0成为常值判断。二次按判别式、实根及首项系数决定解集，a=0调用一次逻辑；使用稳定求根形式减少相消。重根、没有实根、恒成立/恒不成立明确展示。|x-h|<r等场景区分r<0、r=0、r>0。

这是有限参数、浮点计算的模型，不包含任意字符串解析器，不解决任意高阶/分式/指数参数不等式。图区只表示当前解集，不代替证明。

## 3. 输入与渲染合同

纯数学内核与DOM分离，Node真值测试直接调用生产函数。SVG模块只画内核结果；空心点表示排除有限端点，实心点表示包含；无穷端用箭头，不能把视口边界画成解集有限端点。

为离散选择增加数值型options元数据：运算符、端点是否开放/无穷通过下拉框而非有歧义的数字滑块。所有参数仍有min/max/step/value，旧数值滑块行为不变。

韦恩图使用原生SVG clip/mask区域与元素表，支持键盘。复数/有限端点拖动经controller统一同步，保留SVG重绘后的逻辑焦点。切换场景清理专用控件和旧事件。复平面可缩放；固定韦恩图/数轴隐藏不支持的2D缩放。

结果由现有“显示辅助图形”开关主动显示，文案为“显示运算/解集进行核对”。输入集合/区间始终可见，学生探针可用于核对单点。新工具不调用学生写接口、不写已解决题或掌握标记。

## 复查后的数值约定
二次不等式按参数控件给出的最短十进制数字解释系数。判别式符号和是否为零使用该十进制表示的整数运算判断，避免1.8、1.2、0.2这类参数的重根因二进制浮点相消丢失；平方根与根的位置仍为浮点近似。不对任意精确实数作符号证明声明，也不用固定epsilon抹平可区分的小判别式。
