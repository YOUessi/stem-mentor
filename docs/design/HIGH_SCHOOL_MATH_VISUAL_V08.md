## 3. 四类已实现动态可视化工具

### A. 二维直角坐标与函数图像（12 个场景）

包括一次、二次、三次、指数、对数、正弦、余弦、正切、绝对值、反比例、根式、分段函数。提供二维坐标系、数值位置探针、缩放、参数控制和适用条件提醒。

数学边界：实数对数底数必须大于零且不等于 1、真数必须大于零；正切和反比例函数必须在渐近线附近断开绘制；不应将数值曲线当作严格证明。

### B. 直线圆与圆锥曲线（6 个场景）

包括直线、圆、椭圆、双曲线、抛物线、直线与圆的位置关系。动态展示曲线、焦点、准线、渐近线、圆心半径和交点情况。

不套用任意未检查参数的“万能公式”。椭圆当两半轴相等会退化为圆；抛物线准线及焦点依据模型参数计算；直线圆交点从判别式判断。

### C. 三角形（3 个场景）

自由三角形允许拖动 A、B、C 三点、实时计算边长、内角与面积。直角三角形约束保持直角，独立展示边角变化。SSA 条件场景允许调整两边及一对角，展示 0、1、2 种符合几何存在条件的三角形，不把两个反三角函数候选不加检查地都当有效解。

### D. 空间直角坐标与立体（8 个场景）

支持右手空间 XYZ 坐标轴、正交三维投影、拖动旋转相机以及水平角、俯视角、缩放滑块。

具体场景：空间点与 XY 投影、空间向量与夹角、平面及法向量、棱柱、棱锥、球、圆柱、圆锥。几何数值由显式数学公式决定，改变视角不改变数学对象的真实大小。

三维 SVG 箭头端点只允许二维渲染坐标，不得将深度值作为第三个多边形顶点坐标；已将这一错误纳入浏览器回归测试。

## 4. 工程结构与接口

- 后端只读 API：GET /api/math-lab/catalog。
- 课程建设资料：curriculum/highschool_math/curriculum_map.json。
- 可调数学实验场景：curriculum/highschool_math/visual_presets.json。
- 两个源数据生成器：build_curriculum.py 和 build_presets.py。
- 数据审计：backend/app/math_lab_catalog.py；检查唯一 ID、工具类型及参数范围。
- 前端绘图引擎：apps/web/lab/plot2d.js、triangle.js、scene3d.js。
- 场景选择、参数滑块、课程筛选：apps/web/lab/controller.js。
- 增量绿色样式：apps/web/math_lab.css，不覆盖已有绿色 styles.css。

原有学习工作台仍是主要教学界面。用户必须主动点击导航或题目旁的“去数学实验室”才能打开独立实验室。涉及潜在泄露隐藏题目模型时，应默认展示通用类别而不是直接公布正确解法。

## 5. 验收规则

要求完成：
1. 113 条课程目录完整读取，29 个预设可独立切换并全部绘图，规划项不得伪装成已实现。
2. 二维函数定义域、参数数学性质、双曲线渐近线、椭圆焦点、抛物线准线及三角形实际边角由数值测试验证。
3. 三维 XYZ 点坐标投影、法向量、旋转相机和 SVG 多边形坐标有效，不能出现巨大箭头伪影。
4. 390、768、1024、1280 等视口无页面横向溢出。
5. 保留旧版原有三种教学模式、学生历史、知识库及微考点回忆。
6. 无外部 CDN、无 LLM API 调用、没有真实未成年人数据。
7. GitHub CI 及 Mac Chrome 完整回归测试通过，过程日志和测试结果按日期保存。

## 6. 覆盖全高中数学的后续路线

M1：平面向量专用拖动、复平面、单位圆、数轴与集合/逻辑图、空间截面和垂线投影。
M2：动态求导切线、数列与递推、函数组合与周期、解析几何参数变换和辅助线。
M3：概率树、排列组合、二项式分布、统计图、正态密度、回归与假设检验。
M4：数学建模数据实验、极坐标、可组合的约束与较高级立体二次曲面。
M5：每条知识及边界案例的教师审核、不同省份考试元数据、真实学生对照实验。

现在交付的是广覆盖的数学工具基础架构，而不是 113 个知识点已经逐一完成教学、考试训练或自动证明。
