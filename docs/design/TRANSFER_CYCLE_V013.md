# STEM Mentor v0.13：真实历史题目迁移与无提示思考证据

更新：2026-10-19
唯一开发与测试设备：MacBook Air，目录 ~/Documents/文件/stem-mentor。
保持第一版绿色护眼前端；不使用 Tang、不调用大模型 API、不输入真实学生或未成年人信息。

## 问题定义

当前教程的记忆回忆要求实际经历存在，然而“曾经完成旧题”只说明数据库里有学生自述的历史记录，**不意味着旧题做对、方法学会或成功迁移**。

v0.13 不追求生成任意新题答案，而是建立可审核的行为链：

**先独立尝试 → 自愿召回本人相似旧题 → 对比异同 → 再尝试 → 反思能否迁移。**

所有数据属于合成模拟，过程证据不代替独立数学评分。

## 现有工程中的实际约束

历史 Episode 每次仅在学生主动结束题目后创建，含 episode ID、真实所属 student ID、problem ID、受控的 method_tags 与 structure_tags。证据字段是 SELF_REPORTED_NOT_VERIFIED。绝不把自述完成升级为“正确解题”的事实。

历史题目匹配沿用已有保守规则：同一模拟学生完成过的另一道受控题，与新题至少共享一个方法标签以及两个结构标签，否则不推荐。**来源 Episode 必须在目标新题会话开始之前完成**；目标开始后补做的其他题不得追认为事前经验。即使满足，也只是“结构相近候选”，不意味着方法可以无条件套用。

## 双阶段协议（实际实现）

### BEFORE_RECALL：先冻结独立尝试

1. 新题在 INDEPENDENT 模式开始，学生自己写至少10字符的原始思路。
2. 后端检查会话没有记录导师实际提示：hint_count=0，之前已记录的导师动作只允许 WAIT。
3. 提交后记录当时的模式、提示计数、真实历史对话轮数及自报思维阶段，冻结原始文本，不能覆写。
4. **冻结前不从这个迁移流程暴露历史题目标题或方法**；避免诱导学生直接模仿旧题。
5. 即使零应用内提示，也不能推断学生没有使用外部辅导，状态只能写 NO_IN_APP_HINTS_OBSERVED_NOT_PROOF。

### 主动历史召回

完成基线后，用户才能看到数据库里已有的同学生、结构相近旧题标题。旧题身份只显示为“自述已完成、未数学验证”，不返回旧题完整解答。

点击召回按钮时调用原有 tutor_reply 的 recall 模式，实际保存一个带 reference_episode_id 的 RECALL_EPISODE 对话轮。

没有历史题时会明确显示 NO_MATCHING_HISTORY，不能虚构“以前做过”。其他学生的 episode ID 不能作为合法来源。

### AFTER_RECALL：再记录学习思考

需要满足三个条件：
- 本会话存在 BEFORE_RECALL 冻结记录；
- 来源符合当前结构匹配和同学生归属；
- 本会话已经实际发生并保存过引用同一来源的 RECALL_EPISODE 回忆事件。

学生重新写出当前题的思考，不是贴旧题答案。后端保存前后两个文本与元数据，但始终返回 math_verified=false、independent_mastery_verified=false、grade_assigned=false。

每个阶段一次提交，保证基线不能被后来的提示污染。并发重复提交被唯一约束当作冲突，而不是覆盖或崩溃。

## 实现文件

- backend/app/transfer_cycle.py：保守匹配、行为检查、状态机、无评分汇总。
- backend/app/storage.py：transfer_attempts SQLite 独立数据表，现有所有模拟学习数据保留。
- backend/app/main.py：GET /api/sessions/{id}/transfer、POST /api/sessions/{id}/transfer/attempts、GET /api/students/{id}/transfer-summary。
- apps/web/transfer.js / transfer.css：原始绿色学习工作台中的可折叠迁移面板，前后尝试记录与“我的解题经历”汇总。
- backend/tests/test_transfer_v013.py：同学生来源、阶段门控、跨学生隔离、无历史、无提示记录、重复提交等9项。
- tests/browser/test_transfer_v013.py：Mac Chrome 真实端到端、刷新持久化与390px移动端。

## 数据指标：当前可以评价什么，不能评价什么

可以统计：
- 真正冻结过多少个 BEFORE_RECALL 原始想法；
- 多少次有明确记录的历史题目回忆后再次尝试；
- 是否有应用内提示记录及发生顺序；
- 哪个结构标签匹配引出了学习回忆。

当前**不能**自动统计：
- 学生正确率、已证明掌握率、无外部帮助的独立解题率；
- 真实近迁移或远迁移的成功概率；
- 教师盲审评价、长期知识保持或真实学习成绩提升。

这些都需要冻结新测试题、可审阅的数学答案/rubric、教师独立评分或受控实验设计。

## 风险和后续

公开仓库与 SQLite 模拟没有正式学生登录、访问控制或未成年人隐私机制，不能上线给真实学生。

后续 v0.13b 重点：独立冻结的新变式、教师对学生原始步骤人工评价接口、延迟复测与先验/后验线性及多变量控制。不得将提示规则命中当“AI理解”。

旧版 v0.5–v0.12 绿色布局与所有数学实验功能保持兼容。
