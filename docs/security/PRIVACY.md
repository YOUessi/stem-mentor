# 隐私、未成年人安全与内容边界

当前仓库公开（GitHub 连接检查于 2026-10-15），因此：
- 只能提交合成学生、公开或自创且可授权的数学示例；严禁真实学生姓名/学籍/答题记录/录屏与任何 API 密钥。
- 当前模拟系统**没有用户认证、租户隔离或家长管理**，只能作为开发演示，不能向真实未成年人收集学习数据。
- 部署到真实环境前必须加入用户认证、按学生授权隔离、数据保留/导出/删除、审计日志、未成年人隐私与监护人流程。
- 教材/教辅题目进入库前记录版权和授权；不要随意全文抓取受版权保护的资料。
- 不把模拟引擎的模板回答称为经过验证的教学判断；数学无法校验时不能假装证明正确。
- 前端防 XSS；后端对输入长度、SQL 参数、路径和请求体设置边界。
