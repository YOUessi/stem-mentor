# 2026-10-18 · 高中数学全知识点工具底座 v0.8

## 用户要求
以高中全部数学知识需要为上层架构设计动态工具，支持圆锥曲线、三角形、函数曲线、平面坐标系及立体空间 XYZ 坐标系。绿色护眼第一版界面必须保持。MacBook Air 为唯一设备，无 API、无 Tang。

## 已核实参考
教育部普通高中数学课程标准（2017年版2020年修订），按必修、选择性必修与选修拓展构建工程知识清单。来源与局限详见 docs/design/HIGH_SCHOOL_MATH_VISUAL_V08.md。

## 实际完成
- curriculum/highschool_math/curriculum_map.json：113 条工程知识规划，44 条已映射基础可视化交互，69 条待专项工具建设；明确不等于全部完成课程教学。
- curriculum/highschool_math/visual_presets.json：29 个真实可切换场景：函数 12、圆锥曲线与直线圆 6、三角形 3、空间 3D 8。
- 原绿色导航中加入独立“高中数学实验室”，不替换原教学工作台。
- 2D 函数/坐标图：网格、原点、图像、参数、缩放、探针和定义域检查。
- 解析几何：圆、椭圆、双曲线、抛物线的基本焦点/准线/渐近线，直线圆交点。
- 三角形：自由拖点、直角约束、边角面积、SSA 多解可能性检查。
- 空间 3D：右手坐标、可拖动旋转、视角滑块、空间点投影、向量、平面法向量、棱柱/棱锥/球/圆柱/圆锥。
- 浏览课程知识表时按课程层次、完成程度、知识关键字检索；规划与已实现明确分开。
- API GET /api/math-lab/catalog：只读目录，检查唯一 ID 和参数范围，所有材料标记为项目自编、待教研审核。

## 测试记录及实际故障
1. 初次测试误将二维 SVG 顶层节点数作为场景成功标准：部分曲线仅需网格和主路径而导致误判；已改为检查真实坐标轴/图形及指标。
2. 3D 箭头最初将深度字段一同序列化为二维多边形坐标，造成异常巨大三角形；已改用屏幕投影前两个坐标，并增加箭头顶点两维校验。
3. 浏览器测试直接等候 option 可见会超时，实际 option 已载入但浏览器认为 option 本身不可见；改为核验预设个数。
4. 导航到实验室首次异步载入目录时，题目关联实验可能先触发；已令导航等待首次目录读取。

## 限制
目前 113 条是高校前的高中数学课程工程知识覆盖草案，非官方逐条目录，也没有每项知识的专项动画。29 个场景是自主探索的数学工具，不负责独立自动证明、生成完整解答或验证真实学生掌握。
