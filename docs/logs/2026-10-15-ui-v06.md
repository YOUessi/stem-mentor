# 2026-10-15 · v0.6 学习工作台设计与实施日志

## 本轮要求
用户认为现有网页不够精致，希望搜索社交平台案例、成熟动态前端组件，并继续实际开发。

## 设备 / 边界
- 只在 MacBook Air 开发：/Users/youtang/Documents/文件/stem-mentor。
- GitHub 仍是代码与过程记录事实来源。
- 不启用 Tang、不调用 LLM API、不重新编造学生掌握率。

## 调研与设计决定
查看 Dribbble、Behance 的数学教育工具及 Reddit 前端讨论；查阅 shadcn/ui、Motion、React Bits、Motion Primitives、Magic UI、Aceternity UI。决定采用具有清晰信息层次的数学学习工作台，局部状态动态反馈，避免毫无关联的全屏粒子、闪光与浮动。

## 具体修改
1. 深色教学导航、浅色主体、蓝紫和青绿色强调、学习思路路径的轻动画，统一标题及卡片层级。
2. 三种教学模式改为清晰可操作的卡片；所有教学业务请求不变。
3. 工作区左右可拖动调宽，支持方向键及本地存储；小屏自动单列。
4. 加入 Command/Ctrl + K 导航命令面板，支持搜索、上下键和 ESC。
5. 导师空态支持直接填写三种想法起点；学习历程节点更清楚地表达阶段。
6. 学生未提交草稿按会话存至浏览器本地；重新载入后恢复。
7. 删除首次载入的冗余 Toast，避免遮挡题目。
8. 动效尊重系统 Reduced Motion，使用原生 CSS/JS 而非在模拟版引入大型动画依赖。
9. 个人经历和复习计数来自真实的本地模拟接口，不使用假统计。

## 真实浏览器与自动化验收

- 命令面板打开/搜索/跳转、模式切换、草稿刷新恢复、提交思考并更新轨迹、可调整双栏的键盘操作和持久化、手机模式切换均通过。
- 浏览器 pageerror: 0。
- 后端仍执行 85 项回归以及 33/33 合成教学策略和 40/40 检索硬负例场景；不能据此宣称实际教学有效。
