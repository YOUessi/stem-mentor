# 2026-10-17 开发日志：绿色学习体验 v0.7

## 用户目标
继续完善绿色护眼 STEM Mentor，不更换恢复好的第一版配色与布局。重点建设公式排版、交互式几何画板和学生自己能够连接思路的关系图。仍不接入模型 API。

## 设备约束
只在 MacBook Air 上开发、运行和测试，位置 ~/Documents/文件/stem-mentor。GitHub 是唯一版本化事实来源；没有使用 Tang。

## 实现
1. 自托管 MathJax 3.2.2 SVG 包，附 Apache-2.0 许可。公式来自经过结构化标注的题目已知条件，15 道题全部覆盖，未引入在线字体/CDN。
2. 学生可输入基本 LaTeX 表达式查看预览，支持受限命令，不将公式渲染与数学正确性验证混为一谈。
3. 受控定比轨迹、焦点距离和与椭圆上的动点三个场景支持 SVG 自由拖动、实时数值、学生主动启用约束观察、本人拖动形成的路径与清除操作；不直接绘制未知轨迹答案。
4. 用现有会话里的真实思考步骤生成条件/目标/正推/卡点/逆推的学生思维图，不读取教师侧隐藏解题结构。
5. 学生可提出、标注并保存思维关联，但所有关系默认未经证明；SQLite 增加独立表并加入输入条件检查。
6. 手机端为思维图提供可读的条件/目标与步骤卡，保留绿色低刺激背景。
7. 按学生、会话暂存未提交草稿，避免页面刷新丢失；发送后清空缓存。
8. 现有后端对话、历史学习经历、题型/方法 RAG、微考点复习和三种学习模式不做非必要变更。
