# 2026-10-15 v0.4 开发日志

## 目标
在上一版本基础上推进结构化数学推理、教学决策质量与本地真实知识检索。继续不接入 LLM API。

## 交付
- 新增 `reasoning.py` 与 `knowledge/reasoning_graphs.json`：六道受控题的正推/逆推/桥梁/条件结构图与学生可见图的隔离。
- 新增 `diagnosis.py`：文本信号和学生自报阶段分开，标明来源和不确定性。
- 重构 `tutor.py`：可解释教学策略编号、重复卡点策略切换、持久化决策依据、未求助自主模式隐藏方法候选。
- 新增 `retrieval.py`、8 条自编方法文档以及 FTS5 + 中文 bigram + BM25 检索和条件门控。
- 更新 `math_tools.py`：AST 限制符号表达式恒等检验，避免解析时执行任意 Python。
- 增加前端阶段自报、公式等价检验、检索来源与适用条件反馈。
- 更新接口与单元/集成/模拟策略评测。

## 证据
本地 pytest 36/36，通过合成场景评测 19/19；Chromium DOM + FastAPI TestClient 桥接模拟交互成功，JS 错误 0。完整报告见 `docs/evaluation/SYNTHETIC_VALIDATION_20261015.md` 与评测 JSON。

## 未完成/限制
本地环境阻止 Chromium 通过真实网络导航，因此没有声称做过真实 HTTP 端到端浏览器验收。没有 LLM、向量模型、认证和真实学生实验；知识库规模 8 条且待教师专家审核。接下来优先增加有许可证的优质教材语料、数学语义解析与学生教学盲评，而不是用规则拟合数据假装自主思考。
