# STEM Mentor｜Batch13：132 条课程目标与 176 篇草案的编辑态双向关联队列

日期：2026-11-03。MacBook Air 独立工作树 `feat/kb-batch13-review-queue`，承接 Batch12 PR #38，保护主仓所有未提交修改；Tang 没有用于研发。

## 为什么需要这一批

Batch12 建立 132 条按课程方向及课程标准**纸质页码定位**的项目自编目标样本，但未建立任何有效的课程目标→深度讲义关联。此前的 176 篇 `REVIEW_PENDING` 数学深度草案仍仅挂在项目 113 条工程目录上。若不建立可审核的关联队列，容易用「标题相似」或 113/113 的工程链接冒充课标完整覆盖。

本批创建**可机器复算、不公开给学生**的独立候选关联矩阵，每一条关联都保留目标和讲义的规范化 SHA256 校验。链接仅意味着作者认为可能存在**部分主题重叠**，不是经过教研签字的教学内容满足性证据。

## 工程交付

- `scripts/build_kb_batch13_proposals.py`：显式编辑态关联列表及确定性生成器，不使用关键词自动升格。
- `curriculum/highschool_math/objective_lesson_proposals_batch13.json`：132 条目标**每条都有审查队列行**；其中 86 条具有至少一个未审查的候选链接，共 104 条候选边。46 条仍没有编辑建议并保持待建设。
- `backend/app/objective_proposals.py`：逐项验证课程方向/页码、一致性 hash、版本快照、真实草案 ID、重复边、计数及虚假的批准状态。任意课程目标或讲义内容更改都会使旧链失效，必须重生成与重新审核。
- `backend/tests/test_kb_batch13_editorial_links.py`：包括伪造教师审核、学生内容发布、虚构官方分母或覆盖率、错页码、错学科方向、伪造 proof/source grounding、未知/被改动的讲义、重复边等负面案例。
- `scripts/audit_kb_batch13_proposals.py` 及 `docs/evaluation/KB_BATCH13_EDITORIAL_REVIEW_QUEUE.json`：机读项目审查队列分母与审计快照，官方完整原子分母仍保留 `null`；CI 加入两个 `--check`。
- 学生 `/api/knowledge/standard-progress` 与 Approved-only RAG **不接入本编辑队列**，防止未经核验的知识映射影响学生提示或教师解答泄漏。
