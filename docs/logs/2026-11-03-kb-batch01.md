4. K02/K03/K04：原创 28 个分类型完整字段的知识草案（10 概念、18 定理），存为两份按主题分组的 JSON：`core_foundations_v1.json`、`geometry_probability_sequences_v1.json`。包含集合、命题与量词、不等式、函数、指数对数、三角恒等、向量、几何、复数、概率统计、等差等比、导数、计数等。每单元至少两道教师侧例题、反例和错因、三层提示、near/far 变式、明确证明或解释理由，审核状态全部 REVIEW_PENDING。
5. K07/K09：加入自动化 Schema、边界条件和符号/数值不变量测试；修复了最初课程覆盖计数被 defaultdict 的批准状态查询副作用错误扩增的问题；重新整理了向量点积→余弦定理的证明依赖，避免数学论证环。椭圆定义由距离差和两个根式方程逐步推到标准形式；统计样本方差增加独立同分布与有限方差条件。
6. CI：增加课程覆盖脚本在 GitHub Actions 中的执行；Mac 进行现有整体后端/Node、规则策略、检索回归及新内容负面测试。浏览器回归单独使用临时 SQLite 与随机端口，避免影响原本环境。
