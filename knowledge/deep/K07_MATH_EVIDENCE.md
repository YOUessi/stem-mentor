# K07 受限数学证据链（首批，未教师审校）

> 工程事实：这是 **48 条人工冻结的数学子命题的机器检查**，不是
> 48 篇定理的形式证明，更不是学生自由输入数学步骤的正确性认证。
> 关联 #17、#19、#20–#22、#25、#27；建立在 PR #28 的 28 篇
> REVIEW_PENDING 教学草案之上。

## 为什么需要这一层

知识库已有自然语言的定义、证明草案、反例、典型题和提示阶梯，但仅有
Pydantic Schema 并不能证明数学内容正确。语言模型生成「证明完成」
也不等于证明。因此引入 **数学子命题—有效域—可复现验证结果**：
明确记录哪些具体式子可以核对、哪些有反例、哪些由于缺少非零条件必须拒绝。
其余课程推理仍由教师/数学专家审校。

## 数据与运行

- math_evidence_v1.json：项目原创、冻结、全部 REVIEW_PENDING。
- scripts/build_deep_math_evidence.py：人工编写的 48 个声明及解释，
  重新生成同一 JSON；测试检测内容漂移。不是从模型自由文本直接抽取。
- backend/app/deep_math_evidence.py：仅限 + - * / **、有界整数幂、
  受控变量、sin、cos、pi 的 AST，不能调用其他函数或执行 Python。
- scripts/audit_deep_math_evidence.py --check：独立复验所有声明，
  不符合预期非零退出；--output 生成计数及失败原因的可存档报告。
- backend/tests/test_deep_math_evidence_k07.py：固定真假命题、无效分母、
  假审核、恶意语法、错误导数、不合法/伪造数值反例的回归测试。

在项目根目录运行：

    PYTHONPATH=backend .venv/bin/python scripts/audit_deep_math_evidence.py --check
    cd backend && PYTHONPATH=. ../.venv/bin/python -m pytest -q tests/test_deep_math_evidence_k07.py

**有限的形式结论类型：**

1. IDENTITY_ON_DECLARED_DOMAIN：将两个受限表达式的差进行 SymPy 符号
   化简，确认给出的代数/三角恒等式；表达式中每个原始除数必须具有显式
   非零条件。声明条件本身是**假设**，不是被证实的先前步骤。
2. DERIVATIVE_IDENTITY：确认一个具体表达式相对于受控变量的求导结果；
   固定次数例子不自动证明所有指数上的幂函数求导法则。
3. VALID_COUNTEREXAMPLE：以确切有理数赋值，查出一个假命题的
   左右两侧或不等号不成立。见证点若落在分母为零的位置，一律拒绝。
4. DOMAIN_NOT_ESTABLISHED：漏掉必要非零条件，即使表达式简化成常量
   仍拒绝（例如 x/x=1 需要 x≠0，q=1 时等比和的分式无定义）。

## 小例子

对于 (x**2-1)/(x-1) = x+1：

- 代数形式在 x-1 ≠ 0 的定义域内成立；
- 若不声明 x-1 ≠ 0，审计返回 DOMAIN_NOT_ESTABLISHED；
- 即使 SymPy 将分式化简为 x+1，也不能据此给原式补上 x=1；
- 该式是**一个**支持知识点「函数定义域」的算式，不是学生整道证明的认证。

类似地，对 (1-q)*(1+q+q**2+q**3) = 1-q**4 的无分母恒等式，
无需 q≠1；但对 (1-q**4)/(1-q) 的分式版本必须排除 q=1。

## 当前 48 条实际含义

- 28 条受限恒等式；5 条具体导数等式；
- 10 个精确有理数反例；
- 5 个特意遗漏非零条件的拒绝样本；
- 关联 PR #28 的 28 份草案中的 14 个 lesson ID；
- 其余 14 篇草案未受本批子命题核验；
- 正式教师审核通过 **0**，整篇定理形式证明通过 **0**，
  学生实际解题验证 **0**。

这个范围远小于完整高中数学。不要将 math_subclaims_checked=48 用作
知识库正式正确率、课标覆盖率或数学证明完成度。未来应为更多定理建立
专门的条件验证器、区间不等式检查和几何证据，不能依靠形式测试覆盖整个
自然语言证明。

## 安全和发布边界

无 API 路由导出 math_evidence_v1.json、学生答案或教师完整解法；
运行时公开计数由既有 deep_knowledge.public_summary() 提供，仍然
direct_student_teaching_enabled=false。项目保存人工草案及可复验的
符号证据，**审核仍全部等待真实教师签字**。若要将来提供给 Agent，
只能使用权限隔离的证据检索，不能把符号检查成功转换为「定理已教研审核」
或「学生证明正确」。

本检查器不是通用 CAS 前端：刻意不支持 sqrt、log、不等式符号解析、
数学量词、完整分段函数、复杂指数、条件推理链和任意数学表达式。对于
这些任务应输出未支持，而不是推断为数学错误或默认判定正确。
